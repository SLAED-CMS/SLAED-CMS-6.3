# SLAED Phoenix

Самостоятельный пакет презентации SLAED CMS. Все рабочие файлы, музыка, пресеты, изображения, логотипы, шрифты и готовые ролики находятся в этом каталоге. Пакет не зависит от файлов шаблонов или каталога демо.

## Быстрое подключение

Разместите каталог `phoenix` на том же сайте, где будет запускаться презентация. На любой странице подключите скрипт и добавьте кнопку:

```html
<script src="/phoenix/embed.js" defer></script>
<button type="button" data-sl-phoenix>Смотреть Phoenix</button>
```

Скрипт сам определяет каталог пакета по своему адресу и подключает необходимые файлы. Можно перенести или переименовать весь каталог: достаточно изменить `src` подключаемого скрипта. Для запуска требуется HTTP(S), один источник с родительской страницей и разрешённые политикой CSP локальные скрипты, стили, шрифты, аудио, `fetch` и iframe.

Презентация открывается поверх текущей страницы в изолированном iframe. В финале пиксели и прозрачность плавно раскрывают эту же страницу. Перезагрузки нет: введённые данные, состояние JavaScript и адрес сохраняются. Страница становится доступной при музыкальном хвосте. Контейнер удаляется после завершения музыки.

Тема по умолчанию берётся из `data-theme` элемента `html`, затем из системной настройки. Чтобы выбрать её явно:

```html
<button type="button" data-sl-phoenix data-sl-phoenix-preset="dark">Тёмный вариант</button>
<button type="button" data-sl-phoenix data-sl-phoenix-preset="light">Светлый вариант</button>
<button type="button" data-sl-phoenix data-sl-phoenix-sound="0">Смотреть без звука</button>
```

Дополнительные атрибуты: `data-sl-phoenix-volume="0.7"`, `data-sl-phoenix-autoplay="0"` для показа стартового экрана с выбором запуска.

## Управление из JavaScript

После загрузки `embed.js` доступен `window.SlaedPhoenix`:

```javascript
document.querySelector('#launch').addEventListener('click', async () => {
    const result = await SlaedPhoenix.setPlay({preset: 'dark', sound: true, volume: 0.7});
    console.log(result.reason);
});
```

`setPlay()` возвращает Promise, который завершается после закрытия презентации и музыкального хвоста. Повторный вызов во время воспроизведения возвращает тот же Promise и не создаёт второй проигрыватель. `setStop()` закрывает презентацию и останавливает музыку. `isPlaying()` показывает, активна ли презентация, включая музыкальный хвост.

| Параметр | Значение |
|---|---|
| `preset` | Имя JSON-пресета без расширения: `dark`, `light` или собственное |
| `theme` | `dark` или `light`; перекрывает тему пресета |
| `sound` | `true` / `false`; перекрывает пресет |
| `volume` | Число от 0 до 1; перекрывает пресет |
| `autoplay` | `true` / `false`; перекрывает пресет |
| `at` | Секунда для просмотра кадра на паузе; используется при проверке и монтаже |

Музыка включается из пользовательского действия. Если `setPlay({sound: true})` вызван автоматически при загрузке страницы, появится стартовый экран с выбором запуска. Автоматический запуск без звука: `SlaedPhoenix.setPlay({sound: false})`.

События отправляются в `document`:

| Событие | Когда | `event.detail` |
|---|---|---|
| `slaed:phoenix:ready` | Проигрыватель готов | `preset`, `theme` |
| `slaed:phoenix:reveal` | Текущая страница раскрыта; музыкальный хвост продолжается | `preset` |
| `slaed:phoenix:end` | Контейнер и аудио освобождены | `preset`, `reason` |
| `slaed:phoenix:error` | Загрузка не удалась; контейнер освобождён | `preset`, `reason: 'error'` |

Причины завершения: `complete`, `skip`, `close`, `reduced-motion`, `pagehide`, `error`. Escape и кнопка пропуска позволяют сразу вернуться к странице. При системной настройке уменьшения движения используется короткий спокойный вариант.

## Пресеты

`presets/dark.json` и `presets/light.json` содержат настройки запуска:

```json
{
    "theme": "dark",
    "sound": true,
    "volume": 0.7,
    "autoplay": true
}
```

Для своего пресета скопируйте JSON в этот каталог, например `presets/launch.json`, и запускайте с `preset: 'launch'`. Имя начинается с латинской буквы, содержит строчные латинские буквы, цифры или дефисы и не превышает 32 символов. Пресеты изготовления музыки и видео находятся отдельно в `presets/production/` и не используются при запуске.

## Самостоятельный просмотр

Откройте `index.html` через веб-сервер. Примеры адресов:

```text
/phoenix/index.html?theme=dark
/phoenix/index.html?theme=light&at=42
/phoenix/index.html?theme=dark&target=/index.php?name=presentation
```

`target` задаёт страницу для финала самостоятельного просмотра. Для адреса с несколькими query-параметрами кодируйте значение через `encodeURIComponent`. При встроенном запуске раскрывается текущая родительская страница; `target` не используется. Старый адрес `/demo/phoenix-codex.html` перенаправляет на новый проигрыватель, сохраняя параметры и fragment.

## Состав пакета

| Каталог / файл | Содержимое |
|---|---|
| `index.html`, `player/` | Сцены, анимация, единая шкала времени, звук и связь с родительской страницей |
| `embed.js`, `embed.css` | Подключение к любой странице |
| `presets/` | Настройки запуска; `production/` — тексты и параметры изготовления |
| `audio/` | Утверждённая музыкальная тема и резервная дорожка |
| `images/`, `logos/` | Рабочие изображения и оригинальные SVG-логотипы |
| `vendor/` | Локальная палитра, иконки и шрифты для изолированного проигрывателя |
| `exports/` | Светлый и тёмный MP4: 1280 × 720, 30 кадров/с, H.264 / AAC |
| `archive/` | Полные исходные записи, прежние варианты, WAV-мастер и пробы произношения |
| `examples/` | Два примера подключения на страницах разной вложенности |
| `manifest.json`, `checksums.json` | Версия пакета, точки входа и контрольные суммы файлов |

Для публикации проигрывателя достаточно `index.html`, `embed.js`, `embed.css`, `player/`, `presets/dark.json`, `presets/light.json`, `audio/`, `images/`, `logos/`, `vendor/`. Архив и ролики при запуске не загружаются; их можно хранить отдельно от публичного сайта, сохранив полную рабочую копию пакета.

Музыкальная тема длится 83,352 секунды. Плавное затухание начинается на 74,700 секунде, страница раскрывается на 80,700 секунде. Музыка продолжает звучать ещё 2,652 секунды. Утверждённая дорожка перенесена без изменения аудиоданных.

Встроенный запуск не привязан к админке, маршрутам CMS, авторизации, cookies или хранилищу браузера. Выбор страниц и частоты показа остаётся у вызывающей страницы.
