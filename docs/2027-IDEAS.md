# Идеи 2027

Все сырые идеи по системе SLAED после релиза 8.0, по пунктам. Проработанные планы с решениями и шагами лежат
отдельно: `docs/2027-CONNECTOR.md`, `docs/2027-CORE.md`, `docs/2027-ADMIN-UX.md`, `docs/2027-VINE-MONITOR.md`.

Статус: идеи, ничего не решено и не реализовано.

Как пользоваться:
- новая идея — следующий номер в своём разделе; номера сквозные и не переиспользуются, чтобы «идея 4» всегда значила
  одно и то же;
- пункт — заголовок и несколько строк: что, зачем, чем рискует; без устройства и шагов;
- владелец решает делать — идея переезжает в проработанный план (2027-й или новый план 2026 года в roadmap), а здесь
  остаётся строка «→ перенесена в <файл>» под её номером;
- владелец отказывается — строка «отклонена <дата>: <почему>», чтобы не предлагать её снова.

Номеров строк здесь нет намеренно: каждая ссылка называет функцию, файл или константу, их и искать.

## Обновления и мастер

Устройство обновлений — `docs/11-UPDATE-2026.md`, после его закрытия — постоянная справка `docs/UPDATE.md`.

### 1. Автоустановка исправлений безопасности

- Галочка «Ставить исправления безопасности сами» на вкладке «Настройки» страницы «Обновления», по умолчанию
  выключена; срабатывает только на выпуск с флагом `security`, обычные выпуски — по кнопке, как прежде.
- Те же шаги установки гонит планировщик, по одному за запуск, с тем же `apply.lock`, бэкапом и автооткатом; итог —
  оповещение на главной панели и письмо, сорвалась — откат и отчёт `fail` мастеру.
- Отложено владельцем 2026-10-15: фоновая установка — отдельная работа, до 8.0 не нужна.

### 2. Публичная страница «SLAED в цифрах»

- Страница на slaed.net из дневных итогов модуля `master`: доли версий, каналов, PHP и серверов баз; только
  агрегаты, без доменов и `sid`.
- Витрина проекта и опора для решений вроде «какой PHP требовать в следующей версии».

### 3. Подробные отчёты об ошибках по согласию

- В 8.0 мастер получает только число ошибок PHP и базы. Здесь — отдельная галочка, по умолчанию выключена:
  отправлять место ошибки (`file:line` от корня, версия, канал журнала), без текста сообщения.
- Перед включением админ видит предпросмотр ровно того, что уйдёт; на мастере — вкладка «Ошибки» с самыми частыми
  местами по версиям.
- Риск: путь и строка — уже сведения о коде сайта; поэтому только по согласию и без текста.
