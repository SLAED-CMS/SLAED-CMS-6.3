[justify]This section is designed for managing informational messages that are displayed on the main page of the website.
Messages may be needed to:
[li] greet users;
[li] post an important announcement (for example, that the site will be undergoing maintenance on a certain date);
[li] post a «hot» announcement.

[b][color=green]Adding a message[/color][/b]
To add a message, go to the «Add» tab and fill in the form, which contains the following fields:
[li] [b][i]Title[/i][/b] – specify it briefly and clearly;
[li] [b][i]Text[/i][/b] – note that the message text on the website is displayed directly after the title, not on a separate page;
[li] [b][i]Language[/i][/b] – select the language version in which the message should be displayed;
[li] [b][i]Duration in days[/i][/b] – how many days the message will be active. 0 means the time is unlimited;
[li] [b][i]Who will see this?[/i][/b] – select which user types will be able to view the message;
[li] [b][i]Activate?[/i][/b] – select whether the message should be displayed or not.

[color=orangered][b][i]Message display pages[/i][/b][/color]
Messages are displayed only on the main page of the website.

[color=orangered][b][i]Rules for displaying multiple active messages[/i][/b][/color]
The message that was added earlier than the others is displayed.[/justify]
