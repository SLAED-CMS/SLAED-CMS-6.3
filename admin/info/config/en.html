[justify]The «Configurations» section is designed for managing the main settings (configurations) of the website and consists of the following tabs:
[li] [b][i]Basic[/i][/b] – basic website settings are configured;
[li] [b][i]SEO[/i][/b] – settings for search engine optimization of the website;
[li] [b][i]Language[/i][/b] – management of website multilingual settings;
[li] [b][i]Censorship[/i][/b] – settings for excluding unwanted words and phrases;
[li] [b][i]Search[/i][/b] – website search settings;
[li] [b][i]Search Bots[/i][/b] – defining the format for displaying information about search bots on the website;
[li] [b][i]Caching[/i][/b] – setting parameters for website page caching;
[li] [b][i]Mail[/i][/b] – setting the main email template.

[b][color=green]Basic[/color][/b]
[li] [b][i]System Version[/i][/b] – displays the name and version number of the system on which the website is built.
[li] [b][i]Website Name[/i][/b] – the website name can be set here, which will be displayed, for example, in website page titles.
[li] [b][i]Website Address[/i][/b] – the full URL address of the website is specified.
[li] [b][i]Set Website Logo[/i][/b] – the logo is selected from the directory: images/logos/. The logo is used in the design depending on the website theme.
[li] [b][i]Description[/i][/b] – this description is used in the «description» meta tag of website HTML pages (this field is analyzed by search engines among others).
[li] [b][i]Administrator Notes[/i][/b] – information that will be available to all authors (users of the management section). This information is displayed at the top of the system's administrator panel.
[li] [b][i]Website Opening Date[/i][/b] – the date when the website was launched.
[li] [b][i]Administrator E-Mail[/i][/b] – used when sending informational messages to the website administrator (including password recovery). When sending messages to users, this email is specified in the «From» field.
[li] [b][i]Cookie Name for Users[/i][/b] – cookies for users are necessary for the system to identify the user. For example, if they are registered and logged in previously, the system will recognize them automatically (no need to log in again).
It is recommended to change the default cookie name, a size of 3 to 5 characters is sufficient.
[li] [b][i]Session Name for Administrators[/i][/b] – the use of sessions is similar to the use of user cookies: determining administrator activity. However, unlike cookies, the session works on the server side, its duration is limited and set on the server. This method is more secure. A session is considered ended if there were no requests to the website from the user within a certain period of time (usually 15-30 minutes). The only downside is that after closing the browser or leaving the network, the session ends, so re-login will be required.
It is recommended to change the default name, a size of 3 to 5 characters is sufficient.
[li] [b][i]User Cookie Storage Time, in Days[/i][/b] – the storage time of cookies on the user's computer. Throughout the specified time, the system will automatically identify the user; if the time has expired, it will ask to log in with their login/password. Typically, a value of about 30 days is set.
[li] [b][i]Session Duration, in Minutes[/i][/b] – means: how many minutes an authorized website user can be inactive and still be considered online (on the website), with their name displayed in the User Info block.
[li] [b][i]Number of Materials in Administrator Panel Modules[/i][/b] – the number of records that will be displayed by default on one page (for example, in the «News» section).
[li] [b][i]Link to Forum Profile, Link to Forum Private Messages[/i][/b] – if a third-party forum is installed on the website, links can be specified that should lead to the user profile and to the «Private Messages» section of the forum. These links will appear in the personal profile of website users.
[li] [b][i]Link to IP Address Verification Website[/i][/b] – which website will be used to verify IP addresses (whois). IP addresses, for example, are visible to the administrator next to the author who left a comment on the website, and if you click on the IP address, it will be verified by the verification service specified in the field.
[li] [b][i]General User Registration With[/i][/b] – specifies which forum will be used for automatic registration (selected depending on the forum version installed on the website).
[li] [b][i]Design Theme[/i][/b] – the website design theme is selected that should be used at the moment. Theme management is done in the «Design Themes» section of the administrator panel.
[li] [b][i]Module Loaded on the Main Page[/i][/b] – modules are specified that should be loaded on the main page of the website (if provided by the website theme).
[li] [b][i]Module Loaded on the Administrator Main Page[/i][/b] – the module is specified that should be loaded on the main page of the administration section (if provided by the website theme).
[li] [b][i]Security Code Type[/i][/b] – the type of security code (Captcha) to be used on the website is selected. You can choose between S-Captcha and K-Captcha. Below, opposite the «Preview» field, the appearance of the current security code is displayed.
[li] [b][i]Parameter Responsible for Graphic Code[/i][/b] – selects in which cases the graphic code (captcha) should be displayed.
[li] [b][i]Security Code Image Quality, in Percent[/i][/b] – the lower the percentage, the harder it is to read the inscription.
[li] [b][i]Font Type in Security Code Image[/i][/b] – the writing style of the code content is selected.
[li] [b][i]Editor Usage[/i][/b] – the editor that will be used when filling in the content of website modules is selected. These can be editors: BB-editor; HTML editor TinyMCE 4; HTML editor TinyMCE 3.5; HTML editor CKEditor 4.2.
You can quickly change the editor in the administration section in the «Editor Usage» block (displayed on the left).
[li] [b][i]Global System Time[/i][/b] – specify the time zone whose time will be used by the website. The time is displayed, for example, next to each comment or forum message.
[li] [b][i]Activate Debug Extensions[/i][/b] – this functionality allows displaying the following information for website administrators and moderators (optional): system information (memory, generation and DB time); variable analyzer GET, POST, COOKIE; FILES, SESSION, SERVER; database query analyzer. When activated, the information is displayed at the bottom of the website page (below the footer). This functionality allows tracking the technical picture of the operation of modules and extensions (both standard and third-party).
[li] [b][i]Debug Functions Visibility[/i][/b] – allows selecting the display option for debug functions. When selecting the «All Visitors» mode, the information will be visible to all project visitors; in the «Administrators Only» option, only to project administrators.
[li] [b][i]Activate Visitor Sessions?[/i][/b] – when enabled, the system will track all actions of website visitors and record them in the session. If the user has done nothing after the time specified in the «Session Duration, in Minutes» field has elapsed, the session is deleted. If you set the «No» mark, the load on the website will decrease slightly.
[li] [b][i]Display Messages on the Main Page?[/i][/b] – whether messages from the «Messages» section of the administrator panel will be displayed on the main page.
[li] [b][i]Display Page Generation Speed?[/i][/b] – information about page generation speed is displayed in the website footer in the format: Generation: 0.2 sec. and 7 database queries in 0.001 sec. (in the example, data is conditional).
[li] [b][i]Activate Administrator Block «System Information»?[/i][/b] – the setting is responsible for displaying the «System Information» block.
[li] [b][i]Activate Main Administrator Panel?[/i][/b] – responsible for the administrator panel. If you select the «No» option, all content of the administrator panel will be displayed in abbreviated mode in the left blocks; this method is designed to save space and provide better material overview.
[li] [b][i]Activate Information Department Editor?[/i][/b] – if the setting is active, you can edit the help system of the administration section (data in the «Information» tab). For example, this option may be needed if the help system needs to be adjusted to the specifics of certain users of the management section.
[li] [b][i]Close Website for Maintenance?[/i][/b] – the option is used when maintenance work is being carried out on the website. When the option is enabled, website visitors see a message about the temporary unavailability of the website. The style and text of the message depends on the website theme.

[b][color=green]SEO[/color][/b]
[li] [b][i]Character Separating Titles and Headers[/i][/b] – the specified character is used to separate components of the page title (browser title).
[li] [b][i]Website Keywords[/i][/b] – keywords are entered separated by comma and space. Keywords are used in the «keywords» meta tag of website HTML pages (this field is analyzed by search engines among others). Keywords specified in this field are used by default or when automatic keyword generation is disabled.
[li] [b][i]Maximum Number of Keywords[/i][/b] – the specified number is used in automatic keyword generation (this many words will be generated at most). If automatic keyword generation is not enabled, this parameter will not be used. It is not recommended to specify too many keywords (15 - maximum).
[li] [b][i]Minimum Number of Characters in a Word[/i][/b] – the specified number is used in automatic keyword generation. Words whose length is less than specified will not be included in the keyword list. If automatic keyword generation is not enabled, this parameter will not be used.
[li] [b][i]Activate Automatic Keyword Generation?[/i][/b] – the system will automatically generate keywords for each website page based on the page content. Thus, each page contains different sets of keywords.
[li] [b][i]Shuffle Keywords?[/i][/b] – in the «keywords» tag, keywords will be written randomly each time the page is refreshed. The parameter is active both with automatic and manual keyword generation.
[li] [b][i]Activate URL Conversion to SEF?[/i][/b] – SEF (Search Engine Friendly) – web addresses that are convenient for human perception, as well as systems and methods for building such addresses. When this option is activated, website URLs are converted according to the SEF concept. Note that activating this option increases page generation time. This function is only supported if Mod Rewrite is installed on the server; you can check this in the «System Information» block: if Mod Rewrite is installed, «Mod Rewrite: On» will be displayed, otherwise «Mod Rewrite: Off».

[b][color=green]Language[/color][/b]
[hr][color=red][b][i]Attention![/b]
The values of language variables are set in the «Language Editor» section.[/i][/color][hr]
[li] [b][i]Default Language[/i][/b] – the website language that will be loaded by default when opening.
[li] [b][i]Activate Multilingual Properties[/i][/b] – when selecting «Yes», the website will contain links to other language versions.

[li] [b][i]Automatically Switch Website Language to Visitor's Country?[/i][/b] – when selecting «Yes», the website language will switch to the corresponding value depending on the visitor's country.

[b][color=green]Censorship[/color][/b]
Using censorship settings, you can significantly limit the display of unwanted content on website pages.
[li] [b][i]Censorship Method[/i][/b] – currently, essentially two methods are available: perform censorship or not.
[li] [b][i]Replace Forbidden Words With[/i][/b] – a set of characters is specified that will replace the forbidden word.
[li] [b][i]Forbidden Words[/i][/b] – listed separated by comma without space.
[li] [b][i]Convert Addresses to Hyperlinks?[/i][/b] – if text entered through the BB-editor contains link text, it will automatically be displayed as a hyperlink. You can see which editor is used on the «Basic» tab of the «Configurations» section.

[b][color=green]Search[/color][/b]
On this tab, website search settings are configured.
[li] [b][i]Minimum Number of Characters in Search Query[/i][/b] – if the search query contains fewer characters than specified in this field, the system will display a corresponding warning.
[li] [b][i]Number of Search Results per Page[/i][/b] – search results are displayed page by page and each page will contain the specified number of results. Note that if nothing is specified, search results will always be empty.
[li] [b][i]Maximum Number of User Page Numbers[/i][/b] – the page list will include the specified number of pages, and after that the number of the last page separated by ellipsis will be displayed.
[li] [b][i]Search with Expanded Description?[/i][/b] – if «Yes» is selected, each search result will display a fragment of material containing the searched text. If «No» is selected, each result will contain only the page title, as well as information about the module and category to which the material belongs.

[b][color=green]Search Bots[/color][/b]
On this tab, rules for displaying information about search bots on the website are set, as well as a list of search engine websites from which transitions to your project are recorded.

[b][color=green]Optimization[/color][/b]
Caching leads to faster loading of website pages and reduced server load.

[li] [b][i]Caching[/i][/b] – only the main page or all areas of the website. For large portals with high traffic (more than 5,000 unique visitors per day and more than 25,000 pages of content), it is recommended to cache only the main page. Otherwise, the disk space allocated by hosting may overflow, as well as increased load on it.
[li] [b][i]Statistical Cache Storage Time, in Seconds[/i][/b] – cached information is used during the specified time, after which the files will be overwritten.
[li] [b][i]Forced Deletion of Old Cache, in Days[/i][/b] – automatic cleaning of cache files when the time limit is exceeded.
[li] [b][i]Compress Cached Files?[/i][/b] – compression of cached files reduces their size by removing tabs, spaces in HTML tags, comments in CSS styles, writing all text in one line. Size savings, depending on content, is around 5-6%. This speeds up page transfer to the visitor's browser. Unauthorized copying of articles and other website content by automatic programs and grabbers is significantly complicated.
[li] [b][i]Activate Browser Caching?[/i][/b] – when viewing website pages, their content will be stored in computer memory, and when refreshing or reopening the page by the browser, data loading will essentially occur from the visitor's computer.
[li] [b][i]Activate GZip Compression?[/i][/b] – used for transmitting data in compressed form (most browsers support viewing GZip-compressed files). As a rule, this capability is used to speed up the receipt of requested information by website visitors, as well as to reduce outgoing server traffic.

The file caching system significantly reduces server load by disabling the PHP interpreter and database queries. On the first request to a URL, the generated file is saved under a unique MD5 signature, and on subsequent requests to this URL, the file is served from cache memory, which reduces page load time. Database queries and PHP interpreter startup on the server side are not performed when serving from cache.

[hr][b][color=blue]Please Note![/color][/b]
If the website has a lot of updated materials, caching may result in users not seeing updates promptly. Set an adequate cache storage time depending on project traffic; we recommend 300 to 600 seconds.[hr]
