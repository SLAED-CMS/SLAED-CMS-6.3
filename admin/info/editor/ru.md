# Редактор

Раздел **Редактор** (`admin.php?name=editor`) позволяет вносить «горячие» изменения в основные системные файлы конфигурации проекта прямо через панель управления ресурса (без необходимости подключения по FTP). Интерфейс предлагает удобный редактор с подсветкой синтаксиса кода (CodeMirror).

> [!WARNING]
> Данный раздел предназначен только для главных администраторов (Суперпользователей), хорошо знакомых с серверным программным обеспечением, синтаксисом регулярных выражений Apache и языком программирования PHP. Любая синтаксическая опечатка (например, не закрытая кавычка или скобка) в этих файлах вызовет фатальную ошибку 'HTTP 500' и полностью "положит" весь сайт вместе с админкой.

---

## Вкладки файлов

### 1. Ядро системы

Редактирование файла `config/system.php`. 
Сюда можно добавлять собственные PHP-функции и логику, которая будет доступна на уровне ядра во всех модулях системы.

> [!NOTE]
> При вставке PHP-кода в эту вкладку (и во вкладку «Шапка системы») **не нужно** писать открывающие теги `<?php` и закрывающие `?>`. Система сама добавляет их, а также защитную конструкцию `if (!defined('FUNC_FILE')) die('Illegal file access');` при сохранении.

### 2. Шапка системы

Редактирование файла `config/header.php`.
Код, размещенный здесь, будет интегрирован непосредственно в секцию `<head>` HTML-страниц вашего сайта.
Как правило, эта вкладка применяется для быстрого добавления:

* Глобальных счетчиков аналитики (Яндекс Метрика, Google Analytics), если они реализованы через PHP или `<script>`.
* Дополнительных META-тегов (помимо стандартных SEO-настроек).
* Динамических редиректов.

### 3. Правила Apache

Редактирование главного конфигурационного файла сервера `.htaccess`, лежащего в корне сайта. 
Панель позволяет изменять и дополнять правила маршрутизации ЧПУ (Человеко-понятный УРЛ), настраивать сжатие, кеширование браузера и безопасность.

> [!IMPORTANT]
> Для работы этого функционала ваш веб-сервер (Apache/OpenLiteSpeed) обязаны поддерживать работу с директивами `.htaccess`, а модуль `mod_rewrite` должен быть активирован.

### 4. Правила для роботов

Редактирование файла `robots.txt` (также лежащего в корне сайта).
Здесь хранятся инструкции для поисковых пауков (Яндекс, Google, Bing и др.). Вы можете запрещать к индексации служебные разделы (Disallow), разрешать страницы (Allow), указывать путь к `Sitemap.xml` или управлять параметром `Crawl-delay`.

## Примеры полезных внедрений (Snippets)

### Примеры для вкладки «Шапка системы»

**1. Перенаправление посетителя из определенной страны:**
Используя встроенную функцию `user_geo_ip()`, можно ловить гостей из нужных регионов и отправлять их на другие адреса:

```php
$userlang = "Russia";
$metlink = "https://example.com/ru-version/";
$userip = user_geo_ip(getip(), 2);
if ($userip == $userlang) {
    echo '<meta http-equiv="refresh" content="0; url='.$metlink.'">';
}
```

**2. Блокировка вызова правой кнопки мыши (базовая защита от копирования):**
(Вставляется как HTML скрипт прямо внутрь PHP через `echo`):

```php
echo '<script>
function click(event) {
    if (event.button == 2) { 
        alert("Копирование материалов запрещено!"); 
    }
}
document.onmousedown = click;
</script>';
```

### Примеры для вкладки «Правила Apache» (.htaccess)

> [!CAUTION]
> Код ниже добавляется **строго после** строк включения движка реврайтов (т.е. после *RewriteEngine On* и *RewriteBase /*).

**1. Защита от хотлинкинга (Использование ваших картинок на чужих сайтах):**
Данное правило запретит другим сайтам вызывать картинки с вашего хостинга, экономя вам трафик, и вместо ваших фото покажет загрушку.

```apache
RewriteCond %{HTTP_REFERER} !^http://(www\.)?slaed\.net/ [NC]
RewriteRule \.(jpe?g|gif|bmp|png)$ http://www.slaed.net/templates/default/images/bad-hotlink.png [L]
```

*(Не забудьте заменить `slaed\.net` на ваш домен).*

**2. 301 Редирект с www на без-www:**
Объединяет вес сайта для поисковиков.

```apache
RewriteCond %{HTTP_HOST} ^www\.(.*) [NC]
RewriteRule ^(.*)$ http://%1/$1 [R=301,L]
```

**3. Принудительный редирект на защищенный HTTPS протокол:**
Если у вас куплен и установлен SSL сертификат.

```apache
RewriteCond %{HTTPS} off
RewriteRule (.*) https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]
```

**4. Блокировка показа версий серверного ПО:**
(Базовая мера безопасности). Добавляется в любое место `.htaccess`.

```apache
ServerSignature Off
```

**5. Запрет листинга и просмотра файловых директорий браузером:**

```apache
Options All -ExecCGI -Indexes -Includes +FollowSymLinks
```
