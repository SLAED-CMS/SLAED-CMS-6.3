[justify]The «Newsletter» section allows you to create informational messages and send them to user groups (for example, project news, information about discounts, promotions, etc.). Letters are sent based on website traffic: when a site page is requested, letters are sent for active newsletters.

[color=green][b]Adding a newsletter[/b][/color]
To add a newsletter, go to the «Add» tab and fill in the newsletter information:
[li] [b][i]Title[/i][/b] – the title will be used as the email subject.
[li] [b][i]Text[/i][/b] – the letter text that will be sent to newsletter recipients.
[li] [b][i]Newsletter recipients[/i][/b] – select the user group to which the newsletter will be sent. The number of users in the group is displayed to the right of the group name. Explanations for some groups:
[b] * [/b]All users – the newsletter will be sent to all users of the resource;
[b] * [/b]Subscribed users only – the newsletter will be sent only to users who have set the value «YES» in the «Receive news by email?» setting in their personal account.
[b] * [/b]Customers of the «Shop» module – newsletter only to users who have made a purchase through the «Shop» module.
[li] [b][i]Number of letters per sending[/i][/b] – select the number of letters that will be sent at one time. It is recommended to set the value to 1-3 letters so that email systems do not consider the newsletter as SPAM and do not block the address.
[li] [b][i]Start sending newsletter[/i][/b] – if «Yes» is selected, then after selecting «Send» in the adjacent list and clicking «OK», the newsletter will start. If «No» is selected, after selecting «Send» and clicking «OK», the newsletter will not start but will only be saved.
[li] [b][i]Preview and send[/i][/b] – if «Preview» is selected in the field before the «OK» button, clicking the button will not send the newsletter; instead, the newsletter text will be displayed in the upper section of the add form («Preview») as the recipients will see it. If «Send» is selected, clicking the button will either start or only save the newsletter (depending on the value of the «Start sending newsletter» parameter).

[color=green][b]Newsletter list[/b][/color]
The list of all newsletters that have been added is displayed in the «Main» tab. The status of each newsletter is also displayed there: Deactivated or Activated.
The «Deactivated» status is assigned to already sent newsletters and newsletters saved without sending.
The «Activated» status is assigned to newsletters that are still being sent at the time of viewing the section.

[li] Information about how many users the newsletter was sent to and how long the sending took can be viewed in the columns: «Sent» and «Time» respectively.
[li] To view the date and time of newsletter creation, hover the mouse cursor over the icon (i) to the left of the desired newsletter title.
[li] To sort the newsletter list by a column, click on its name (clicking again will sort in reverse order).
[li] To modify a newsletter, click on the value (Full editing) in the «Functions» column. Editing can be useful for resending a newsletter or for starting a newsletter if it was not sent when added.
[li] To delete a newsletter, click on the value (Delete object) in the «Functions» column.

[hr][color=blue][b]Please note[/b][/color]
[li] If a newsletter was edited and resent, it is not added as a new row in the newsletter list; instead, the recipient statistics and sending time information are recalculated.
[li] When editing a newsletter for resending, make sure the user group is selected correctly.
[li] The email displayed in the «From» field is set in the «Configurations» section.[/justify]
