[justify]The "Word Replacement" section is designed to set rules for replacing words with arbitrary content defined by the administrator.
Word replacement is typically used for search engine optimization of website page content. For example, you can set rules where any mention of the word "slaed" will be replaced with a link to the website [url=https://slaed.net]slaed.net[/url].

[b][color=green]Setting replacement words[/color][/b]
Word replacement rules are set in the "Content" and "News" tabs.
[li] [b][i]Content[/i][/b] – rules for word replacement in texts created in the "Content" module are set here.
[li] [b][i]News[/i][/b] – rules for word replacement in news texts are set here.

To set word replacement rules, specify the following:
[li] [b][i]Word[/i][/b] – you can specify either a single word or a phrase. When text fully matching the specified word is found, it will be replaced.
[li] [b][i]Content[/i][/b] – the replacement text is specified here. You can enter HTML tags in the field for text formatting or creating hyperlinks.

To add a new word, click the plus sign next to the last added field.
To delete an empty new field, click the plus sign next to the field preceding the empty new field.
To delete a filled and previously saved field, you need to enter the value 0 in the "Word" and "Content" fields.
Note that all changes will take effect after clicking the "Save changes" button.

[color=orangered][b][i]Rules for partial word matching[/i][/b][/color]
If replacement rules are set for the word "paid", they will ultimately be applied both to the word "paid" and to the part "paid" in
the word "unpaid".

[color=orangered][b][i]Case sensitivity rules[/i][/b][/color]
For words written in Cyrillic, case is taken into account. For example, the words "Paid" and "paid" are treated as different words during replacement.[/justify]
