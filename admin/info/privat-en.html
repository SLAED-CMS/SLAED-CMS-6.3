[justify]The "Private Messages" section is designed for managing and configuring private messages of website users.

The administrator has the following capabilities:
[li] Viewing message text;
[li] Viewing message read status;
[li] Deleting messages;
[li] Section settings (configuration).

[b][color=green]Message List[/color][/b]
A paginated list of all private messages is displayed as a table in the "Main" tab. Explanations for some table columns:
[li] [b][i]Subject[/i][/b] – the message subject is displayed, along with an icon (i), hovering over which shows the full message text.
The depth of correspondence can be determined by the message subject: when replying to a message, the value "Reply:" is added to the subject.
[li] [b][i]Sender, Recipient[/i][/b] – the user's nickname (system name) is displayed as a hyperlink. Clicking it opens the page with the user's profile information.
[li] [b][i]Status[/i][/b] – if the message has been read by the recipient, the icon (i) for read message is displayed. If unread – (!) unread message.
[li] [b][i]Functions[/i][/b] – the administrator can delete any message by clicking the value (Delete object).

[b][color=green]Section Settings[/color][/b]
Message settings management is done in the "Configuration" tab, where the following settings can be configured:
[li] [b][i]Number of entries per user page[/i][/b] – the specified number of messages will be displayed when the user browses the "Private Messages" section. It is recommended not to exceed 30 messages per page to avoid increasing page load times.
[li] [b][i]Number of entries per administrator page[/i][/b] – the specified number of messages will be displayed on one page of the "Private Messages" section in the administration area.
[li] [b][i]Maximum number of page numbers for users[/i][/b] – if the number of pages with messages exceeds the specified value, an ellipsis will be displayed after the page number corresponding to the specified number.
[li] [b][i]Maximum number of page numbers for administrators[/i][/b] – similar to the previous setting, but configured for the management section (administration area).
[li] [b][i]Maximum allowed number of characters in a word[/i][/b] – the user will not be able to send a message in which any word exceeds the specified number of characters (can be used, for example, to protect against SPAM hyperlinks).
[li] [b][i]Minimum time interval between publications, in seconds[/i][/b] – the user will not be able to send a message if the specified number of seconds has not yet passed since the previous sending (used to protect against SPAM mailings through private messages).
[li] [b][i]Maximum number of incoming (saved) messages[/i][/b] – if the limit is reached, the user will be prompted to clean up message folders.
[li] [b][i]Notify users about new messages?[/i][/b] – the notification is sent to the e-mail address specified in the user's profile.
[li] [b][i]Allow sending messages to yourself?[/i][/b] – this setting is usually set to "No", but may be useful in some cases.
[li] [b][i]Display button to user profile?[/i][/b] – if set to "Yes", when viewing a message, the user will see a button: Personal information, clicking which opens the personal information of the message sender.
[li] [b][i]Display button to user's website?[/i][/b] – if set to "Yes", when viewing a message, the user will see a button: Visit website, clicking which opens the website of the message sender, if the website address is specified in the user's personal information.
[li] [b][i]Activate private messages?[/i][/b] – if set to "No", the private messaging functionality is not available.[/justify]
