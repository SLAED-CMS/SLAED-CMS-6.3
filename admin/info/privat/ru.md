# Личные сообщения

Раздел **«Личные сообщения»** (`admin.php?name=privat`) предназначен для глобального управления внутренним мессенджером сайта, с помощью которого пользователи общаются друг с другом. Администратор имеет полномочия модерировать переписку для обеспечения порядка на проекте.

---

## 1. Главная (Список сообщений)

В этой вкладке выводится таблица всех личных сообщений на сайте. Используется AJAX-подгрузка списка для быстрой работы с большими базами.

* **№** — уникальный идентификатор (ID) сообщения.
* **Заголовок** — тема беседы.
  * Если навести курсор на синюю иконку **`(i)`** перед заголовком, появится всплывающая подсказка с полным текстом этого сообщения (чтобы вам не нужно было заходить «внутрь» каждого письма для проверки).
* **Отправитель** и **Получатель** — никнеймы пользователей в виде гиперссылок. При клике на них откроется профиль соответствующего юзера. (Если сообщение отправлено гостем с публичной формы, будет написано «*Гость*»).
* **Дата** — точное время отправки письма.
* **Статус** — визуальный маркер прочтения:
  * *Красная иконка* (!) — сообщение отправлено, но адресат его **еще не прочитал**.
  * *Зеленая иконка* (i) — сообщение уже прочитано получателем.
* **Функции** — меню **Редактор**, содержащее опцию удаления сообщения.

> [!NOTE]
> Вы можете легко отследить глубину переписки (треды). Если пользователь отвечает на чужое сообщение, к теме его ответа автоматически добавляется приставка `Ответ: `.

---

## 2. Конфигурации

Вкладка тонкой настройки пользовательского мессенджера:

* **Количество публикаций на страницу (пользователя и администратора)** — лимиты пагинации для вывода списка сообщений (рекомендуется оставлять по умолчанию: *25*).
* **Максимальное количество номеров страниц** — отвечает за вид пагинации внизу списка (сколько кнопок с цифрами выводить до многоточия).
* **Максимально допустимое количество знаков в слове** — защита от «растягивания» дизайна шаблона неадекватно длинными словами.
* **Защита от СПАМа (Минимальный период времени)** — задает паузу (кулдаун) в секундах между отправкой двух сообщений: не позволяет ботам или спамерам делать массовые автоматические рассылки юзерам. По умолчанию *60*.
* **Лимиты базы (Входящие и Сохраненные)** — максимальная емкость папок каждого отдельного пользователя. Если ящик пользователя (например, *250* писем) переполняется, система вежливо предложит ему очистить старые сообщения, прежде чем он сможет читать новые.
* **Уведомлять пользователей о новых сообщениях?** — если `Да`, то при получении личного сообщения внутри сайта юзеру дополнительно уйдет красивое оповещение на его контактный E-Mail ящик.
* **Запретить отправлять сообщения самому себе?** — запрещает пользователям использовать свои же «Входящие», как приватный блокнот для заметок (чтобы не забивать базу).
* **Выводить кнопку профиля/сайта** — переключатели, управляющие выводом удобных кнопок для быстрого перехода в профиль отправителя при чтении его письма на фронтенде.
* **Активировать личные сообщения?** — глобальный рубильник `Да / Нет`. Если выбрать `Нет`, весь функционал обмена сообщениями на сайте будет физически отключен.
