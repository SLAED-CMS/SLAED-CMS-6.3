[justify]La section "Messages privés" est destinée à la gestion et à la configuration des messages privés des utilisateurs du site.

L'administrateur dispose des fonctionnalités suivantes :
[li] Consultation du texte des messages ;
[li] Consultation du statut de lecture des messages ;
[li] Suppression des messages ;
[li] Configuration de la section (paramètres).

[b][color=green]Liste des messages[/color][/b]
Une liste paginée de tous les messages privés est affichée sous forme de tableau dans l'onglet "Principal". Explications de certaines colonnes du tableau :
[li] [b][i]Objet[/i][/b] – l'objet du message est affiché, ainsi qu'une icône (i), au survol de laquelle le texte complet du message s'affiche.
La profondeur de la correspondance peut être déterminée par l'objet du message : lors d'une réponse à un message, la valeur "Réponse :" est ajoutée au sujet.
[li] [b][i]Expéditeur, Destinataire[/i][/b] – le pseudo (nom dans le système) de l'utilisateur est affiché sous forme d'hyperlien, dont le clic ouvre la page avec les informations du profil de l'utilisateur.
[li] [b][i]Statut[/i][/b] – si le message a été lu par le destinataire, l'icône (i) message lu est affichée. Si non lu – (!) message non lu.
[li] [b][i]Fonctions[/i][/b] – l'administrateur peut supprimer n'importe quel message en cliquant sur la valeur (Supprimer l'objet).

[b][color=green]Paramètres de la section[/color][/b]
La gestion des paramètres des messages se fait dans l'onglet "Configuration", où les paramètres suivants peuvent être définis :
[li] [b][i]Nombre d'entrées par page utilisateur[/i][/b] – le nombre spécifié de messages sera affiché lorsque l'utilisateur parcourt la section "Messages privés". Il est recommandé de ne pas dépasser 30 messages par page afin de ne pas augmenter le temps de chargement des pages.
[li] [b][i]Nombre d'entrées par page administrateur[/i][/b] – le nombre spécifié de messages sera affiché sur une page de la section "Messages privés" dans la zone d'administration.
[li] [b][i]Nombre maximum de numéros de pages pour les utilisateurs[/i][/b] – si le nombre de pages de messages dépasse la valeur spécifiée, des points de suspension seront affichés après le numéro de page correspondant au nombre spécifié.
[li] [b][i]Nombre maximum de numéros de pages pour les administrateurs[/i][/b] – similaire au paramètre précédent, mais défini pour la section de gestion (zone d'administration).
[li] [b][i]Nombre maximum de caractères autorisés dans un mot[/i][/b] – l'utilisateur ne pourra pas envoyer un message dans lequel un mot dépasse le nombre de caractères spécifié (peut être utilisé par exemple pour se protéger contre les hyperliens SPAM).
[li] [b][i]Intervalle de temps minimum entre les publications, en secondes[/i][/b] – l'utilisateur ne pourra pas envoyer un message si le nombre de secondes spécifié ne s'est pas encore écoulé depuis le dernier envoi (utilisé pour se protéger contre les envois de SPAM via les messages privés).
[li] [b][i]Nombre maximum de messages entrants (sauvegardés)[/i][/b] – si la limite est atteinte, l'utilisateur sera invité à nettoyer les dossiers de messages.
[li] [b][i]Notifier les utilisateurs des nouveaux messages ?[/i][/b] – la notification est envoyée à l'adresse e-mail indiquée dans le profil de l'utilisateur.
[li] [b][i]Autoriser l'envoi de messages à soi-même ?[/i][/b] – ce paramètre est généralement défini sur "Non", mais peut être utile dans certains cas.
[li] [b][i]Afficher le bouton vers le profil de l'utilisateur ?[/i][/b] – si défini sur "Oui", lors de la consultation d'un message, l'utilisateur verra un bouton : Informations personnelles, dont le clic ouvre les informations personnelles de l'expéditeur du message.
[li] [b][i]Afficher le bouton vers le site de l'utilisateur ?[/i][/b] – si défini sur "Oui", lors de la consultation d'un message, l'utilisateur verra un bouton : Visiter le site, dont le clic ouvre le site de l'expéditeur du message, si l'adresse du site est indiquée dans les informations personnelles de l'utilisateur.
[li] [b][i]Activer les messages privés ?[/i][/b] – si défini sur "Non", la fonctionnalité d'échange de messages privés n'est pas disponible.[/justify]
