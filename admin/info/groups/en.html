[justify]Groups are designed to categorize users either based on the number of points they have accumulated or by assigning them to a special group.
Each authorized user performs certain actions on the website (viewing pages, commenting, etc.) – for each such action, they can earn the number of points specified in the settings, thereby entering the corresponding user group (rank).

[b][color=green]Points management[/color][/b]
Points values are managed in the «Points» tab. Enter the number of points awarded for performing certain actions on the website and click «Save».

[b][color=green]Groups management[/color][/b]
Groups are managed in the «Main» and «Add» tabs.
The «Main» tab allows you to view the list of created groups and perform the following actions (column «Functions»):
[li] [b][i]Detailed view[/i][/b] – opens the «Users» section, which displays users belonging to the group.
[li] [b][i]Full editing[/i][/b] – opens the group data editing form.
[li] [b][i]Delete object[/i][/b] – the group is deleted.

The «Add» tab allows you to add a new group. The group addition form contains:
[li] [b][i]Group name[/i][/b] – this name is displayed on the website when viewing user information.
[li] [b][i]Description[/i][/b] – enter a description characterizing the group; the description is not displayed on the website.
[li] [b][i]Special group[/i][/b] – if the group is special, points are not taken into account and the user must be assigned to this group by editing their profile.
[li] [b][i]Minimum required number of points[/i][/b] – specify how many points a user needs to collect to become a member of the group being created. If the group is marked as special, this field disappears.
[li] [b][i]Image[/i][/b] – select an image that characterizes the group members. By default, a list of ranks is offered. Images are loaded into the list from the website's images/ranks/ directory, so the range of available images can be expanded independently if needed.
[li] [b][i]Color[/i][/b] – the color of the group name is selected. That is, on the website the group name will be displayed in the chosen color.
After filling in the form, don't forget to click the «Save» button.[/justify]
