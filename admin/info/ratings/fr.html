[justify]La section "Notations" permet de gérer la participation du contenu des modules aux notations :
[li] [b][i]Profil[/i][/b] – le profil (informations personnelles) de chaque utilisateur est évalué ;
[li] [b][i]Questions et réponses[/i][/b] – les entrées du module "Questions et réponses" sont évaluées ;
[li] [b][i]Catalogue de fichiers[/i][/b] – les entrées (fichiers) du module "Catalogue de fichiers" sont évaluées ;
[li] [b][i] Forum[/i][/b] – les sujets du module "Forum" sont évalués (les réponses dans les sujets ne sont pas évaluées) ;
[li] [b][i]Aide[/i][/b] – les messages du module "Aide" sont évalués ;
[li] [b][i]Blagues[/i][/b] – les entrées (blagues) du module "Blagues" sont évaluées ;
[li] [b][i]Catalogue de sites[/i][/b] – les entrées (sites) du module "Catalogue de sites" sont évaluées ;
[li] [b][i]Catalogue média[/i][/b] – les entrées du module "Catalogue média" sont évaluées ;
[li] [b][i]Actualités[/i][/b] – les entrées du module "Actualités" sont évaluées ;
[li] [b][i]Articles[/i][/b] – les entrées du module "Articles" sont évaluées ;
[li] [b][i]Boutique[/i][/b] – les produits du module "Boutique" sont évalués.

Pour chacun des modules disponibles, les paramètres suivants peuvent être définis :
[li] [b][i]Intervalle de participation à la notation, en jours[/i][/b] – combien de jours l'information sur le vote de l'utilisateur sera conservée dans le système (à l'expiration du délai, l'utilisateur pourra à nouveau évaluer l'entrée). Cela sert à empêcher la manipulation des notations par les visiteurs du site. Valeur 0 – pas de restriction.
[li] [b][i]Activer la notation[/i][/b] – si le module correspondant disposera d'un système de notation ou non.
[li] [b][i]Autoriser la notation uniquement en vue détaillée ?[/i][/b] – si l'échelle de notation sera disponible en vue abrégée d'une entrée du module ou uniquement en vue détaillée.

[b][color=green]Règles de calcul de la notation[/color][/b]
La notation est un système de comptabilisation des évaluations des utilisateurs qu'ils peuvent attribuer aux entrées correspondantes du site. La notation s'effectue sur une échelle de cinq points. L'échelle de notation peut être composée d'étoiles ou selon le principe plus/moins.[/justify]
