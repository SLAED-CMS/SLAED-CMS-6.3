[hr][color=red][b][i]Achtung![/b]
Dieser Bereich ist nur für Administratoren gedacht, die mit Serversoftware und der Programmiersprache PHP gut vertraut sind.[/i][/color][hr]
[justify]Der Bereich «Editor» ermöglicht die direkte Verwaltung der wichtigsten Systemdateien über das Administrationspanel. Die Dateiverwaltung erfolgt in den Registerkarten:
[li] [b][i]Systemkern[/i][/b] – Einbindungsdatei in den Systemkern: config/system.php. In der Registerkarte kann Code hinzugefügt werden, der in den Systemkern eingefügt wird.
[li] [b][i]System-Header[/i][/b] – Einbindungsdatei in den System-Header: config/header.php. In der Registerkarte kann Code eingefügt werden, der in den Head-Bereich des Systems eingebunden wird. In der Regel wird diese Datei für die Einbindung von Java-Skripten und Meta-Tags verwendet.
[li] [b][i]System-SEF[/i][/b] – Konfigurationsdatei für SEF-Transformationsregeln auf Systemebene: config/rewrite.php. In der Registerkarte können die Standardregeln für die Transformation von Browser-Adresszeilen geändert oder ergänzt werden. Diese Funktion wird nur bei auf dem Server installiertem Mod Rewrite unterstützt.
[li] [b][i]Server-SEF[/i][/b] – Konfigurationsdatei für SEF-Transformationsregeln auf Serverebene: .htaccess. In der Registerkarte können die Standardregeln für die Transformation von Browser-Adresszeilen auf Serverebene geändert oder ergänzt werden. Diese Funktion wird nur bei auf dem Server installiertem Mod Rewrite unterstützt.
[li] [b][i]Regeln für Robots[/i][/b] – Konfigurationsdatei für Anweisungen und Indizierungsparameter für Suchmaschinenroboter: robots.txt. In der Registerkarte kann die Textdatei im Stammverzeichnis der Website geändert oder ergänzt werden, in der spezielle Anweisungen für Suchmaschinenroboter aufgezeichnet sind. Diese Anweisungen können die Indizierung bestimmter Bereiche oder Seiten der Website verbieten, auf die korrekte «Spiegelung» der Domain hinweisen, dem Suchmaschinenroboter empfehlen, ein bestimmtes Zeitintervall zwischen dem Herunterladen von Dokumenten vom Server einzuhalten usw. In dieser Datei können Sie die Indizierungsparameter der Website sowohl für alle Roboter gleichzeitig als auch für jede Suchmaschine einzeln festlegen.

Um Änderungen an einer Datei vorzunehmen, wechseln Sie zur entsprechenden Registerkarte und nehmen Sie Änderungen im geöffneten Dateiinhalt-Editor vor. Zum Speichern klicken Sie auf «Speichern».[/justify]

[hr][color=red][b][i]Achtung![/b]
Wenn für die Konfigurationsdateien nicht die entsprechenden Zugriffsrechte festgelegt sind (CHMOD - 666), gibt das System eine entsprechende Warnung aus.[/i][/color][hr]
[b][color=green]Beispiele für die Verwendung des Einbindungs-Editors im Bereich «System-Header»[/color][/b]

[color=orangered][b][i]Weiterleitung eines Besuchers von einer bestimmten Website[/i][/b][/color]
Wechseln Sie zur Registerkarte «System-Header» und fügen Sie folgenden Eintrag hinzu:
[php]$reflink = "#slaed.net#i";
$metlink = "news.html";
$referer = text_filter(getenv("HTTP_REFERER"));
if (preg_match($reflink, $referer)) {
echo '<meta http-equiv="refresh" content="0; url='.$metlink.'">';
}[/php]
[justify]$reflink – verantwortlich für die Adresse der Website, von der der Besucher kam.
Anstelle von: slaed.net geben Sie Ihre Domain an.
$metlink – verantwortlich für die Seite, zu der der Besucher weitergeleitet wird.
Anstelle von: news.html geben Sie die erforderliche Seite oder Website an.

[color=orangered][b][i]Verbieten des Kopierens von Informationen von der Website[/i][/b][/color]
Alles, was gelesen und gesehen werden kann, kann entsprechend auch kopiert werden. Einen wirksamen Kopierschutz gibt es nicht. Das bedeutet aber nicht, dass man es nicht erschweren kann. Man kann die Verwendung der rechten oder anderer Maustasten, die zum Kopieren verwendet werden, deaktivieren. Dies wird ein kleines, aber dennoch ein Hindernis beim Kopieren für Anfänger sein.
Wechseln Sie zur Registerkarte «System-Header» und fügen Sie folgenden Eintrag hinzu:[/justify]
[php]echo '<script>
<!--//
function click() {
// Um die linke Taste zu deaktivieren, setzen Sie die Zahl 1
// Um die dritte Taste zu deaktivieren, setzen Sie die Zahl 3
if (event.button == 2) {
// Geben Sie hier Ihre Meldung ein, die im Warnfenster erscheint
alert("Copyright Scriptic!");
}
}
document.onmousedown=click;
//-->
</script>';[/php]
[justify]Beachten Sie, dass dieser Code nur in Internet Explorer-Browsern funktioniert. Es ist nicht ausgeschlossen, dass es auch für andere Browser etwas Ähnliches gibt. Wenn Sie einen anderen Code verwenden möchten, ersetzen Sie diesen einfach durch Ihren Code und fügen Sie ihn zwischen echo ' und '; ein.[/justify]

[color=orangered][b][i]Weiterleitung eines Besuchers aus einem bestimmten Land[/i][/b][/color]
Wechseln Sie zur Registerkarte «System-Header» und fügen Sie folgenden Eintrag hinzu:
[php]$userlang = "Russia";
$metlink = "news.html";
$userip = user_geo_ip(getip(), 2);
if ($userip == $userlang) {
echo '<meta http-equiv="refresh" content="0; url='.$metlink.'">';
}[/php]
[justify]$userlang – verantwortlich für den Namen des Landes, aus dem der Besucher kam.
Der Ländername darf nicht beliebig sein und muss den Standards für die Verwendung der Klasse entsprechen. Die richtige Schreibweise eines Landes kann in der Variable $COUNTRY_NAMES der Datei core/geo_ip.php überprüft werden.
$metlink – verantwortlich für die Seite, zu der der Besucher weitergeleitet wird.
Anstelle von: news.html geben Sie die erforderliche Seite oder Website an.

[b][color=green]Beispiele für die Verwendung des Einbindungs-Editors im Bereich «Server-SEF»[/color][/b]

[color=orangered][b][i]Verbot der Verwendung von Bildern von der Website durch andere Websites[/i][/b][/color]
Es ist kein Geheimnis, dass einige Websites, um ihren Traffic und den verwendeten Serverplatz zu sparen, Remote-Bilder von anderen Websites verwenden und damit fremden Traffic verbrauchen und die Serverlast erhöhen. Um dies zu verhindern, schlagen wir folgende Methoden vor.
Wechseln Sie zur Registerkarte «Server-SEF» und fügen Sie nach:[/justify]
[php]# Mod rewrite on
RewriteEngine On
RewriteBase /[/php]
folgenden Eintrag hinzu:
[php]RewriteOptions MaxRedirects=100
RewriteCond %{HTTP_REFERER} !^http://(www\.)?slaed\.net/ [NC]
RewriteRule \.(jpe?g|gif|bmp|png)$ http://www.slaed.net/templates/default/images/logos/slaed_logo_60x60.png [L][/php]
[justify]Anstelle von: slaed geben Sie den Domainnamen Ihrer Website an.
Anstelle von: net geben Sie die Domain-Zone Ihrer Website an.
Anstelle von: http://www.slaed.net/templates/default/images/logos/slaed_logo_60x60.png geben Sie einen Link zum Logo oder Bild an, das auf der Website angezeigt wird, die Bilder von Ihrer Website verwendet.

[color=orangered][b][i]Zusammenführung von Domain mit www und ohne[/i][/b][/color]
Auf den ersten Blick scheint eine Domain mit dem Präfix www und ohne dasselbe zu sein, aber das ist nicht der Fall. Der Server erkennt sie als zwei verschiedene Domains und in der Regel können darauf zwei völlig unterschiedliche Websites installiert werden. Bei einigen Hostern ist die Zusammenführung zweier Domains von vornherein vorgesehen und erfolgt automatisch, bei einigen gibt es diese Einstellung in der Hosting-Systemsteuerung. Für Hostings, bei denen keine Zusammenführung vorgesehen ist, kann folgende Methode verwendet werden.
Wechseln Sie zur Registerkarte «Server-SEF» und fügen Sie nach:[/justify]
[php]# Mod rewrite on
RewriteEngine On
RewriteBase /[/php]
folgenden Eintrag hinzu:
[php]# Redirect
RewriteCond %{HTTP_HOST} !^www\.slaed\.net [NC]
RewriteRule ^(.*)$ http://www.slaed.net/$1 [R=301,L][/php]
[justify]Anstelle von: slaed geben Sie den Domainnamen Ihrer Website an.
Anstelle von: net geben Sie die Domain-Zone Ihrer Website an.
Damit diese Methode funktioniert, muss der Server des Hosters die Arbeit mit .htaccess unterstützen, Mod Rewrite muss installiert und aktiviert sein.[/justify]

[color=orangered][b][i]Mögliche Regeln und Einstellungen[/i][/b][/color]
[justify]In der folgenden Beschreibung werden mögliche Regeln mit Erläuterungen vorgestellt, die in unserem Fall für «Server-SEF» verwendet werden können, nämlich in der Hauptdatei .htaccess, die sich im Hauptverzeichnis des Systems befindet.[/justify]

[php]# Verbot von Verzeichnisauflistung und -anzeige
Options All -ExecCGI -Indexes -Includes +FollowSymLinks[/php]

[php]# Indexseite der Website
DirectoryIndex index.php[/php]

[php]# Standard-Kodierung der Website
AddDefaultCharset utf-8[/php]

[php]# Weiterleitung bei entsprechendem Serverfehler
ErrorDocument 400 /index.php?error=400
ErrorDocument 401 /index.php?error=401
ErrorDocument 403 /index.php?error=403
ErrorDocument 404 /index.php?error=404
ErrorDocument 500 /index.php?error=500
ErrorDocument 503 /index.php?error=503[/php]

[php]# Sicherheitseinstellungen, relevant für Versionen unter PHP 5.3.0, für PHP 5.4.0 und höher nicht relevant
php_flag register_globals off
php_flag safe_mode on
php_flag magic_quotes_gpc on[/php]

[php]# Verbot der Anzeige von Server-Software-Versionen
ServerSignature Off[/php]

Die oben genannte Regel wird leider nicht von allen Hostern unterstützt. Die unten beschriebenen Einstellungen sind nur verfügbar, wenn mod_rewrite auf dem Server installiert ist.

[php]# Aktivierung von mod_rewrite
RewriteEngine On[/php]

[justify]Das Modul mod_rewrite ist ein Softwaremodul des Apache-Webservers (beachten Sie, dass es unter anderen Webservern nicht ausgeführt wird!). Seine Hauptfunktion ist die Manipulation von URL-Aktionen. Das Modul ist sehr vielseitig und universell; hier werden einige praktische Beispiele gezeigt.[/justify]

[php]# Stammverzeichnis
RewriteBase /[/php]

[php]# Weiterleitung von www auf ohne www
RewriteCond %{HTTP_HOST} ^www\.(.*) [NC]
RewriteRule ^(.*)$ http://%1/$1 [R=301,L][/php]

[php]# Weiterleitung von ohne www auf www
RewriteCond %{HTTP_HOST} ^[^.]+\.[^.]+$
RewriteCond %{HTTPS}s ^on(s)|
RewriteRule ^ http%1://www.%{HTTP_HOST}%{REQUEST_URI} [R=301,L][/php]

[php]# Weiterleitung vom http-Protokoll auf https
RewriteCond %{HTTPS} off
RewriteRule (.*) https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L][/php]

[php]# Weiterleitung von Adressen mit index.php auf ohne index.php
RewriteCond %{THE_REQUEST} ^GET.*index\.php [NC]
RewriteRule (.*?)index\.php/*(.*) /$1$2 [R=301,L][/php]

[php]# Weiterleitung zu neuer Kategorie
RewriteRule ^alte/(.*)$ /neue/$1 [R=301,L][/php]

[php]# Regeln zur Anfrageverarbeitung zum Blockieren häufiger Exploits
RewriteCond %{QUERY_STRING} proc/self/environ [OR]
RewriteCond %{QUERY_STRING} mosConfig_[a-zA-Z_]{1,21}(=|\%3D) [OR]
RewriteCond %{QUERY_STRING} base64_(en|de)code\(.*\) [OR]
RewriteCond %{QUERY_STRING} base64_encode[^(]*\([^)]*\) [OR]
RewriteCond %{QUERY_STRING} (<|%3C)([^s]*s)+cript.*(>|%3E) [NC,OR]
RewriteCond %{QUERY_STRING} GLOBALS(=|\[|\%[0-9A-Z]{0,2}) [OR]
RewriteCond %{QUERY_STRING} _REQUEST(=|\[|\%[0-9A-Z]{0,2})
RewriteRule .* index.php [F][/php]

[php]# Blockierung von MySQL-Injektionen
RewriteCond %{QUERY_STRING} CONCAT.*\( [NC,OR]
RewriteCond %{QUERY_STRING} UNION.*SELECT.*\( [NC,OR]
RewriteCond %{QUERY_STRING} UNION.*ALL.*SELECT [NC]
RewriteRule ^(.*)$ index.php [F,L][/php]

[php]# Blockierung von Datei-Injektionen
RewriteCond %{REQUEST_METHOD} GET
RewriteCond %{QUERY_STRING} [a-zA-Z0-9_]=http:// [OR]
RewriteCond %{QUERY_STRING} [a-zA-Z0-9_]=(\.\.//?)+ [OR]
RewriteCond %{QUERY_STRING} [a-zA-Z0-9_]=/([a-z0-9_.]//?)+ [NC]
RewriteRule .* - [F][/php]

[php]# Weiterleitung für fremde Domains
RewriteCond %{HTTP_HOST} !^slaed\.net$
RewriteRule ^(.*)$ http://slaed.net/$1 [R=301,L][/php]
