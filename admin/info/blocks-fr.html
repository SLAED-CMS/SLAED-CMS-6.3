[justify]La section «Blocs et Bannières» offre la possibilité de construire le site à partir de «briques» appelées «blocs».
Les types de blocs suivants existent :
[li] [b][i]Standard[/i][/b] – placés à des endroits spécifiques du site ;
[li] [b][i]Libres (fly)[/i][/b] – ces blocs peuvent être utilisés n'importe où, dans les modèles ou les modules du système.
La plupart des besoins de fonctionnalité du site sont couverts par les blocs standard, mais dans certains cas, les blocs libres peuvent être utilisés.

[color=green][b]Blocs Standard[/b][/color]
Les blocs standard peuvent être divisés selon les propriétés suivantes :
[li] [b][i]Par type[/i][/b] :
* Fichier – blocs dont les informations sont affichées via des fonctions HTML et PHP définies dans le fichier correspondant.
* HTML – blocs dont les informations sont affichées via des fonctions HTML définies dans le contenu du bloc.
* RSS – blocs qui affichent des informations provenant d'un lien RSS.
* Système – les blocs système incluent : Admin, UserBox.
[li] [b][i]Par accessibilité (qui voit)[/i][/b] : tous les utilisateurs, utilisateurs uniquement, administrateurs uniquement, anonymes uniquement.
[li] [b][i]Par position[/i][/b] : gauche, centre bas, centre haut, droite, bannière supérieure, bannière inférieure.

[color=orangered][b][i]Mise en forme des blocs standard[/i][/b][/color]
La mise en forme des blocs standard est gérée par les modèles de thème : block-center.html, block-all.html, block-right.html et autres modèles avec le préfixe block. (Voir section «Thème de design»).
Vous pouvez créer un design unique pour n'importe quel bloc dans le répertoire blocks/ (block-name.php ; name est le nom du bloc). Pour ce faire :
1. Dans le répertoire templates/thème_design/, créez un fichier modèle nommé block-name.html.
2. Dans le modèle créé, créez un design unique pour le bloc block-name.php.
[b]Exemple :[/b]
Un design unique pour le bloc block-voting.php est requis. Dans ce cas, un fichier modèle est créé dans le répertoire templates/thème_design/ avec le nom block-voting.html. Le système trouvera ce fichier modèle automatiquement et l'utilisera uniquement pour la mise en forme du bloc block-voting.php.

[b][i][color=orangered]Ajout d'un bloc fichier[/color][/i][/b]
Pour ajouter un bloc fichier, les étapes suivantes doivent être effectuées :

[b]1.[/b] Créer le fichier du bloc.
Un fichier pour un bloc fichier peut être créé de deux façons : via l'interface de la section d'administration et via la structure de fichiers du site.

[u]Création d'un fichier via l'interface de la section d'administration[/u]
Allez dans l'onglet «Ajouter un bloc fichier», qui affiche le formulaire pour ajouter un nouveau bloc fichier.
Spécifiez le nom du fichier à créer (par exemple, mysite), en notant que SLAED CMS ajoutera automatiquement le préfixe «block-» au nom du fichier.
Spécifiez le type de fichier à créer.
Cliquez sur «Créer le bloc» et un formulaire se chargera où le code du bloc doit être inséré.
[hr][color=red][b][i]Attention ![/b]
Dans le code du programme du bloc, pour afficher des informations, vous devez utiliser la variable $content au lieu des méthodes standard echo ou print – c'est la seule particularité à considérer. Tout le reste est implémenté en utilisant les méthodes et fonctions PHP et HTML standard. Lors de l'implémentation de blocs, notez que tout code PHP doit commencer par <?php et se terminer par ?>.[/i][/color][hr] Après l'insertion, cliquez sur «Enregistrer» et le fichier correspondant sera créé dans la structure de fichiers du site (par exemple, block-mysite.php comme dans notre exemple).
[hr][color=red][b][i]Attention ![/b]
Lors de la création d'un fichier de bloc fichier, vous devez définir les permissions CHMOD 777 sur le dossier blocks/, puis CHMOD 666 sur le fichier créé.[/i][/color][hr]
[u]Création d'un fichier via la structure de fichiers du site[/u]
Les fichiers PHP pour les blocs fichier sont stockés dans le répertoire «blocks», qui se trouve dans le répertoire racine du site. Dans ce répertoire, vous pouvez créer votre propre fichier PHP, en le nommant obligatoirement au format «block-nombloc.php» (si le format du nom diffère, le fichier ne sera pas visible dans la liste lors de l'ajout d'un bloc).

[b]2.[/b] Établir un lien entre le fichier créé et le bloc.
Pour établir un lien entre le fichier et le bloc fichier, un nouveau bloc doit être ajouté en allant dans l'onglet «Ajouter un bloc».
Le formulaire d'ajout a les champs suivants :
[li] [b][i]Titre[/i][/b] – le titre du bloc est saisi (quel que soit le titre saisi, c'est ce qui est affiché) ;
[li] [b][i]Lien vers le canal RSS[/i][/b] – si un flux RSS spécifique doit être affiché dans le bloc, spécifiez un lien vers celui-ci ou sélectionnez dans la liste standard. Lors de la saisie d'un lien RSS, vous n'avez pas besoin de sélectionner un fichier dans le champ «Nom du fichier» ou de remplir «Contenu». Lors de la création d'un bloc fichier, ce champ reste inchangé.
[li] [b][i]Temps de mise à jour[/i][/b] – à quelle fréquence le flux RSS doit être mis à jour. Lors de la création d'un bloc fichier, ce champ reste inchangé.
[li] [b][i]Nom du fichier[/i][/b] – lors de la création d'un bloc fichier, le fichier précédemment créé est sélectionné.
[li] [b][i]Contenu[/i][/b] – rempli uniquement lors de la création d'un bloc HTML (lors du remplissage du contenu, aucun fichier n'a besoin d'être sélectionné). Lors de la création d'un bloc fichier, ce champ reste inchangé.
[li] [b][i]Position[/i][/b] – la position où le bloc doit être affiché est sélectionnée.
[li] [b][i]Afficher le bloc dans les modules[/i][/b] – la liste des modules dans lesquels le bloc doit être affiché est sélectionnée.
[li] [b][i]Langue[/i][/b] – sélection de la version linguistique dans laquelle le bloc doit être affiché.
[li] [b][i]Activer[/i][/b] – «oui» – le bloc sera affiché, «non» – le bloc ne sera pas affiché.
[li] [b][i]Temps de travail en jours[/i][/b] – vous pouvez spécifier le nombre de jours pendant lesquels le bloc doit être actif. 0 – bloc actif sans restrictions.
[li] [b][i]Après expiration[/i][/b] – vous pouvez choisir ce que le système doit automatiquement faire avec le bloc après l'expiration du temps de travail.
[li] [b][i]Qui verra cela ?[/i][/b] – vous pouvez spécifier pour quelles catégories d'utilisateurs la vue du bloc est disponible.

[color=orangered][b][i]Ajout d'un bloc HTML[/i][/b][/color]
Créer des blocs HTML est très pratique pour afficher des bannières, des liens et d'autres éléments pour lesquels le code HTML est suffisant.
Ajouter un bloc HTML est aussi simple qu'un bloc fichier. Allez dans l'onglet «Ajouter un bloc» et remplissez les champs comme lors de la création d'un bloc fichier, mais au lieu de sélectionner un fichier, remplissez le champ «Contenu». Le contenu doit être rempli avec du code HTML.

[color=orangered][b][i]Ajout d'un bloc RSS[/i][/b][/color]
Allez dans l'onglet «Ajouter un bloc» et remplissez les champs comme lors de la création d'un bloc fichier, mais au lieu de sélectionner un fichier, spécifiez le lien du canal RSS et le temps de mise à jour.

[color=orangered][b][i]Utilisation des blocs directement dans les fichiers HTML du thème de design[/i][/b][/color]
1. Créez un bloc dans le panneau d'administration du système ; il peut s'agir d'un bloc standard ou libre.
2. Activez le bloc et déterminez son N° – numéro dans la liste des blocs.
3. Pour insérer un bloc, par exemple dans le fichier principal : index.html du thème de design, ajoutez simplement le code : {%BLOCKS n,XXX%}

XXX – numéro de votre bloc
n – sans mise en forme
ou
XXX – nom complet du fichier de bloc dans le répertoire : blocks/ par ex. : block-forum.php
s – mise en forme standard

D'autres options sont possibles à votre discrétion.

[u]Description des variables[/u]
{%BLOCKS none,XXX%} ou {%BLOCKS n,XXX%} – Tout bloc système ou bloc libre sans mise en forme, où XXX est soit l'ID du bloc, soit le nom du fichier de bloc.

{%BLOCKS standart,XXX%} ou {%BLOCKS s,XXX%} – Tout bloc système ou bloc libre avec mise en forme de bloc libre, où XXX est soit l'ID du bloc, soit le nom du fichier de bloc.

[u]Création d'une mise en forme personnelle pour un bloc[/u]
Pour créer une mise en forme exclusive pour un bloc, un fichier modèle pour ce bloc doit être créé avec le nom :

block-15.html
15 – est le numéro du bloc dans la liste des blocs. Dans la base de données (table préfixe_blocks, champ bid).
ou
block-name.html
name – est le nom du bloc, nom complet du fichier de bloc dans le répertoire : blocks/

Le fichier de mise en forme du bloc doit être placé dans le répertoire principal du thème de design avec les autres modèles système standard.

[color=green][b]Blocs Libres (fly)[/b][/color]
Un bloc libre (fly) peut être placé n'importe où sur la page du site, pour lequel le code de création de ce bloc libre doit être inséré dans le fichier PHP correspondant (par exemple, dans config/config_header.php). Le code de création de bloc libre ne peut pas être inséré dans les modèles de thème de design (fichiers *.html), car dans ce cas ce code PHP ne sera pas traité. Des informations plus complètes sur l'insertion de blocs dans les modèles de thème de design sont fournies dans la section «Thème de design».
Un bloc libre est décrit dans un script PHP par la fonction : blocks("why", "who"), où blocks est la fonction de création d'un bloc libre avec les paramètres : why et who.
Selon les paramètres why et who, la fonction de création de bloc libre peut :
[li] Imprimer le bloc libre formé vers la sortie standard (afficher le bloc sur la page).
[li] Retourner une chaîne avec le bloc libre formé (sortie du bloc dans une variable pour insertion ultérieure de ce bloc dans un modèle HTML). Dans ce cas, ce bloc libre peut être avec ou sans mise en forme – cela dépend des paramètres why.

[u]Signification des paramètres why :[/u]
[li] [b][i]none[/i][/b] (affiche le corps du bloc sur la page sans mise en forme)
$fly_block_1_1 = blocks("none", 15);
$fly_block_1_2 = blocks("none", "block-menu2.php");
[li] [b][i]standart[/i][/b] (affiche le corps du bloc sur la page avec mise en forme)
$fly_block_2_1 = blocks("standart", 15);
$fly_block_2_2 = blocks("standart", "block-menu2.php");
[li] [b][i]plzreturn[/i][/b] (affiche le corps du bloc dans une variable sans sortie de page et sans mise en forme)
$fly_block_3_1 = blocks("plzreturn", 15);
$fly_block_3_2 = blocks("plzreturn", "block-menu2.php");
[li] [b][i]oreturnform[/i][/b] (corps du bloc dans une variable sans sortie de page, mais avec mise en forme)
$fly_block_4_1 = blocks("oreturnform", 15);
$fly_block_4_1 = blocks("oreturnform", "block-menu2.php");
* 15 – est le bid, numéro du bloc dans la base de données (le numéro du bloc peut être vu dans le panneau d'administration dans la ligne N°).

[u]Signification des paramètres who :[/u]
[li] [b][i]bid[/i][/b] du bloc (numéro du bloc dans la base de données ; table préf_blocks (préf – est le préfixe de table DB), champ bid)
$fly_block_5_1 = blocks("none", 15);
$fly_block_5_2 = blocks("standart", 15);
$fly_block_5_3 = blocks("plzreturn", 15);
$fly_block_5_4 = blocks("oreturnform", 15);
[li] [b][i]block-name.php[/i][/b] (nom du fichier PHP du bloc ; name est le nom du bloc)
$fly_block_6_1 = blocks("none", "block-menu2.php");
$fly_block_6_2 = blocks("standart", "block-menu2.php");
$fly_block_6_3 = blocks("plzreturn", "block-menu2.php");
$fly_block_6_4 = blocks("oreturnform", "block-menu2.php");
Pour utiliser le bloc libre créé, ce bloc doit être actif. Ce bloc ne doit avoir qu'une seule marque – «Bloc libre», sinon ce bloc sera traité comme standard.

Pour créer une mise en forme exclusive pour un bloc libre, un fichier modèle pour ce bloc doit être créé avec le nom :
[li] [b][i]fly-block-15.html[/i][/b] (15 – est le numéro du bloc dans la base de données (table préf_blocks, champ bid)) ;
[li] [b][i]fly-block-name.html[/i][/b] (name – est le nom du bloc).[/justify]
[b]Exemple 1 :[/b]
Un bloc libre avec les paramètres suivants doit être créé :
[li] Sortie du corps du bloc libre sur la page.
[li] Sans mise en forme.
[li] Par numéro de bloc dans la base de données.
[php]blocks("none", 15);[/php]
[li] En utilisant le nom du bloc.
[php]blocks("none", "block-menu2.php");[/php]
[b]Exemple 2 :[/b]
Un bloc libre avec les paramètres suivants doit être créé :
[li] Sortie du corps du bloc libre sur la page.
[li] Avec mise en forme.
[li] Par numéro de bloc dans la base de données.
[php]blocks("standart", 15);[/php]
[li] En utilisant le nom du bloc :
[php]blocks("standart", "block-menu2.php");[/php]
[b]Exemple 3 :[/b]
Un bloc libre avec les paramètres suivants doit être créé :
[li] Sortie du corps du bloc libre dans une variable.
[li] Sans mise en forme.
[li] Par numéro de bloc dans la base de données
[php]global $blockg;
ob_start();
blocks("plzreturn", 15);
$blockg["15"] = ob_get_clean();[/php]
[li] En utilisant le nom du bloc :
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");[/php]
[b]Exemple 4 :[/b]
Un bloc libre avec les paramètres suivants doit être créé :
[li] Sortie du corps du bloc libre dans une variable.
[li] Avec mise en forme.
[li] Par numéro de bloc dans la base de données.
[php]global $blockg;
ob_start();
blocks("oreturnform", 15);
$blockg["15"] = ob_get_clean();[/php]
[li] En utilisant le nom du bloc.
[php]global $blockg;
$blockg["menu2"] = blocks("oreturnform", "block-menu2.php");[/php]
[justify]Pour afficher une variable contenant le corps du bloc libre sur la page, vous devez faire ce qui suit :
Ouvrez le fichier config/config_header.php et insérez le code :[/justify]
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");[/php]
[justify]N'importe où dans le modèle (par exemple, dans templates/votre_thème/index.html) insérez le tableau $blockg[menu2] (notez l'absence de guillemets à l'intérieur des crochets !) Au lieu de $blockg[menu2], le bloc menu2 sera affiché sur la page, dont le code est contenu dans le fichier blocks/block-menu2.php.
Pour une sortie correcte d'un bloc libre sur la page, qui est demandé à la base de données par bid de la table préf_blocks, avec le module rss_info activé (sortie des nouvelles au format RSS), vous devez écrire dans le fichier PHP config/config_header.php :[/justify]
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");
ob_start();
blocks("none", 15);
$blockg["15"] = ob_get_clean();[/php]
[justify]Un bloc libre peut être affiché sur les pages du site sur l'ensemble du site si son code est intégré dans le thème de design, ou il peut être affiché dans un module spécifique si son code est intégré dans le code de ce module.
Un bloc libre ne peut pas être traité par le système comme un bloc standard, mais un bloc standard peut être traité par le système comme un bloc libre. Exemple : le bloc modules avec bid 1 (table slaed_blocks) peut être affiché sur la page à nouveau comme un bloc libre, et alors toutes les restrictions qui s'appliquent au bloc modules s'appliquent à ce bloc (afficher uniquement sur la page principale ou uniquement dans un module ou dans les modules sélectionnés ou dans tous les modules).

[b][i][color=orangered]Modification d'un fichier de bloc[/color][/i][/b]
Pour modifier un fichier de bloc fichier, allez dans l'onglet «Modifier le bloc» et sélectionnez le fichier à modifier.

[b][i][color=orangered]Modification d'un bloc[/color][/i][/b]
Dans l'onglet «Accueil» dans la colonne «Fonctions», cliquez sur (Édition complète) – le formulaire de modification du bloc sera affiché.

[b][i][color=orangered]Modification de la position du bloc[/color][/i][/b]
Dans l'onglet «Accueil» dans la colonne «Position», utilisez les flèches pour changer la position du bloc. La position du bloc sélectionnée est affichée dans la colonne «Position».[/justify]
