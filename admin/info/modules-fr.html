[justify]La section «Modules» est destinée à la gestion des sections (modules) du site.
Pour tous les modules, les fonctions d'édition et d'activation/désactivation sont disponibles. Pour le module «News (Actualités)», les fonctions supplémentaires suivantes sont disponibles :
[li] [b][i]Mise à jour des tables de la base[/i][/b] – mise à jour des tables de la base de données du module ;
[li] [b][i]Suppression des tables de la base[/i][/b] – suppression des tables de la base de données du module ;
[li] [b][i]Ajout des tables de la base[/i][/b] – ajout des tables de la base de données du module (disponible après la suppression) ;
[li] [b][i]Nettoyage des tables de la base[/i][/b] – supprime le contenu des tables de la base de données du module sans modifier la structure (nettoyage des données).

Les fonctions de suppression et d'ajout des tables de la base de données du module sont également disponibles pour le module «Order (Formulaire de commande)».

[b][color=green]Édition des données du module[/color][/b]
L'accès au formulaire d'édition du module s'effectue en cliquant sur le bouton «Éditeur».
Lors de l'édition du module, les éléments suivants peuvent être modifiés :
[li] [b][i]Qui verra[/i][/b] – les droits d'accès au module sont définis : visiteur (tous), utilisateur (autorisés uniquement), administrateur.
[li] [b][i]Pour les utilisateurs du groupe[/i][/b] – l'accès à la consultation du module peut être restreint en fonction de l'appartenance de l'utilisateur à un groupe.
[li] [b][i]Affichage des blocs dans le module[/i][/b] – vous pouvez indiquer à quelles positions les blocs doivent être affichés sur les pages du module.
[li] [b][i]Rendre visible dans le bloc des modules[/i][/b] – activer ou non l'affichage du lien vers le module dans le bloc block-modules.php.

[color=orangered][b][i]Ajout autonome d'un module[/i][/b][/color]
SLAED CMS, étant un système ouvert, permet d'ajouter des modules supplémentaires à la structure du site. Les modules sont stockés dans le répertoire : modules/ (les dossiers des nouveaux modules doivent être copiés dans le répertoire : modules/).
Avec des modules personnalisés, la fonctionnalité du système peut être considérablement étendue. Si un module supplémentaire contient un fichier de table dans le dossier du module, par exemple : modules/news/sql/table.sql, alors après avoir ajouté le dossier de ce module dans le dossier : modules/, dans la section d'administration «Modules», vous devez lancer le mécanisme de création des tables du module correspondant en cliquant sur la valeur (Ajout des tables de la base).[/justify]
