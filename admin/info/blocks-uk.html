[justify]Розділ «Блоки та банери» надає можливість будувати сайт із «цеглинок», які називаються «блоки».
Існують наступні види блоків:
[li] [b][i]Стандартні[/i][/b] – розміщуються у визначених місцях сайту;
[li] [b][i]Вільні (fly)[/i][/b] – дані блоки можна використовувати в будь-яких місцях, шаблонах або модулях системи.
Більшість потреб щодо функціональності сайту покриваються за допомогою стандартних блоків, але в деяких випадках можна застосовувати вільні блоки.

[color=green][b]Стандартні блоки[/b][/color]
Стандартні блоки можна розділити за наступними властивостями:
[li] [b][i]За типом[/i][/b]:
* Файлові – блоки, інформація в яких виводиться за допомогою html та php функцій, заданих у відповідному файлі.
* HTML – блоки, інформація в яких виводиться за допомогою html функцій, заданих у вмісті блоку.
* RSS – блоки, в яких виводиться інформація, взята за RSS посиланням.
* Системні – до системних блоків належать: Admin, UserBox.
[li] [b][i]За доступністю (хто бачить)[/i][/b]: всі користувачі, тільки користувачі, тільки адміністратори, тільки аноніми.
[li] [b][i]За позицією[/i][/b]: зліва, по центру внизу, по центру вгорі, справа, верхній банер, нижній банер.

[color=orangered][b][i]Оформлення стандартних блоків[/i][/b][/color]
За оформлення стандартних блоків відповідають шаблони тем: block-center.html, block-all.html, block-right.html та інші шаблони, що мають у назві префікс block. (Див. розділ «Тема оформлення»).
Можна створити унікальне оформлення для будь-якого блоку, що знаходиться в директорії blocks/ (block-name.php; name - це ім'я блоку). Для цього:
1. У директорії templates/тема_оформлення/ необхідно створити файл шаблону з ім'ям block-name.html.
2. У створеному шаблоні необхідно зробити унікальне оформлення для блоку block-name.php.
[b]Приклад:[/b]
необхідно зробити унікальне оформлення для блоку block-voting.php. У цьому випадку створюється файл шаблону в директорії templates/тема_оформлення/ з назвою block-voting.html. Система знайде цей файл шаблону автоматично, а потім буде використовувати його тільки для оформлення блоку block-voting.php.

[b][i][color=orangered]Додавання файлового блоку[/color][/i][/b]
Для додавання файлового блоку необхідно виконати наступні дії:

[b]1.[/b] Створити файл блоку.
Створити файл для файлового блоку можна двома способами: через інтерфейс адміністраторського розділу та через файлову структуру сайту.

[u]Створення файлу через інтерфейс адміністраторського розділу[/u]
Перейдіть у вкладку «Додати файловий блок», яка відображає форму додавання нового файлового блоку.
Вкажіть ім'я створюваного файлу (наприклад, mysite), враховуючи, що SLAED CMS сама підставить до імені файлу префікс «block-».
Вкажіть тип створюваного файлу.
Натисніть кнопку «Створити блок», після чого завантажиться форма, в яку необхідно вставити код блоку.
[hr][color=red][b][i]Увага![/b]
У тексті програмного коду блоку, для виводу інформації необхідно використовувати змінну $content замість стандартних методів echo або print, це єдина відмінна особливість, яку необхідно враховувати. Все інше реалізується за допомогою стандартних методів та функцій PHP та HTML. При реалізації блоків враховуйте, будь-який PHP код повинен починатися з <?php і закінчуватися ?>.[/i][/color][hr] Після вставки натисніть кнопку «Зберегти» і у файловій структурі сайту буде створено відповідний файл (наприклад, block-mysite.php, як у нашому прикладі).
[hr][color=red][b][i]Увага![/b]
При створенні файлу файлового блоку необхідно встановити права CHMOD 777 на папку blocks/, а в подальшому CHMOD 666 на створений файл.[/i][/color][hr]
[u]Створення файлу через файлову структуру сайту[/u]
Php файли для файлових блоків зберігаються в директорії «blocks», яка знаходиться в кореневій директорії сайту. У даній директорії можна створити свій php файл, обов'язково назвавши його у форматі «block-ім'я_блоку.php» (у випадку, якщо формат назви відрізняється, то при додаванні блоку файл не буде видно у списку).

[b]2.[/b] Встановити зв'язок між створеним файлом та блоком.
Для того щоб встановити зв'язок між файлом та файловим блоком, необхідно додати новий блок, перейшовши у вкладку «Додати блок».
Форма додавання має наступні поля:
[li] [b][i]Заголовок[/i][/b] – вводиться заголовок блоку (який заголовок введено - такий і відображається);
[li] [b][i]Посилання на канал RSS[/i][/b] – у випадку, якщо необхідно, щоб у блоці виводилася певна RSS стрічка – вкажіть посилання на неї або виберіть зі стандартного списку. У випадку введення посилання на RSS не потрібно вибирати файл у полі «Ім'я файлу» та заповнювати «Вміст». При створенні файлового блоку дане поле залишається без змін.
[li] [b][i]Час оновлення[/i][/b] – з якою частотою повинна оновлюватися RSS стрічка. При створенні файлового блоку дане поле залишається без змін.
[li] [b][i]Ім'я файлу[/i][/b] – при створенні файлового блоку вибирається попередньо створений файл.
[li] [b][i]Вміст[/i][/b] – заповнюється тільки у випадку створення HTML блоку (при заповненні вмісту не потрібно вибирати файл). При створенні файлового блоку дане поле залишається без змін.
[li] [b][i]Позиція[/i][/b] – вибирається позиція, на якій повинен виводитися блок.
[li] [b][i]Відображати блок у модулях[/i][/b] – вибирається перелік модулів, в яких необхідно відображати блок.
[li] [b][i]Мова[/i][/b] – вибір мовної версії, в якій необхідно відображати блок.
[li] [b][i]Активувати[/i][/b] – «так» - блок буде показуватися, «ні» - блок не буде показуватися.
[li] [b][i]Час роботи в днях[/i][/b] – можна вказати кількість днів, протягом яких блок повинен бути активним. 0 – блок активний без обмежень.
[li] [b][i]Після закінчення[/i][/b] – можна вибрати, що система повинна автоматично зробити з блоком після закінчення часу роботи.
[li] [b][i]Хто це буде бачити?[/i][/b] – можна вказати, для яких категорій користувачів доступний перегляд блоку.

[color=orangered][b][i]Додавання HTML блоку[/i][/b][/color]
Створювати HTML-блоки дуже зручно для виводу банерів, посилань та інших елементів, для виводу яких достатньо використання HTML коду.
Додати HTML-блок так само просто, як і файловий, для цього необхідно перейти у вкладку «Додати блок» і заповнити поля, що і при створенні файлового блоку, але замість вибору файлу заповнити поле «Вміст». Заповнювати вміст необхідно html-кодом.

[color=orangered][b][i]Додавання RSS-блоку[/i][/b][/color]
Перейдіть у вкладку «Додати блок» і заповніть поля, що і при створенні файлового блоку, але замість вибору файлу вкажіть посилання на канал RSS та час оновлення.

[color=orangered][b][i]Використання блоків безпосередньо в html файлах теми оформлення[/i][/b][/color]
1. Створіть блок у панелі адміністратора системи, ним може бути стандартний або вільний блок.
2. Активуйте блок і в списку блоків визначте його № - номер
3. Для вставки блоку, наприклад в основний файл: index.html теми оформлення, достатньо додати ділянку коду: {%BLOCKS n,ХХХ%}

ХХХ - номер вашого блоку
n - без оформлення
або
ХХХ - повна назва файлу блоку в директорії: blocks/ наприклад: block-forum.php
s - стандартне оформлення

Можливі й інші варіанти, на ваш розсуд.

[u]Опис змінних[/u]
{%BLOCKS none,ХХХ%} або {%BLOCKS n,ХХХ%} - Довільний блок системи або вільний блок без оформлення, де ХХХ - це або ID блоку, або назва файлу блоку.

{%BLOCKS standart,ХХХ%} або {%BLOCKS s,ХХХ%} - Довільний блок системи або вільний блок з оформленням вільного блоку, де ХХХ - це або ID блоку, або назва файлу блоку.

[u]Створення персонального оформлення для блоку[/u]
Для формування ексклюзивного оформлення для блоку необхідно створити файл шаблону цього блоку з ім'ям.

block-15.html
15 - це номер блоку у списку блоків. У базі даних (таблиця префікс_blocks, поле bid).
або
block-name.html
name - це ім'я блоку, повна назва файлу блоку в директорії: blocks/

Файл оформлення блоку слід розміщувати в основній директорії теми оформлення разом з іншими стандартними шаблонами системи.

[color=green][b]Вільні (fly) блоки[/b][/color]
Вільний блок (fly) можна розмістити в будь-якому місці сторінки сайту, для чого потрібно вставити код формування цього вільного блоку у відповідний php-файл (в config/config_header.php, наприклад). У шаблони тем оформлення (файли *.html) не можна вставляти код формування вільного блоку, оскільки в цьому випадку цей php-код не буде оброблятися. Більш повна інформація про вставку блоків у шаблони тем оформлення наведена в розділі «Тема оформлення».
Вільний блок описується в php-скрипті функцією: blocks("why", "who"), де blocks - функція створення вільного блоку з параметрами: why та who.
Залежно від параметрів why та who функція створення вільного блоку може:
[li] Друкувати на стандартний вивід сформований вільний блок (виводити блок на сторінку).
[li] Повертати рядок зі сформованим вільним блоком (вивід блоку в змінну для подальшої вставки цього блоку в html-шаблон). При цьому цей вільний блок може бути з оформленням або без нього – це залежить від параметрів why.

[u]Значення параметрів why:[/u]
[li] [b][i]none[/i][/b] (виводить тіло блоку на сторінку без оформлення)
$fly_block_1_1 = blocks("none", 15);
$fly_block_1_2 = blocks("none", "block-menu2.php");
[li] [b][i]standart[/i][/b] (виводить тіло блоку на сторінку з оформленням)
$fly_block_2_1 = blocks("standart", 15);
$fly_block_2_2 = blocks("standart", "block-menu2.php");
[li] [b][i]plzreturn[/i][/b] (виводить тіло блоку в змінну без виводу на сторінку і без оформлення)
$fly_block_3_1 = blocks("plzreturn", 15);
$fly_block_3_2 = blocks("plzreturn", "block-menu2.php");
[li] [b][i]oreturnform[/i][/b] (тіло блоку в змінну без виводу на сторінку, але з оформленням)
$fly_block_4_1 = blocks("oreturnform", 15);
$fly_block_4_1 = blocks("oreturnform", "block-menu2.php");
* 15 – це bid, номер блоку в базі даних (Номер блоку можна подивитися в панелі адміністратора в рядку №).

[u]Значення параметрів who:[/u]
[li] [b][i]bid[/i][/b] блоку (номер блоку в базі даних; таблиця преф_blocks (преф – це префікс таблиць БД), поле bid)
$fly_block_5_1 = blocks("none", 15);
$fly_block_5_2 = blocks("standart", 15);
$fly_block_5_3 = blocks("plzreturn", 15);
$fly_block_5_4 = blocks("oreturnform", 15);
[li] [b][i]block-name.php[/i][/b] (ім'я php-файлу блоку; name - це ім'я блоку)
$fly_block_6_1 = blocks("none", "block-menu2.php");
$fly_block_6_2 = blocks("standart", "block-menu2.php");
$fly_block_6_3 = blocks("plzreturn", "block-menu2.php");
$fly_block_6_4 = blocks("oreturnform", "block-menu2.php");
Щоб користуватися створеним вільним блоком необхідно, щоб цей блок був активним. На цьому блоці повинна бути тільки одна позначка - «Вільний блок», в іншому випадку цей блок буде стандартним.

Для формування ексклюзивного оформлення для вільного блоку необхідно створити файл шаблону цього блоку з ім'ям:
[li] [b][i]fly-block-15.html[/i][/b] (15 - це номер блоку в базі даних (таблиця преф_blocks, поле bid));
[li] [b][i]fly-block-name.html[/i][/b] (name - це ім'я блоку).[/justify]
[b]Приклад 1:[/b]
Необхідно створити вільний блок з параметрами:
[li] Вивід тіла вільного блоку на сторінку.
[li] Без оформлення.
[li] За номером блоку в базі даних.
[php]blocks("none", 15);[/php]
[li] З використанням імені блоку.
[php]blocks("none", "block-menu2.php");[/php]
[b]Приклад 2:[/b]
Необхідно створити вільний блок з параметрами:
[li] Вивід тіла вільного блоку на сторінку.
[li] З оформленням.
[li] За номером блоку в базі даних.
[php]blocks("standart", 15);[/php]
[li] З використанням імені блоку:
[php]blocks("standart", "block-menu2.php");[/php]
[b]Приклад 3:[/b]
Необхідно створити вільний блок з параметрами:
[li] Вивід тіла вільного блоку в змінну.
[li] Без оформлення.
[li] За номером блоку в базі даних
[php]global $blockg;
ob_start();
blocks("plzreturn", 15);
$blockg["15"] = ob_get_clean();[/php]
[li] З використанням імені блоку:
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");[/php]
[b]Приклад 4:[/b]
Необхідно створити вільний блок з параметрами:
[li] Вивід тіла вільного блоку в змінну.
[li] З оформленням.
[li] За номером блоку в базі даних.
[php]global $blockg;
ob_start();
blocks("oreturnform", 15);
$blockg["15"] = ob_get_clean();[/php]
[li] З використанням імені блоку.
[php]global $blockg;
$blockg["menu2"] = blocks("oreturnform", "block-menu2.php");[/php]
[justify]Для виводу на сторінку змінної, що містить у собі тіло вільного блоку, необхідно зробити наступне:
Відкриваємо файл config/config_header.php і в нього вставляємо код:[/justify]
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");[/php]
[justify]У будь-яке місце шаблону (в templates/ваша_тема/index.html, наприклад) вставляємо масив $blockg[menu2] (зверніть увагу на відсутність лапок всередині квадратних дужок!) На сторінку замість $blockg[menu2] буде виведено блок menu2, код якого міститься у файлі blocks/block-menu2.php.
Для коректного виводу на сторінку вільного блоку, який з бази даних запитується за bid з таблиці преф_blocks, при включеному модулі rss_info (вивід новин у форматі RSS) необхідно в php-файл config/config_header.php записати:[/justify]
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");
ob_start();
blocks("none", 15);
$blockg["15"] = ob_get_clean();[/php]
[justify]Вільний блок може виводитися на сторінки сайту на всьому сайті, якщо його код вбудований у тему оформлення, або він може виводитися в якомусь певному модулі, якщо його код вбудований в код цього модуля.
Вільний блок не може бути оброблений системою як стандартний блок, але стандартний блок може бути оброблений системою як вільний блок. Приклад: блок modules, що має bid 1 (таблиця slaed_blocks), можна вивести на сторінку ще раз як вільний блок, і тоді на цей блок накладаються всі ті обмеження, які накладені на блок modules (показувати тільки на головній сторінці сайту або тільки в одному модулі або у вибраних модулях або у всіх модулях).

[b][i][color=orangered]Зміна файлу блоку[/color][/i][/b]
Для редагування файлу файлового блоку перейдіть у вкладку «Редагувати блок» і виберіть потрібний для редагування файл.

[b][i][color=orangered]Зміна блоку[/color][/i][/b]
У вкладці «Головна» в стовпці «Функції» перейдіть за значенням (Повне редагування) – відобразиться форма редагування блоку.

[b][i][color=orangered]Зміна положення блоку[/color][/i][/b]
У вкладці «Головна» в стовпці «Положення» за допомогою стрілок змінюйте положення блоку. Вибрана позиція блоку виводиться в стовпці «Позиція».[/justify]
