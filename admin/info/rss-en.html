[justify]RSS is an international format specially created for transmitting data from one website to another. In addition, RSS can be used to read news with special programs – news aggregators – and thus quickly learn about website updates.
In the RSS Channels section, you can adjust the settings of the website's RSS channels. There are two ways to use an RSS channel.
1. Direct access. The export file index.php?go=rss is located in the main directory of the website. Link to RSS channel: http://site_adress/index.php?go=rss
2. Through the rss_info module, where users or website visitors can choose the channel they are interested in or view channels from other websites.

[b][color=green]Creating RSS channels[/color][/b]
RSS channels are created in the "RSS Channels" tab. There are two types of channels: standard and external.
Standard channels are website channels that will be added to the website header code for viewing information by other websites, browsers, or other corresponding programs. External channels are channels from other websites that will be added to the module's channel list for direct viewing by website visitors.

For each RSS channel, you can set the following information:
[li] [b][i]Title[/i][/b] – the name of the RSS channel being added is entered.
[li] [b][i]Address[/i][/b] – the URL address of the channel.
[li] [b][i]Usage[/i][/b]:
* Standard channel – a website channel. The file index.php?go=rss, located in the main directory of the website, is responsible for the channel.
* External channel – you can add RSS channels from other websites (for example, [url=https://www.slaed.net/index.php?go=rss&name=news]https://www.slaed.net/index.php?go=rss&name=news[/url] – link to the SLAED news channel).

To add a new RSS channel, click the plus sign next to the last added channel.
To delete empty RSS channel fields, click the plus sign next to the field preceding the empty fields.
To delete a filled and previously saved RSS channel, you need to enter the value 0 in the channel form fields.
Note that all changes will take effect after clicking the "Save changes" button.

[b][color=green]"Configurations" tab[/color][/b]
Allows you to set the section settings. Among the main settings are:
[li] [b][i]Minimum/maximum default count[/i][/b] – how many entries will be transmitted via the RSS channel;
[li] [b][i]News channel display template[/i][/b] – in this field you can set the rules for displaying entries on the website transmitted via the RSS channel. Note that there are special variables:
* [title] – News title;
* [date] – News publication date;
* [guid] – Link to the news item;
* [description] – News content.
[li] [b][i]Activate channel output on website pages[/i][/b] – this option is responsible for displaying the RSS channel link. This link is displayed using standard browser tools (if supported).
[li] [b][i]Activate RSS channel viewing?[/i][/b] – this option means: can users view the website's RSS channels in the "RSS Channels (RSS info)" section and on the main page of their profile.[/justify]
