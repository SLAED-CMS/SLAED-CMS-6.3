[justify]Der Bereich "Weiterleitungen" dient zur Anzeige der Statistiken von Weiterleitungen der Benutzer und Suchmaschinen-Bots von anderen Websites. Er ermöglicht beispielsweise die Bewertung der Effektivität einer Linksetzung auf einer bestimmten Ressource.

[color=green][b]Tab "Hauptseite"[/b][/color]
Die Weiterleitungsstatistik wird als Tabelle dargestellt, die folgende Informationen enthält:
[li] [b][i]Nickname[/i][/b] – wenn der weitergeleitete Benutzer auf der Website registriert ist, wird sein Nickname angezeigt. Wenn nicht registriert, dann die IP-Adresse. Wenn die Weiterleitung von einem Suchmaschinen-Bot durchgeführt wurde, wird der Name der Suchmaschine angezeigt.
[li] [b][i]IP-Adresse[/i][/b] – die IP-Adresse des weitergeleiteten Benutzers wird angezeigt.
[li] [b][i]Weiterleitungsadressen[/i][/b] – von welcher Seite die Weiterleitung auf die Website erfolgte.
[li] [b][i]Eingangsadressen[/i][/b] – auf welche konkrete Seite die Weiterleitung erfolgte.
[li] [b][i]Datum[/i][/b] – Datum und Uhrzeit der Weiterleitung.

[b][i][color=orangered]Sortierungen und Gruppierungen in der Weiterleitungstabelle[/color][/i][/b]
Zur Gruppierung der Weiterleitungen nach verschiedenen Kriterien verwenden Sie die vor der Tabelle aufgeführten Kriterien.
Durch Klicken auf den Namen der gewünschten Spalte können die Daten in der Spalte auch alphabetisch sortiert werden.

[color=green][b]Tab "Konfiguration"[/b][/color]

[li] [b][i]Anzahl der Einträge pro Administratorseite[/i][/b] – die angegebene Anzahl von Weiterleitungen wird auf einer Seite in der Weiterleitungstabelle im Tab "Hauptseite" angezeigt.
[li] [b][i]Maximale Anzahl der Seitennummern für Administratoren[/i][/b] – wenn die Anzahl der Seiten mit Weiterleitungen den angegebenen Wert überschreitet, wird nach der Seitennummer, die der angegebenen Zahl entspricht, eine Ellipse angezeigt.
[li] [b][i]Speicherdauer der Weiterleitungen von anderen Websites, in Tagen[/i][/b] – nach Ablauf dieser Zeit werden die Weiterleitungsinformationen automatisch gelöscht.
[li] [b][i]Weiterleitungsstatistik von anderen Websites aktivieren?[/i][/b] – ob Weiterleitungen gespeichert werden oder nicht.

[color=green][b]Tab "Löschen"[/b][/color]
[hr][color=red][b][i]Achtung![/b]
Ein Klick auf diesen Tab löscht die Weiterleitungsstatistik.[/i][/color][/justify]
