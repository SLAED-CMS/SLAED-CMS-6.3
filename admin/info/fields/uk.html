[justify]За допомогою цього розділу можна самостійно та у простій формі розширити можливості інформаційної наповненості для наступних модулів: Профіль (профіль користувача), Зміст, Форум, Допомога, Новини.
[hr][color=blue][b]Зверніть увагу![/color][/b]
Додаткові поля для модуля форум працюють тільки в системному форумі (у форумі SLAED). В інтегрованих форумах (наприклад, phpBB) додаткові поля не відображаються.[hr]
Для додавання додаткового поля до потрібного модуля перейдіть на вкладку, що відповідає назві модуля. Можна додати поля наступних типів:
[li] Один рядок;
[li] Текстове поле;
[li] Список з вибором;
[li] Дата: рік-місяць-число години:хвилини (наприклад, 01-11-1900 12:34);
[li] Дата: рік-місяць-число (наприклад, 01-11-1900).

Форма додавання додаткового поля містить:
[li] [b][i]Назва[/i][/b] – вкажіть у цьому полі назву додаткового поля.
[li] [b][i]Зміст[/i][/b] – можна вказати зміст поля, який буде виводитися в ньому за замовчуванням. Для поля «список з вибором» елементи списку записуються через кому без пробілу.
[li] [b][i]Тип поля[/i][/b] – виберіть необхідний тип поля.
[li] [b][i]Використання[/i][/b] – виберіть, чи є поле обов'язковим чи ні.
Для додавання нового додаткового поля натисніть на знак плюс біля останнього доданого поля.
Для видалення незаповненого нового поля – натисніть на знак плюс біля поля, що стоїть перед незаповненим новим полем.
Для видалення заповненого та раніше збереженого поля необхідно у поля «Назва» та «Зміст» записати значення 0.
Врахуйте, що всі зміни набудуть чинності після натискання кнопки «Зберегти зміни».[/justify]
