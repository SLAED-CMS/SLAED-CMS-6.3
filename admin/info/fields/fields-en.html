[justify]Using this section, you can independently and easily extend the information capabilities for the following modules: Profile (user profile), Content, Forum, Help, News.
[hr][color=blue][b]Please note![/color][/b]
Additional fields for the forum module only work in the system forum (SLAED forum). In integrated forums (e.g., phpBB), additional fields are not displayed.[hr]
To add an additional field to the desired module, go to the tab corresponding to the module name. The following field types can be added:
[li] Single line;
[li] Text field;
[li] Selection list;
[li] Date: year-month-day hours:minutes (e.g., 01-11-1900 12:34);
[li] Date: year-month-day (e.g., 01-11-1900).

The form for adding an additional field contains:
[li] [b][i]Name[/i][/b] – specify the name of the additional field in this field.
[li] [b][i]Content[/i][/b] – you can specify the content of the field that will be displayed in it by default. For the «selection list» field, list items are entered separated by commas without spaces.
[li] [b][i]Field type[/i][/b] – select the required field type.
[li] [b][i]Usage[/i][/b] – select whether the field is mandatory or not.
To add a new additional field, click the plus sign next to the last added field.
To delete an unfilled new field, click the plus sign next to the field before the unfilled new field.
To delete a filled and previously saved field, you need to enter the value 0 in the «Name» and «Content» fields.
Note that all changes will take effect after the «Save changes» button is pressed.[/justify]
