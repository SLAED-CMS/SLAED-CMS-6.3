[justify]À l'aide de cette section, vous pouvez de manière autonome et simple étendre les possibilités de contenu informationnel pour les modules suivants : Profil (profil utilisateur), Contenu, Forum, Aide, Actualités.
[hr][color=blue][b]Veuillez noter ![/color][/b]
Les champs supplémentaires pour le module forum ne fonctionnent que dans le forum système (forum SLAED). Dans les forums intégrés (par exemple, phpBB), les champs supplémentaires ne sont pas affichés.[hr]
Pour ajouter un champ supplémentaire au module souhaité, accédez à l'onglet correspondant au nom du module. Les types de champs suivants peuvent être ajoutés :
[li] Ligne unique ;
[li] Champ de texte ;
[li] Liste de sélection ;
[li] Date : année-mois-jour heures:minutes (par exemple, 01-11-1900 12:34) ;
[li] Date : année-mois-jour (par exemple, 01-11-1900).

Le formulaire d'ajout d'un champ supplémentaire contient :
[li] [b][i]Nom[/i][/b] – indiquez dans ce champ le nom du champ supplémentaire.
[li] [b][i]Contenu[/i][/b] – vous pouvez indiquer le contenu du champ qui sera affiché par défaut. Pour le champ «liste de sélection», les éléments de la liste sont saisis séparés par des virgules sans espaces.
[li] [b][i]Type de champ[/i][/b] – sélectionnez le type de champ requis.
[li] [b][i]Utilisation[/i][/b] – choisissez si le champ est obligatoire ou non.
Pour ajouter un nouveau champ supplémentaire, cliquez sur le signe plus à côté du dernier champ ajouté.
Pour supprimer un nouveau champ non rempli, cliquez sur le signe plus à côté du champ précédant le nouveau champ non rempli.
Pour supprimer un champ rempli et précédemment enregistré, vous devez saisir la valeur 0 dans les champs «Nom» et «Contenu».
Notez que toutes les modifications prendront effet après avoir cliqué sur le bouton «Enregistrer les modifications».[/justify]
