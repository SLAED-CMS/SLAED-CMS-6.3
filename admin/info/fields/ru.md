# Дополнительные поля

Модуль **«Дополнительные поля»** позволяет администратору гибко настраивать и расширять информационные формы ввода данных на сайте без необходимости ручного редактирования исходного кода `PHP`/`HTML` шаблонов.

Вы можете добавить собственные кастомные поля (до 10 штук на каждый модуль) для сбора специфической информации от пользователей или дополнения контента.

---

## Вкладки модулей

Возможность добавления полей реализована изолированно для 6 различных подсистем сайта (каждая вынесена в отдельную вкладку):

* **Профиль** — поля, которые пользователи будут заполнять при регистрации или изменении своих данных (например: номер телефона, ссылка на соц. сети).
* **Содержание** — при создании и публикации статей.
* **Форум** — привязка дополнительных атрибутов к темам форума.
* **Помощь** — расширение раздела Вопросы и ответы (F.A.Q).
* **Новости** — дополнительные данные при публикации новостей.
* **Форма заказа** — расширение параметров формы онлайн-заказа (например: удобное время доставки).

> [!WARNING]
> Дополнительные поля для вкладки **Форум** работают и выводятся только во внутреннем (системном) форуме SLAED. Если вы используете сторонние интегрированные форумы (например, XenForo, vBulletin, phpBB), данные кастомные поля в них отображаться не будут.

---

## Настройка поля

Чтобы добавить новое поле, нажмите на значок `+ Дополнительное поле: {номер}` на нужной вкладке. Откроется форма настройки, состоящая из 4 параметров:

| Параметр | Описание |
|---|---|
| **Название** | Публичное имя (label) поля, которое будет отображаться пользователю в формах сайта. |
| **Содержание** | Данные по умолчанию. Имеет особую роль: если вы выбрали тип «Список с выбором», именно в это поле нужно записать все варианты ответа, **обязательно через запятую вплотную и без пробелов** (Например: `Красный,Синий,Зеленый`). |
| **Тип** | Формат элемента, который увидит пользователь (см. типы ниже). |
| **Использование** | Определяет статус обязательности. `Обязательно к заполнению` не позволит пользователю отправить форму, пока он не укажет данные; `Не обязательно к заполнению` допускает пустое значение. |

### Поддерживаемые типы (Тип)
1. **Одна строка** — стандартный `<input type="text">` для ввода коротких фраз.
2. **Текстовое поле** — многострочный `<textarea>` для ввода объемного текста.
3. **Список с выбором** — выпадающий список `<select>`. Требует указания вариантов в поле `Содержание` через запятую.
4. **Дата: год-месяц-число часы:минуты** — поле с маской ввода точного времени (например: `2024-11-01 12:30`).
5. **Дата: год-месяц-число** — поле с маской ввода только даты (например: `2024-11-01`).

---

## Управление (Удаление полей)

Система хранит поля в виде строки в файле конфигурации. Если вы хотите **навсегда удалить** ранее созданное и сохраненное поле:

> [!TIP]
> Откройте настройки этого поля и запишите ровно один символ **`0`** (цифра ноль) в оба поля: «Название» и «Содержание». Затем нажмите кнопку `Сохранить изменения`. При следующем сохранении система обработает нуль как команду на удаление, и поле полностью пропадет из базы и с сайта.
