# Дополнительные поля

Раздел **«Дополнительные поля»** добавляет к формам сайта собственные поля без правки кода и шаблонов. Он доступен только главному администратору.

---

## Вкладки

У каждой вкладки свой набор полей, не больше 256 на вкладку:

* **Профиль** — поля профиля пользователя.
* **Форум** — поля тем форума.
* **По одной вкладке на каждый тип материалов** — поля материалов этого типа, например «Новости» или «Файлы».

Кнопка «Сохранить изменения» записывает все вкладки сразу. Если хоть одно определение неверно, не сохраняется ничего: форма остаётся с набранными значениями, а сверху появляется первая ошибка с указанием вкладки и поля.

> [!NOTE]
> Определения профиля и форума хранятся в `config/fields.php`, определения типа материалов — в настройках самого типа. Если тип за это время изменили в другом окне, его запись будет отклонена с сообщением об этом.

> [!WARNING]
> Пока не выполнено обновление данных 8.0, раздел закрыт для записи и вместо формы показывает предупреждение.

---

## Настройка поля

Каждое поле — блок во всю ширину: в его шапке имя поля, под ней строки с подписью слева и значением справа. Значок «+» в шапке блока открывает следующий пустой блок. Поля блока:

| Поле | Что задаёт |
|---|---|
| **Техническое имя** | Имя, под которым хранятся значения: строчная латинская буква, затем буквы, цифры или подчёркивание, не длиннее 32 символов. У сохранённого поля не меняется. |
| **Заголовок** | Подпись поля в форме. Значение, начинающееся с подчёркивания, читается как языковая константа. |
| **Описание** | Подсказка под полем, до 1000 символов. |
| **Тип** | Вид поля, см. таблицу ниже. У сохранённого поля не меняется. |
| **Значение по умолчанию** | Значение нового поля. Оно должно проходить те же проверки, что и ввод пользователя. Для переключателя это `0` или `1`, для нескольких значений — ключи вариантов через запятую. |
| **Нижняя и верхняя граница** | Смысл зависит от типа, см. таблицу ниже. Обе границы включаются в допустимый диапазон. |
| **Знаков после точки** | Только для десятичного числа, обязательно, от 1 до 18. |
| **Варианты** | Только для списка: ключ, заголовок, позиция и признак активности. Всего до 256 вариантов. Форма каждый раз показывает три пустые строки для новых. Ключ сохранённого варианта не меняется, и удалить такой вариант нельзя: его можно только выключить. |
| **Обязательно к заполнению** | Форма не примет пустое значение. Отключённое поле обязательным быть не может. |
| **Разрешить несколько значений** | Только для списка. |
| **Активировать?** | Отключённое поле скрыто, но его значения сохраняются. |
| **Позиция** | Порядок полей в форме, целое число. |
| **Удалить** | Только у сохранённого поля. Поле исчезает из формы, а его значения теряются при следующем сохранении владельца этих значений. |

### Типы и границы

| Тип | Что означают границы |
|---|---|
| **Одна строка** | Число символов, не больше 4096 |
| **Текстовое поле** | Число символов, не больше 262144 |
| **Список с выбором** | Число выбранных вариантов, не больше 64, и только при нескольких значениях |
| **Переключатель: да или нет** | Границ нет |
| **Целое число** | Само значение |
| **Десятичное число** | Само значение |
| **Дата: год-месяц-число** | Сама дата |
| **Дата: год-месяц-число часы:минуты** | Сама дата и время |
| **E-Mail** | Число символов, не больше 254 |
| **Ссылка** | Число символов, не больше 2048 |
