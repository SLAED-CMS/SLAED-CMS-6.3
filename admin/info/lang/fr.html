[justify]Cette section est destinée à la gestion des textes de service du site, affichés dans tous les modules du site dans toutes les versions linguistiques.
[b][color=green]Gestion des textes[/color][/b]
La gestion des textes des modules linguistiques s'effectue dans l'onglet «Principal», qui contient une liste des modules dans lesquels les textes de service pour les versions linguistiques peuvent être définis.
Explications du tableau affiché dans l'onglet «Principal» :
[li] [b][i]Module[/i][/b] – affiche le nom du module système.
[li] [b][i]Qui voit[/i][/b] – affiche si les informations de ce module sont visibles par tous les visiteurs du site ou uniquement par les utilisateurs (visiteurs autorisés).
[li] [b][i]Statut[/i][/b] – si le module est actuellement activé (Activé), c'est-à-dire affiché sur le site, ou non (Désactivé).

L'administrateur peut effectuer les actions suivantes avec chaque entrée (accès aux actions dans la colonne «Fonctions») :
[li] [b][i]Administrateur[/i][/b] – accès à l'édition des mots de service utilisés dans la section d'administration, ou absence de valeur indiquant que la partie administrative du module ne contient pas de mots de service.
[li] [b][i]Module[/i][/b] – accès à l'édition des mots de service utilisés dans la partie publique du système, ou absence de valeur indiquant que la partie utilisateur du module ne contient pas de mots de service.

L'accès au formulaire d'édition des mots de service pour les versions linguistiques s'effectue en cliquant sur la valeur dans la colonne correspondante (Administrateur ou Module).

[hr][b][color=blue]Veuillez noter ![/color][/b]
Pour l'édition des constantes linguistiques principales du panneau d'administration ainsi que des parties utilisateur, les paramètres PHP Max input vars : 4000 (nombre maximum autorisé de variables entrantes) et plus sont requis. Ce paramètre est disponible dans le bloc administrateur «Informations système».[hr]
[color=orangered][b][i]Règles de définition des versions linguistiques pour les pages de contenu (actualités, textes et autres)[/i][/b][/color]
Pour créer des actualités pour une version linguistique spécifique du site (par exemple, pour l'anglais), vous devez créer une catégorie dans la section «Catégories» et indiquer dans quelle version linguistique elle doit être affichée (créer la catégorie en anglais respectivement). Ensuite, lors de la création d'une actualité en anglais, associez-la à la catégorie linguistique précédemment créée. L'utilisateur, en passant à la version anglaise, verra les actualités associées à la catégorie anglaise.
Pour créer des pages de contenu linguistiques, créez simplement leur contenu dans la langue correspondante et ajoutez le lien vers celles-ci dans la version linguistique souhaitée.[/justify]
