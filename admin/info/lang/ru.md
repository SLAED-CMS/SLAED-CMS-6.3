# Редактор языков

Модуль **«Редактор языков»** (`admin.php?name=lang`) — это мощный инструмент для управления мультиязычностью SLAED CMS. Он позволяет переводить все системные сообщения, кнопки и тексты интерфейса непосредственно из панели администратора, без необходимости вручную редактировать `.php` файлы в коде движка.

---

## 1. Главная (Список модулей)

Во вкладке «Главная» представлена таблица всех доступных в системе модулей и системных компонентов, которые можно перевести на разные языки.

* **№** — порядковый номер. (Под номером 1 всегда идет ядро `Система`).
* **Название** — публичное имя модуля на русском (или вашем системном) языке.
* **Модуль** — техническое имя директории, где лежат файлы (например: `news`, `forum`).
* **Кто видит** — права доступа к модулю на фронтенде (Все посетители / Только пользователи).
* **Статус** — зеленый индикатор 'Активирован' или красный 'Деактивирован'.
* **Функции** — кнопка **Редактор**, при наведении на которую выпадает меню:
  * `Администратор` — редактирование языковых файлов, используемых в админ-панели этого модуля.
  * `Модуль` — редактирование текстов фронтенда (тексты, которые видят обычные посетители сайта).
  * *Если одной из кнопок нет, значит модуль не имеет соответствующих языковых файлов.*

---

## 2. Интерфейс перевода

При клике на редактирование модуля открывается интерфейс работы со словарем констант:

1. **Языковая константа** — техническое имя (например, `_ACESS`), используемое в коде PHP.
2. Далее идут поля ввода перевода этой константы для всех установленных в системе языков (Немецкий, Английский, Француский, Русский и т.д.).
3. **Автоперевод (кнопка OK)** — справа от каждого пустого языка есть синяя кнопка `OK`. При нажатии на нее сработает скрипт автоматизированного перевода текста с базового языка на целевой через API!

---

## 3. Конфигурации

Здесь задаются параметры для автоматизации перевода и удобства работы:

* **API-Ключ** — ключ доступа к сервису машинного перевода для работы волшебной синей кнопки `OK`.
* **Язык, с которого будет производиться перевод** — базовый (опорный) язык (по умолчанию Русский), с которого система будет запрашивать перевод на другие языки (Английский, Французский и т.д).
* **Количество новых полей с языковыми константами** — сколько пустых блоков добавлять на каждой странице внизу списка, чтобы вы могли придумать и добавить абсолютно новую языковую переменную в код.
* **Konstanten pro Seite** — количество констант, выводимых на одной странице (пагинация). Рекомендуемое значение: 100, чтобы не перегружать браузер и лимиты POST-запроса сервера.

> [!NOTE]
> **Как создавать контент (Новости, Статьи) на разных языках?**
> Редактор языков переводит только интерфейс. Чтобы сделать полностью англоязычные новости, вы должны пойти в модуль «Категории», создать там категорию «International News» и в ее настройках отметить, что она выводится только при британском флаге. Затем добавьте англоязычную новость именно в эту категорию.
