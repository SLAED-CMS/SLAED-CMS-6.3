[justify]Les groupes sont destinés à la répartition des utilisateurs soit en fonction du nombre de points accumulés, soit par affectation à un groupe spécial.
Chaque utilisateur autorisé effectue certaines actions sur le site (consultation de pages, commentaires, etc.) – pour chacune de ces actions, il peut accumuler le nombre de points spécifié dans les paramètres et ainsi accéder au groupe d'utilisateurs correspondant (rang).

[b][color=green]Gestion des points[/color][/b]
La gestion de la valeur des points s'effectue dans l'onglet «Points». Saisissez le nombre de points attribués pour l'exécution de certaines actions sur le site et cliquez sur «Enregistrer».

[b][color=green]Gestion des groupes[/color][/b]
La gestion des groupes s'effectue dans les onglets «Principal» et «Ajouter».
L'onglet «Principal» permet de consulter la liste des groupes créés et d'effectuer les actions suivantes (colonne «Fonctions») :
[li] [b][i]Vue détaillée[/i][/b] – ouvre la section «Utilisateurs», qui affiche les utilisateurs appartenant au groupe.
[li] [b][i]Édition complète[/i][/b] – ouvre le formulaire d'édition des données du groupe.
[li] [b][i]Supprimer l'objet[/i][/b] – le groupe est supprimé.

L'onglet «Ajouter» permet d'ajouter un nouveau groupe. Le formulaire d'ajout de groupe contient :
[li] [b][i]Nom du groupe[/i][/b] – ce nom est affiché sur le site lors de la consultation des informations sur l'utilisateur.
[li] [b][i]Description[/i][/b] – saisissez une description caractérisant le groupe ; la description n'est pas affichée sur le site.
[li] [b][i]Groupe spécial[/i][/b] – si le groupe est spécial, les points ne sont pas pris en compte et l'utilisateur doit être affecté à ce groupe en modifiant son profil.
[li] [b][i]Nombre minimum de points requis[/i][/b] – indiquez combien de points un utilisateur doit accumuler pour devenir membre du groupe créé. Si le groupe est marqué comme spécial, ce champ disparaît.
[li] [b][i]Image[/i][/b] – sélectionnez une image caractérisant les membres du groupe. Par défaut, une liste de rangs est proposée. Les images sont chargées dans la liste depuis le répertoire images/ranks/ du site, il est donc possible d'élargir la gamme d'images disponibles de manière autonome.
[li] [b][i]Couleur[/i][/b] – la couleur du nom du groupe est sélectionnée. C'est-à-dire que sur le site, le nom du groupe sera affiché dans la couleur choisie.
Après avoir rempli le formulaire, n'oubliez pas de cliquer sur le bouton «Enregistrer».[/justify]
