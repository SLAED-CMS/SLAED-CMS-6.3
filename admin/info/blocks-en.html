[justify]The «Blocks and Banners» section provides the ability to build the website from «building blocks» called «blocks».
The following types of blocks exist:
[li] [b][i]Standard[/i][/b] – placed in specific locations on the website;
[li] [b][i]Free (fly)[/i][/b] – these blocks can be used anywhere, in templates or system modules.
Most website functionality needs are covered by standard blocks, but in some cases free blocks can be used.

[color=green][b]Standard Blocks[/b][/color]
Standard blocks can be divided by the following properties:
[li] [b][i]By type[/i][/b]:
* File-based – blocks whose information is output through HTML and PHP functions defined in the corresponding file.
* HTML – blocks whose information is output through HTML functions defined in the block content.
* RSS – blocks that display information taken from an RSS link.
* System – system blocks include: Admin, UserBox.
[li] [b][i]By accessibility (who sees)[/i][/b]: all users, only users, only administrators, only anonymous.
[li] [b][i]By position[/i][/b]: left, center bottom, center top, right, top banner, bottom banner.

[color=orangered][b][i]Styling of Standard Blocks[/i][/b][/color]
The styling of standard blocks is handled by theme templates: block-center.html, block-all.html, block-right.html and other templates with the prefix block. (See section «Design Theme»).
You can create a unique design for any block in the blocks/ directory (block-name.php; name is the block name). To do this:
1. In the templates/design_theme/ directory, create a template file named block-name.html.
2. In the created template, create a unique design for the block block-name.php.
[b]Example:[/b]
A unique design for the block block-voting.php is required. In this case, a template file is created in the templates/design_theme/ directory with the name block-voting.html. The system will find this template file automatically and use it only for styling the block block-voting.php.

[b][i][color=orangered]Adding a File Block[/color][/i][/b]
To add a file block, the following steps must be performed:

[b]1.[/b] Create the block file.
A file for a file block can be created in two ways: through the administration section interface and through the website's file structure.

[u]Creating a file through the administration section interface[/u]
Go to the «Add File Block» tab, which displays the form for adding a new file block.
Specify the name of the file to be created (e.g., mysite), noting that SLAED CMS will automatically add the prefix «block-» to the file name.
Specify the type of file to be created.
Click «Create Block» and a form will load where the block code must be inserted.
[hr][color=red][b][i]Warning![/b]
In the program code of the block, to output information you must use the variable $content instead of standard methods echo or print – this is the only distinguishing feature to consider. Everything else is implemented using standard PHP and HTML methods and functions. When implementing blocks, note that any PHP code must start with <?php and end with ?>.[/i][/color][hr] After inserting, click «Save» and the corresponding file will be created in the website's file structure (e.g., block-mysite.php as in our example).
[hr][color=red][b][i]Warning![/b]
When creating a file block file, you must set CHMOD 777 permissions on the blocks/ folder, and subsequently CHMOD 666 on the created file.[/i][/color][hr]
[u]Creating a file through the website's file structure[/u]
PHP files for file blocks are stored in the «blocks» directory, which is in the root directory of the website. In this directory, you can create your own PHP file, necessarily naming it in the format «block-blockname.php» (if the name format differs, the file will not be visible in the list when adding a block).

[b]2.[/b] Establish a link between the created file and the block.
To establish a link between the file and the file block, a new block must be added by going to the «Add Block» tab.
The add form has the following fields:
[li] [b][i]Title[/i][/b] – the block title is entered (whatever title is entered is what is displayed);
[li] [b][i]RSS Channel Link[/i][/b] – if a specific RSS feed should be displayed in the block, specify a link to it or select from the standard list. When entering an RSS link, you don't need to select a file in the «File Name» field or fill in «Content». When creating a file block, this field remains unchanged.
[li] [b][i]Update Time[/i][/b] – how often the RSS feed should be updated. When creating a file block, this field remains unchanged.
[li] [b][i]File Name[/i][/b] – when creating a file block, the previously created file is selected.
[li] [b][i]Content[/i][/b] – filled only when creating an HTML block (when filling in content, no file needs to be selected). When creating a file block, this field remains unchanged.
[li] [b][i]Position[/i][/b] – the position where the block should be displayed is selected.
[li] [b][i]Display Block in Modules[/i][/b] – the list of modules in which the block should be displayed is selected.
[li] [b][i]Language[/i][/b] – selection of the language version in which the block should be displayed.
[li] [b][i]Activate[/i][/b] – «yes» – the block will be shown, «no» – the block will not be shown.
[li] [b][i]Working Time in Days[/i][/b] – you can specify the number of days the block should be active. 0 – block is active without restrictions.
[li] [b][i]After Expiration[/i][/b] – you can choose what the system should automatically do with the block after the working time expires.
[li] [b][i]Who Will See This?[/i][/b] – you can specify for which user categories the block view is available.

[color=orangered][b][i]Adding an HTML Block[/i][/b][/color]
Creating HTML blocks is very convenient for displaying banners, links, and other elements for which HTML code is sufficient.
Adding an HTML block is just as simple as a file block. Go to the «Add Block» tab and fill in the fields as when creating a file block, but instead of selecting a file, fill in the «Content» field. The content must be filled with HTML code.

[color=orangered][b][i]Adding an RSS Block[/i][/b][/color]
Go to the «Add Block» tab and fill in the fields as when creating a file block, but instead of selecting a file, specify the RSS channel link and update time.

[color=orangered][b][i]Using Blocks Directly in HTML Files of the Design Theme[/i][/b][/color]
1. Create a block in the system administration panel; it can be a standard or free block.
2. Activate the block and determine its No. – number in the block list.
3. To insert a block, for example in the main file: index.html of the design theme, simply add the code: {%BLOCKS n,XXX%}

XXX – your block number
n – without styling
or
XXX – full name of the block file in the directory: blocks/ e.g.: block-forum.php
s – standard styling

Other options are possible at your discretion.

[u]Variable Description[/u]
{%BLOCKS none,XXX%} or {%BLOCKS n,XXX%} – Any system block or free block without styling, where XXX is either the block ID or the block file name.

{%BLOCKS standart,XXX%} or {%BLOCKS s,XXX%} – Any system block or free block with free block styling, where XXX is either the block ID or the block file name.

[u]Creating Personal Styling for a Block[/u]
To create exclusive styling for a block, a template file for this block must be created with the name:

block-15.html
15 – is the block number in the block list. In the database (table prefix_blocks, field bid).
or
block-name.html
name – is the block name, full name of the block file in the directory: blocks/

The block styling file should be placed in the main directory of the design theme along with other standard system templates.

[color=green][b]Free (fly) Blocks[/b][/color]
A free block (fly) can be placed anywhere on the website page, for which the creation code of this free block must be inserted into the corresponding PHP file (e.g., in config/config_header.php). Free block creation code cannot be inserted into design theme templates (*.html files), as in this case this PHP code will not be processed. More complete information about inserting blocks into design theme templates is provided in the «Design Theme» section.
A free block is described in a PHP script by the function: blocks("why", "who"), where blocks is the function for creating a free block with parameters: why and who.
Depending on the why and who parameters, the free block creation function can:
[li] Print the formed free block to standard output (display the block on the page).
[li] Return a string with the formed free block (block output to a variable for subsequent insertion of this block into an HTML template). In this case, this free block can be with or without styling – this depends on the why parameters.

[u]Meaning of why parameters:[/u]
[li] [b][i]none[/i][/b] (outputs the block body on the page without styling)
$fly_block_1_1 = blocks("none", 15);
$fly_block_1_2 = blocks("none", "block-menu2.php");
[li] [b][i]standart[/i][/b] (outputs the block body on the page with styling)
$fly_block_2_1 = blocks("standart", 15);
$fly_block_2_2 = blocks("standart", "block-menu2.php");
[li] [b][i]plzreturn[/i][/b] (outputs the block body to a variable without page output and without styling)
$fly_block_3_1 = blocks("plzreturn", 15);
$fly_block_3_2 = blocks("plzreturn", "block-menu2.php");
[li] [b][i]oreturnform[/i][/b] (block body to variable without page output, but with styling)
$fly_block_4_1 = blocks("oreturnform", 15);
$fly_block_4_1 = blocks("oreturnform", "block-menu2.php");
* 15 – is the bid, block number in the database (Block number can be viewed in the administration panel in the No. row).

[u]Meaning of who parameters:[/u]
[li] [b][i]bid[/i][/b] of the block (block number in the database; table pref_blocks (pref – is the DB table prefix), field bid)
$fly_block_5_1 = blocks("none", 15);
$fly_block_5_2 = blocks("standart", 15);
$fly_block_5_3 = blocks("plzreturn", 15);
$fly_block_5_4 = blocks("oreturnform", 15);
[li] [b][i]block-name.php[/i][/b] (name of the block PHP file; name is the block name)
$fly_block_6_1 = blocks("none", "block-menu2.php");
$fly_block_6_2 = blocks("standart", "block-menu2.php");
$fly_block_6_3 = blocks("plzreturn", "block-menu2.php");
$fly_block_6_4 = blocks("oreturnform", "block-menu2.php");
To use the created free block, this block must be active. This block should only have one mark – «Free Block», otherwise this block will be treated as standard.

To create exclusive styling for a free block, a template file for this block must be created with the name:
[li] [b][i]fly-block-15.html[/i][/b] (15 – is the block number in the database (table pref_blocks, field bid));
[li] [b][i]fly-block-name.html[/i][/b] (name – is the block name).[/justify]
[b]Example 1:[/b]
A free block with the following parameters must be created:
[li] Output of the free block body on the page.
[li] Without styling.
[li] By block number in the database.
[php]blocks("none", 15);[/php]
[li] Using the block name.
[php]blocks("none", "block-menu2.php");[/php]
[b]Example 2:[/b]
A free block with the following parameters must be created:
[li] Output of the free block body on the page.
[li] With styling.
[li] By block number in the database.
[php]blocks("standart", 15);[/php]
[li] Using the block name:
[php]blocks("standart", "block-menu2.php");[/php]
[b]Example 3:[/b]
A free block with the following parameters must be created:
[li] Output of the free block body to a variable.
[li] Without styling.
[li] By block number in the database
[php]global $blockg;
ob_start();
blocks("plzreturn", 15);
$blockg["15"] = ob_get_clean();[/php]
[li] Using the block name:
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");[/php]
[b]Example 4:[/b]
A free block with the following parameters must be created:
[li] Output of the free block body to a variable.
[li] With styling.
[li] By block number in the database.
[php]global $blockg;
ob_start();
blocks("oreturnform", 15);
$blockg["15"] = ob_get_clean();[/php]
[li] Using the block name.
[php]global $blockg;
$blockg["menu2"] = blocks("oreturnform", "block-menu2.php");[/php]
[justify]To output a variable containing the free block body on the page, the following must be done:
Open the file config/config_header.php and insert the code:[/justify]
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");[/php]
[justify]Anywhere in the template (e.g., in templates/your_theme/index.html) insert the array $blockg[menu2] (note the absence of quotes inside the square brackets!) Instead of $blockg[menu2], the menu2 block will be output on the page, whose code is contained in the file blocks/block-menu2.php.
For correct output of a free block on the page, which is requested from the database by bid from the pref_blocks table, with the rss_info module enabled (news output in RSS format), the following must be written in the PHP file config/config_header.php:[/justify]
[php]global $blockg;
$blockg["menu2"] = blocks("plzreturn", "block-menu2.php");
ob_start();
blocks("none", 15);
$blockg["15"] = ob_get_clean();[/php]
[justify]A free block can be displayed on website pages throughout the entire website if its code is integrated into the design theme, or it can be displayed in a specific module if its code is integrated into that module's code.
A free block cannot be processed by the system as a standard block, but a standard block can be processed by the system as a free block. Example: the modules block with bid 1 (table slaed_blocks) can be output on the page again as a free block, and then all restrictions that apply to the modules block apply to this block (show only on the main page or only in one module or in selected modules or in all modules).

[b][i][color=orangered]Changing a Block File[/color][/i][/b]
To edit a file block file, go to the «Edit Block» tab and select the file to edit.

[b][i][color=orangered]Changing a Block[/color][/i][/b]
In the «Home» tab in the «Functions» column, click (Full Edit) – the block editing form will be displayed.

[b][i][color=orangered]Changing Block Position[/color][/i][/b]
In the «Home» tab in the «Position» column, use the arrows to change the block position. The selected block position is displayed in the «Position» column.[/justify]
