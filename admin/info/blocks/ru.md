# Блоки и баннеры

Модуль **Блоки и баннеры** предоставляет инструменты для управления структурными элементами дизайна: стандартными и свободными блоками. Вы можете отображать HTML-код, интегрировать исполняемые PHP-файлы и RSS-ленты в заданных позициях сайта или выводить их тегом в любом месте доверенного контента.

## Вкладки модуля

### 1. Главная
Список всех созданных блоков, сгруппированный по позициям. Над таблицей выводится информационная подсказка по управлению порядком и свободным блокам.

**Группы списка** — строки-заголовки по позициям: *Слева*, *Справа*, *По центру вверху*, *По центру внизу*, *Верхний баннер*, *Нижний баннер*. Свободные блоки собраны в отдельной группе в конце списка. Заголовок группы кликабелен: клик сворачивает или разворачивает ее блоки (иконки-стрелки справа показывают состояние; выбор запоминается в браузере).

**Колонки таблицы:**
* **№** — ID блока в базе данных (`bid`).
* **Заголовок** — название блока. Иконка `i` рядом с названием показывает всплывающую справку: полное название, язык и срок действия.
* **Тип** — вид содержимого (`HTML`, `Файл` или `RSS/RDF`, `Системный`).
* **Кто видит** — уровень доступа (Все посетители, Только пользователи, Только администраторы, Только анонимы).
* **Позиция** — порядок вывода внутри группы: ручка для перетаскивания и номер. У свободных блоков вместо номера — чип «Свободный блок» (иконка-ветер) или «Свободный фиксированный блок» (иконка-булавка): позиция и порядок на них не действуют.
* **Статус** — индикатор состояния: зеленая иконка — блок активен, красная — отключен. Переключение статуса выполняется через веер «Функции».
* **Функции** — кнопка «⋯» раскрывает веер действий поверх строки (соседние строки не перекрываются): *активировать/деактивировать*, *редактировать*, *удалить*.

**Изменение порядка** — зажмите ручку в колонке «Позиция» и перетащите строку на новое место. Перетаскивание работает только внутри своей группы; при попытке переноса в чужую группу целевая строка подсвечивается красным. Новый порядок сохраняется сразу (AJAX, без перезагрузки страницы), сохраненная строка подсвечивается зеленой вспышкой, номера пересчитываются автоматически.

> [!NOTE]
> Быстрое изменение статуса выполняется через веер «Функции» с перезагрузкой страницы. Смена порядка перетаскиванием происходит без перезагрузки.

### 2. Добавить блок
Создание нового блока (HTML, RSS) или привязка существующего файла (`block-*.php`).

* **Заголовок** — название блока. Допускается использование системных языковых констант (например, `_LOGIN`, `_SEARCH`).
* **Файл RSS / Канал RSS** — URL ленты новостей. Для обычного блока оставьте вариант «Свой»: тогда используется поле «Содержание».
* **Переводов строк новостей** — при выборе стандартного канала позволяет ограничить количество записей.
* **Время обновления** — периодичность парсинга RSS (от 30 мин. до 24 часов).
* **Имя файла** — выбор из выпадающего списка доступных файлов в папке `blocks/`.
* **Содержание** — текстовое поле (с поддержкой визуального редактора) для ввода произвольного текста или HTML-кода при создании HTML-блока.
* **Позиция** — позиционирование блока на странице (как и в списке «Главная»).
* **Отображать блок в модулях** — выбор конкретных модулей, где будет выводиться блок. Плюс ряд специальных переключателей (справа от списка модулей):
  * **Главная** — блок будет отображаться (или не отображаться) на главной странице наряду с модулями.
  * **Только на главной** — выводить блок *исключительно* на стартовой странице сайта.
  * **Во всех модулях** — принудительно выводить повсеместно.
  * **Отрицание** — инверсия выделения списка: блок будет выводиться везде, *кроме* отмеченных модулей.
  * **Свободный блок** — исключает блок из автоматического вывода позиций; он выводится только тегом `[block=id]` (см. «Виды блоков»).
  * **Свободный фиксированный блок** — свободный блок, который при выводе тегом дополнительно учитывает ограничения списка модулей и переключателей выше.
* **Язык** — привязка блока к конкретной языковой версии локализации (или «Всем»).
* **Активировать?** — включить (Да) или выключить (Нет).
* **Время действия в днях** — количество дней, в течение которых блок остается активен (0 — бессрочно).
* **После окончания времени действия** — автоматическое действие (`Деактивировать` или `Удалить`).
* **Кому доступен просмотр?** — ограничение прав на видимость.

> [!TIP]
> При создании HTML блока в поле **Содержание** очень удобно вставлять код баннеров, скрипты рекламных сетей, счетчики аналитики и произвольную HTML-верстку без необходимости создавать отдельные файлы.

### 3. Добавить файловый блок
Используется для быстрого создания PHP и HTML файлов блоков напрямую из интерфейса ПУ (в директорию `blocks/`).

* **Имя файла** — введите логическое имя файла на латинице.
* **Тип** — `PHP` или `HTML`.

При нажатии «Создать блок» откроется полноформатный редактор кода с подсветкой синтаксиса для ввода тела скрипта (или HTML разметки). После сохранения вы сможете выбрать этот файл на вкладке «Добавить блок».

> [!CAUTION]
> При написании PHP-кода файлового блока:
> Для вывода информации на экран необходимо использовать конкатенацию переменной **`$content .= 'Ваша разметка';`**. Строго **не используйте** стандартные функции вывода `echo`, `print` или `printf` напрямую в теле PHP-файла блока — это нарушит структуру вывода макета темы оформления сайта.

> [!NOTE]
> В редакторе вводится только тело блока: служебную обертку — шапку файла и защиту от прямого доступа `if (!defined('BLOCK_FILE')) { ... }` — система добавляет автоматически при сохранении. Для типа `HTML` содержимое сохраняется внутри конструкции `<<<BLOCKHTML ... BLOCKHTML;`. Если вы создаете файл блока вручную (по FTP), защиту `BLOCK_FILE` необходимо добавить самостоятельно.

### 4. Редактировать блок
Встроенный редактор исходного кода для существующих файловых блоков.
* **Имя файла** — выпадающий список со всеми файлами из директории `blocks/`.

Нажатие «Редактировать» открывает поле редактора кода для внесения прямых правок. Эта функция избавляет от необходимости подключаться по FTP для мелких изменений.

### 5. Сортировка
Служебная автоматическая функция, выполняемая в один клик. Проводит пересортировку и оптимизацию порядка вывода (`weight`) всех блоков в базе данных сайта по позициям.

Используйте «Сортировку», если в колонке «Позиция» сбилась нумерация или блоки стали отображаться в непредсказуемом порядке (например, после ручного вмешательства в структуру БД).

### 6. Справка
Стандартная вкладка справки, подтягивающая содержимое из `admin/info/blocks/ru.md`.

## Виды блоков

### 1. Стандартные блоки
Имеют жесткую привязку к позициям в шаблоне темы оформления (Верхний баннер, Слева, и т.д.). Управление видимостью, правами, сроками отображения и привязкой к модулям осуществляется через стандартные поля в админке. Оформление всех блоков задает единый фрагмент темы `fragments/block-all.html` — отдельных позиционных шаблонов нет.

Особый подвид — **системные блоки** (тип `Системный` в списке): встроенные блоки ядра, например «Администрация» и «Блок пользователя». Их содержимое генерирует система; позицией, порядком, правами и статусом они управляются как обычные блоки.

### 2. Свободные блоки
Специальный вид блоков. Свободный блок исключается из автоматического вывода позиций и выводится только там, где в контенте размещен тег вставки.
Чтобы блок стал свободным, при его добавлении или редактировании в таблице «Отображать блок в модулях» отметьте переключатель `Свободный блок`.

Свободный блок можно вывести двумя способами — тегом в контенте и тегом в шаблоне темы. В обоих случаях `id` — номер блока из колонки «№» списка (для файловых блоков используется ID их записи в списке).

**1. Тег в контенте:** `[block=id]`

Обрабатывается только в доверенном контенте, который создают администраторы и авторы: тексты новостей, статей и других модулей. В пользовательском контенте (комментарии, сообщения форума, подписи) тег не обрабатывается и остается обычным текстом.

Пример: разместите `[block=42]` в тексте статьи — на этом месте будет выведен блок с ID 42 в стандартном оформлении темы, с заголовком.

**2. Тег в шаблоне темы:** `{% freeblock id %}`

Размещается в HTML-файлах темы оформления (`templates/тема/layouts|partials|fragments/*.html`) — там, где блок нужен в самом макете, вне стандартных позиций.

Пример: `{% freeblock 42 %}` в `layouts/app.html` выведет блок с ID 42 на всех страницах, использующих этот макет.

Оба тега используют один механизм вывода и одинаковые правила (см. ниже); допускается только числовой ID. Не путайте `{% freeblock id %}` с конструкцией `{% block имя %}` — последняя относится к наследованию макетов шаблонизатора и к блокам сайта отношения не имеет.

> [!IMPORTANT]
> Блок, отмеченный как `Свободный блок`, исключается из автоматического вывода сайта: он перестает выводиться в своей позиции независимо от настроек. При выводе любым тегом действуют статус активности, срок действия, привязка к языку и права «Кому доступен просмотр?»; для `Свободного фиксированного блока` дополнительно применяются ограничения списка модулей. Если блок не существует, отключен или недоступен по этим условиям — тег выводит пустоту, без сообщений об ошибке.

> [!NOTE]
> Теги не обрабатываются в содержимом самих блоков: `[block=id]` внутри HTML-блока и `{% freeblock id %}` внутри шаблона оформления блока останутся без вывода. Вкладывать блоки друг в друга нельзя.

> [!NOTE]
> Устаревшие способы вызова из прошлых версий — PHP-функция `blocks("why", "who")` и тег шаблона `{%BLOCKS n,file%}` — в текущей версии не поддерживаются. Используйте `[block=id]` в контенте и `{% freeblock id %}` в шаблонах темы.
