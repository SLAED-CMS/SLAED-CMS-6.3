# Блоки и баннеры

Модуль **Блоки и баннеры** предоставляет инструменты для управления структурными элементами дизайна: стандартными и свободными (fly) блоками. Вы можете отображать HTML-код, интегрировать исполняемые PHP-файлы и RSS-ленты в заданных позициях сайта или динамически вызывать их в любом месте.

## Вкладки модуля

### 1. Главная
Список всех созданных блоков с возможностью быстрой сортировки, настройки и удаления.

**Колонки таблицы:**
* **№** — уникальный счетчик вывода списка (в базе данных это `bid` — ID блока).
* **Заголовок** — название блока. Клик по иконке `i` (рядом с названием) открывает всплывающее контекстное меню с пунктами:
  * *Активировать / Деактивировать*
  * *Полное редактирование*
  * *Удаление объекта*
* **Тип** — вид содержимого (`HTML`, `Файл` или `RSS`).
* **Кто видит** — уровень доступа (Все посетители, Только анонимы, Только зарегистрированные, Только модераторы, Только администраторы).
* **Позиция** — текущее расположение блока (`Левая сторона`, `По центру вверху`, `По центру внизу`, `Правая сторона`, `Верхний баннер`, `Нижний баннер`).
* **Положение** — порядок вывода блока в выбранной зоне. Сортировка осуществляется нажатием стрелочек (вверх/вниз).
* **Статус** — индикатор состояния. Зеленая иконка "i" означает, что блок активен, красная "!" — отключен. Клик по иконке переключает статус.
* **Функции** — красная кнопка «Редактор» для перехода в режим подробного редактирования.

> [!NOTE]
> Быстрое изменение статуса (клик по зеленой/красной иконке) и смена положения (клик по стрелочкам) происходит **с перезагрузкой страницы**. Модуль в этих целях не использует AJAX.

### 2. Добавить блок
Создание нового блока (HTML, RSS) или привязка существующего файла (`block-*.php`).

* **Заголовок** — название блока. Допускается использование системных языковых констант (например, `_LOGIN`, `_SEARCH`).
* **Файл RSS / Канал RSS** — URL ленты новостей. Можно ввести вручную или выбрать из списка по умолчанию.
* **Переводов строк новостей** — при выборе стандартного канала позволяет ограничить количество записей.
* **Время обновления** — периодичность парсинга RSS (от 30 мин. до 24 часов).
* **Имя файла** — выбор из выпадающего списка доступных файлов в папке `blocks/`.
* **Содержание** — текстовое поле (с поддержкой визуального редактора) для ввода произвольного текста или HTML-кода при создании HTML-блока.
* **Позиция** — позиционирование блока на странице (как и в списке "Главная").
* **Отображать блок в модулях** — выбор конкретных модулей, где будет выводиться блок. Плюс ряд специальных переключателей (справа от списка модулей):
  * **Главная** — блок будет отображаться (или не отображаться) на главной странице наряду с модулями.
  * **Только на главной** — выводить блок *исключительно* на стартовой странице сайта.
  * **Во всех модулях** — принудительно выводить повсеместно.
  * **Отрицание** — инверсия выделения списка: блок будет выводиться везде, *кроме* отмеченных модулей.
  * **Свободный блок** — делает блок fly-блоком (выводится только при явном вызове в коде/шаблоне).
  * **Свободный фиксированный блок** — делает fly-блок с жестким выводом.
* **Язык** — привязка блока к конкретной языковой версии локализации (или "Всем").
* **Активировать?** — включить (Да) или выключить (Нет).
* **Время действия в днях** — количество дней, в течение которых блок остается активен (0 - бессрочно).
* **После окончания времени действия** — автоматическое действие (`Деактивировать` или `Удалить`).
* **Кому доступен просмотр?** — ограничение прав на видимость.

> [!TIP]
> При создании HTML блока в поле **Содержание** очень удобно вставлять код баннеров, скрипты рекламных сетей, счетчики аналитики и произвольную HTML-верстку без необходимости создавать отдельные файлы.

### 3. Добавить файловый блок
Используется для быстрого создания PHP и HTML файлов блоков напрямую из интерфейса ПУ (в директорию `blocks/`).

* **Имя файла** — введите логическое имя файла на латинице. Система автоматически добавит к имени префикс `block-` и нужное расширение (например: введете `test`, создастся `block-test.php`).
* **Тип** — `PHP` или `HTML`.

При нажатии «Создать блок» откроется полноформатный редактор кода с подсветкой синтаксиса для ввода тела скрипта (или HTML разметки). После сохранения вы сможете выбрать этот файл на вкладке "Добавить блок".

> [!CAUTION]
> При написании PHP-кода файлового блока:
> Для вывода информации на экран необходимо использовать конкатенацию переменной **`$content .= 'Ваша разметка';`**. Строго **не используйте** стандартные функции вывода `echo`, `print` или `printf` напрямую в теле PHP-файла блока — это нарушит структуру вывода макета темы оформления сайта.

### 4. Редактировать файл
Встроенный редактор исходного кода для существующих файловых блоков.
* **Имя файла** — выпадающий список со всеми файлами из директории `blocks/`.

Нажатие "Редактировать" открывает поле редактора кода для внесения прямых правок. Эта функция избавляет от необходимости подключаться по FTP для мелких изменений.

### 5. Исправить
Служебная автоматическая функция, выполняемая в один клик. Проводит пересортировку и оптимизацию `weight` (порядка вывода) всех блоков в базе данных сайта по категориям позиций.

Используйте функцию "Исправить", если в таблице блоков в колонке "Положение" сбилась нумерация или блоки стали отображаться в непредсказуемом порядке (например, после ручного вмешательства в структуру БД).

### 6. Информация
Стандартная вкладка справки, подтягивающая содержимое из `admin/info/blocks/ru.md`.

## Виды блоков

### 1. Стандартные блоки
Имеют жесткую привязку к позициям в шаблоне темы оформления (Верхний баннер, Слева, и т.д.). Управление видимостью, правами, сроками отображения и привязкой к модулям осуществляется через стандартные поля в админке.

### 2. Свободные (fly) блоки
Специальный вид блоков. "Fly-блок" можно вручную вызвать в любом месте PHP-сценариев системы либо непосредственно в HTML-файлах вашего шаблона, вне обвязки стандартных позиций.
Для того чтобы блок стал "Свободным", при его добавлении или редактировании в таблице "Отображать блок в модулях" следует отметить чекбокс `Свободный блок`.

> [!IMPORTANT]
> Если блок отмечен как `Свободный блок` — он исключается из списков автоматического вывода сайта (т.е. он перестанет выводиться в левой или правой колонке, независимо от своих настроек позиции).

**Как вывести свободный блок в PHP коде:**
Функция возвращает или выводит блок: `blocks($why, $who)`
$why (`"none"`, `"standart"`, `"plzreturn"`, `"oreturnform"`): стиль вывода и флаг return.
$who (ID блока в БД или имя файла).
Пример: `blocks("none", 42);` — выведет блок с ID 42 (без оформления темы).

**Как вывести свободный блок прямо в HTML шаблоне:**
В файлах `.html` темы оформления (например, в `index.html`) можно вставлять специальные теги, которые будут отпарсены системой:
* `{%BLOCKS n,block-login.php%}` — выведет блок `block-login.php` без оформления (голым кодом).
* `{%BLOCKS s,block-login.php%}` — выведет со стандартным оформлением темы (будет использован шаблон `block-center.html` или его аналог).
Вместо имени файла также разрешено использовать числовой ID блока.
