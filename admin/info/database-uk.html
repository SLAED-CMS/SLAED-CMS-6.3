[justify]Розділ призначений для виконання основних операцій з адміністрування бази даних сайту.
У даному розділі можна виконати наступні дії:
[li] [b][i]Оптимізація бази даних[/i][/b] – дія виконується безпосередньо після переходу в однойменну вкладку. Регулярно виконуючи оптимізацію бази даних, зменшується її розмір і відповідно з цим прискорюється робота з отримання інформації з бази даних.
Рекомендується використовувати дану функцію мінімум один раз на тиждень.
[li] [b][i]Ремонт бази даних[/i][/b] – дія виконується безпосередньо після переходу в однойменну вкладку. При несподіваній зупинці MySQL сервера, під час виконання будь-яких дій, може статися пошкодження структури таблиць бази даних, використання цієї функції проведе ремонт пошкоджених таблиць.[hr][color=blue][b]Зверніть увагу![/color][/b]
У вкладках «Оптимізація бази даних» і «Ремонт бази даних» відображається стовпець «Витрати», в якому виводиться інформація про вільний простір, звільнений після оптимізації або ремонту бази даних.[hr][li] [b][i]Запит в базу даних[/i][/b] – дозволяє виконати довільний запит в БД. Через форму, виведену у вкладці, можна виконувати, практично, будь-які запити за винятком запитів на вибірку даних (SELECT).

[b][i][color=orangered]Приклади запитів в базу даних[/color][/i][/b]
[li] Запит, який видалить всіх зареєстрованих користувачів, які не відвідували проект, починаючи з: 2010-02-29 18:15:00.[/justify]
[code]DELETE FROM {prefix}_users WHERE user_lastvisit < "2010-02-29 18:15:00";[/code]
[justify][li] Запит, який видалить всіх зареєстрованих користувачів, які жодного разу не відвідували проект.[/justify]
[code]DELETE FROM {prefix}_users WHERE user_lastvisit = "0000-00-00 00:00:00";[/code]
[justify][li] Запит, який видалить всіх зареєстрованих користувачів, які використовують IP-адресу: 193.201.225.104. Дана можливість корисна для масового видалення спам-ботів у випадку їх реєстрації.[/justify]
[code]DELETE FROM {prefix}_users WHERE user_last_ip = "193.201.225.104";[/code]
[justify][li] У деяких випадках, при публікації великих текстів з вмістом більше 65535 символів, є необхідність збільшити розмір збереженої інформації до максимуму. Виконайте наступний пакет запитів:[/justify]
[code]ALTER TABLE `{prefix}_stories` CHANGE `hometext` `hometext` MEDIUMTEXT NULL DEFAULT NULL;
ALTER TABLE `{prefix}_stories` CHANGE `bodytext` `bodytext` LONGTEXT NOT NULL;[/code][justify][hr][color=red][b][i]Увага![/b]
