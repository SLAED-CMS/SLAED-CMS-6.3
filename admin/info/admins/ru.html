# Администраторы Раздел предназначен для управления учётными записями администраторской панели. Каждый администратор получает доступ только к тем модулям, которые явно указаны в его правах. ## Добавление администратора Перейдите во вкладку **Добавить** и заполните форму. ### Поля формы | Поле | Описание | |---|---| | **Ник** | Логин для входа в систему | | **Звание** | Должность или роль (отображается в списке) | | **E-Mail** | Адрес для связи и восстановления пароля | | **Ссылка** | URL профиля или сайта администратора | | **Пароль** | Минимум 6 символов, буквенно-цифровой | | **Получать уведомления** | Включает отправку системных уведомлений | | **Отправить уведомление на E-Mail** | Отправляет письмо с данными после сохранения | | **Текст сообщения** | Шаблон письма. Доступные подстановки: `[login]`, `[pass]` | | **Использование редактора** | Текстовый редактор по умолчанию | | **Язык** | Язык интерфейса панели управления | | **Разрешения** | Список модулей, к которым разрешён доступ | > [!IMPORTANT] > При добавлении обязательно заполнить: **ник**, **e-mail**, **пароль** и **повтор пароля**. При редактировании поле пароля можно оставить пустым — текущий пароль сохранится без изменений. ## Управление администраторами Список всех администраторов отображается во вкладке **Главная**. Столбцы: ник, звание, сайт, e-mail, язык, IP-адрес. Для просмотра даты регистрации и последнего входа наведите курсор на значок **(i)** в первой колонке. - Редактирование: колонка «Функции» → **Полное редактирование** - Удаление: колонка «Функции» → **Удаление объекта** ## Права доступа Список модулей формируется автоматически из всех установленных модулей системы. При включении опции **Полный доступ** администратор получает права суперпользователя. Новые модули появляются в списке автоматически; удалённые исчезают при следующем открытии формы редактирования. Временно заблокировать доступ можно, сняв все отметки в списке разрешений — без удаления учётной записи. > [!IMPORTANT] > Администратор и пользователь сайта — разные сущности системы. Добавление одного не создаёт другого. Это сделано намеренно для повышения безопасности. > [!WARNING] > Если включена опция «Отправить уведомление на E-Mail», письмо будет отправляться при **каждом** сохранении формы редактирования. > [!CAUTION] > Если в разделе «Безопасность» задан дополнительный логин/пароль для панели — сообщите его всем администраторам. > [!CAUTION] > При смене URL входа в панель управления — сообщите новый адрес всем администраторам.
