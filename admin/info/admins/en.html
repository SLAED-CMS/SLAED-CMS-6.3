[justify]The «Administrators» section is designed for managing users of the administration section. Administrators can access the module control panels according to the assigned access rights.

[color=green][b]Adding an Administrator[/b][/color]
To add a new administrator, go to the «Add» tab and fill in the information about the new administrator.

Explanations for form fields:
[li] [b][i]Nickname[/i][/b] – text field, the nickname is used as a login.
[li] [b][i]Title[/i][/b] – text field where the administrator's title is entered (this can be a position, role name, etc.).
[li] [b][i]E-Mail[/i][/b] – administrator's email, also used for password recovery.
[li] [b][i]Link[/i][/b] – link to the administrator's website (for example, to their Facebook profile).
[li] [b][i]Password[/i][/b] – used for system login. It is recommended to create an alphanumeric password with at least 6 characters.
[li] [b][i]Receive emails and notifications?[/i][/b] – whether the administrator will receive notifications (for example, about new comments).
[li] [b][i]Send notification to user's E-Mail[/i][/b] – if checked, after adding the user, an email will be sent to the specified address, the text of which is set in the «Message text» field.
[li] [b][i]Message text[/i][/b] – email template that will be sent to the administrator if the «Send notification to user's E-Mail» field is checked.
[li] [b][i]Editor usage[/i][/b] – selection of the text editor that will be used by the administrator by default.
[li] [b][i]Language[/i][/b] – selection of the language in which the administration section will be presented by default for the administrator (the language can be switched in the upper left corner of the administration section).
[li] [b][i]Permissions[/i][/b] – specifies which modules the administrator will have access to. If «Access» is selected, the administrator will have access to all modules.

When adding an administrator, you must specify: nickname, email, password, and password confirmation.

[color=green][b]Administrator Management[/b][/color]
Management of existing administrators is done in the «Home» tab. To change administrator information, click (Full Edit) in the «Functions» column. To delete an administrator account, click (Delete Object) in the «Functions» column.

[hr][color=blue][b]Please Note[/b][/color]
[li] When editing an administrator account, if the «Send notification to user's E-Mail» field is checked, an email according to the template will be sent to the administrator each time the account is edited.
[li] To view the registration date and time and the last login of the administrator, hover the mouse cursor over the (i) icon next to the desired administrator in the first column of the administrator list.
[li] An administrator's access to system sections can be temporarily blocked by unchecking the modules in the list that the administrator has access to.
[li] If a new module is added to the modules directory (for example, a custom module), it will automatically appear in the permissions list when editing/adding administrators.
[li] Adding an administrator does not automatically add a user (and vice versa), as these are different system entities (done for increased security).
[li] If an additional login and password for the administration section is set in the «Security» section, don't forget to inform the administrators.
[li] When changing the default login link to the administration section, don't forget to inform the administrators.[/justify]
