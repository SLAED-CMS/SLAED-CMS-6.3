[justify]The «Categories» section allows you to create thematic branches (categories) for system modules. Category creation is available for the following modules:
[li] Questions and Answers – faq;
[li] File Catalog – files;
[li] Forum – forum;
[li] Help – help;
[li] Jokes – jokes;
[li] Website Catalog – links;
[li] Media Catalog – media;
[li] News – news;
[li] Articles – pages;
[li] Shop – shop.

To view the categories of a module, select the module in the upper right list on the «Home» tab (the category list will update automatically).

[b][color=green]Managing Categories and Subcategories[/color][/b]
The list of categories and subcategories is displayed on the «Home» tab.
If a subcategory is displayed, the value «[color=darkgreen]Yes[/color]» appears in the «Sub-c...» column; if a category is displayed – «[color=red]No[/color]».
Also, when displaying a subcategory, the hierarchical structure of the subcategory's belonging to categories is shown in the «Category» column, i.e., first the category name is displayed, then the subcategory name.
If an image is set for a category or subcategory, the value «[color=darkgreen]Yes[/color]» is displayed in the «Image...» column; if no image is set – «[color=red]No[/color]».

[b][i][color=orangered]Sorting Categories and Subcategories[/color][/i][/b]
To set the display order of categories and/or subcategories, click on the arrow icons in the «Position» column: up, down.
After clicking on the arrow icon, the category or subcategory will move down or up without page reload.
Note that subcategories are sorted within the category to which they belong.

[b][i][color=orangered]Editing Categories and Subcategories[/color][/i][/b]
There are two ways to edit (change) category or subcategory data:
1. Click on (Full Edit) in the «Functions» column.
2. Go to the «Edit» tab and, selecting the desired category or subcategory from the list, click «Edit».

The editing form for categories or subcategories is identical to the add form.

[b][i][color=orangered]Deleting Categories and Subcategories[/color][/i][/b]
To delete a category or subcategory, click on (Delete Object) in the «Functions» column on the «Home» tab.

[b][color=green]Adding a Category[/color][/b]
To add a new category for the selected module, go to the «Add Category» tab and fill in the information about the new category.
[b][hr][color=blue]Please Note![/color][/b]
Information when adding a category is filled in the following tabs:
[li] [b][i]Category[/i][/b] – basic information about the category is filled in here.
[li] [b][i]Access Rights[/i][/b] – access rights of website visitors to information placed in the category are specified here.
[li] [b][i]Forum Rights[/i][/b] – various types of rights are specified here. Only needs to be filled for categories of the «Forum» module (not considered for categories of other modules).
When moving between tabs, information is saved. To complete the category adding process, click «Add».[hr][b][i][color=orangered]Filling the «Category» Tab[/color][/i][/b]
The following information must be filled in the «Category» tab:
[li] [b][i]Title[/i][/b] – category name (will be displayed on the website).
[li] [b][i]Description[/i][/b] – brief explanation of the category.
[li] [b][i]Language[/i][/b] – selection of the language version in which the category being added is valid.
[li] [b][i]Module[/i][/b] – selection of the module to which the category is being added.
[li] [b][i]Image[/i][/b] – selection of an image for the category (displayed next to the title). Images are selected from the directory: images/categories/. You can add your own category images to this folder. Recommended image size is 48x48 pixels, image type .*png.
[li] [b][i]Activate[/i][/b] – whether the category will be available for use (value «Yes») or not (value «No»).
Only the «Title» field is required.

[b][i][color=orangered]Filling the «Access Rights» Tab[/color][/i][/b]
On this tab, access rights of website visitors to information that will be created in the category being added are selected.
You can select user groups that will have access to view information and groups with read access to information.
To select multiple groups, hold the Ctrl or Shift key.

[b][i][color=orangered]Filling the «Forum Rights» Tab[/color][/i][/b]
[b][hr][color=blue]Please Note![/color][/b]
This tab only needs to be filled for categories of the «Forum» module (not considered for categories of other modules).[hr]The following rights can be specified for the forum category being added:
[li] [b][i]Can create[/i][/b] – users of selected groups will be able to create (add) new topics within the category being added.
[li] [b][i]Can reply[/i][/b] – users of selected groups will be able to reply (write messages) in topics created within the category.
[li] [b][i]Can edit[/i][/b] – users of selected groups will be able to edit (modify) topics and messages in them created within the category.
[li] [b][i]Can delete[/i][/b] – users of selected groups will be able to delete topics and messages in them created within the category.
[li] [b][i]Can moderate[/i][/b] – users of selected groups will be moderators of the forum category being added. A moderator can edit and delete topics and replies.

[b][color=green]Adding a Subcategory[/color][/b]
To add a new subcategory for the selected module, go to the «Add Subcategory» tab and fill in the information about the new subcategory.
The form and process for adding a subcategory are identical to the form and process for adding a category, except for selecting the category to which the subcategory is being added. Category selection is done in the «Category» tab.
A subcategory can be added both for a category and for another subcategory, allowing the creation of a hierarchy with virtually unlimited nesting levels.
[b][hr][color=blue]Please Note![/color][/b]
[li] A category cannot be made a subcategory (subordinated to another category), and a subcategory cannot be made a category (first nesting level). Immediately determine whether a category or subcategory is being added.
[li] After editing a category or subcategory, all materials associated with the changed entry are saved.
[li] The subordination of a subcategory can be changed when editing it. Thus, for example, forum branches can be moved from one main topic (category) to another.
[li] To view the description of a category, hover the mouse cursor over the (i) icon next to the desired category (subcategory) in the «Category» column of the «Home» tab.[/justify]
