[justify]The «Comments» section is designed for managing comments posted by users on the website (moderation).

[b][color=green]Comment Management[/color][/b]
Comment management is performed in the following tabs:
[li] [b][i]Home[/i][/b] – management of all comments posted on the website.
[li] [b][i]Awaiting Review[/i][/b] – management of comments posted by website «guests» (unauthorized visitors). Guest comments are sent for review if the corresponding option is set in the comment configuration.

[b][i][color=orangered]Managing Posted Comments[/color][/i][/b]
The following actions are available for each posted comment:
[li] [b][i]Detailed View[/i][/b] – the comment opens on the website (page of the material to which the comment was added).
[li] [b][i]Full Edit[/i][/b] – the form for changing the comment text opens.
[li] [b][i]Delete Object[/i][/b] – the comment is deleted.

To invoke any action, hover the mouse cursor over the (Editor) button (displayed in the lower right corner of the comment) and select the corresponding item in the menu displayed next to the button.

For [b][i]batch processing[/i][/b], comments can be marked individually by checking the checkbox to the right of the comment, or all comments displayed on the page by checking «Mark All» to the right of the top comment.
Note that when navigating to the next page of the comment list, marks set on the previous page are not saved.
The action for marked comments is selected at the bottom of the comment list. The following actions are available:
[li] [b][i]Activate[/i][/b] – this action is relevant for comments awaiting review. When this action is selected, the comment is displayed on the website for public viewing.
[li] [b][i]Delete[/i][/b] – delete marked comments.

[b][i][color=orangered]Managing Comments Awaiting Review[/color][/i][/b]
Managing comments awaiting review is similar to managing posted comments.
If a comment is suitable for posting on the website, it must be marked (checkbox on the right) and the action for marked comments (bottom right of the list) «Activate» should be selected.

[b][color=green]Comment Configuration[/color][/b]
Management of settings (configurations) for the «Comments» section is done in the «Configurations» tab, where the following settings can be configured:
[li] [b][i]Number of posts per user page[/i][/b] – the specified number of comments will be displayed on one page of the public part of the website. We recommend not setting the number of comments on one page to more than 30 to avoid increasing page load time.
[li] [b][i]Number of posts per administrator page[/i][/b] – the specified number of comments will be displayed on one page of the «Comments» section in the administrative area.
[li] [b][i]Maximum number of user page numbers[/i][/b] – if the number of pages with comments exceeds the specified value, an ellipsis will be displayed after the page number corresponding to the specified number.
[li] [b][i]Maximum number of administrator page numbers[/i][/b] – similar to the previous setting, but configured for the management section (administrative area).

[b][color=green]Managing Comments Directly on the Website[/color][/b]
After logging into the system under an administrator account, you can manage comments directly on the website when viewing commented materials (not in the administrative area). For the administrator, the (Editor) button is displayed (in the upper left corner of the comment), and hovering the mouse cursor over it displays the comment management menu.
The menu contains:
[li] [b][i]Quick Edit[/i][/b] – without page reload, the comment will be displayed in text editing mode.
[li] [b][i]Close for Review[/i][/b] – the comment will be moved to «Awaiting Review» status. For convenience, the administrator sees comments with «Awaiting Review» status on the website, but such comments are displayed «paler» compared to accepted comments.
[li] [b][i]Activate[/i][/b] – this action is relevant for comments awaiting review. When this action is selected, the comment is displayed on the website for public viewing.[/justify]
