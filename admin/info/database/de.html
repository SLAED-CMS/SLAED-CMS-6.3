[justify]Der Bereich ist für die Durchführung grundlegender Operationen zur Verwaltung der Website-Datenbank vorgesehen.
In diesem Bereich können folgende Aktionen durchgeführt werden:
[li] [b][i]Datenbankoptimierung[/i][/b] – die Aktion wird unmittelbar nach dem Wechsel zur gleichnamigen Registerkarte ausgeführt. Durch regelmäßige Optimierung der Datenbank wird ihre Größe reduziert und entsprechend die Arbeit beim Abrufen von Informationen aus der Datenbank beschleunigt.
Es wird empfohlen, diese Funktion mindestens einmal pro Woche zu verwenden.
[li] [b][i]Datenbankreparatur[/i][/b] – die Aktion wird unmittelbar nach dem Wechsel zur gleichnamigen Registerkarte ausgeführt. Bei einem unerwarteten Stopp des MySQL-Servers während der Ausführung von Aktionen kann die Struktur der Datenbanktabellen beschädigt werden. Die Verwendung dieser Funktion repariert beschädigte Tabellen.[hr][color=blue][b]Beachten Sie![/color][/b]
In den Registerkarten «Datenbankoptimierung» und «Datenbankreparatur» wird die Spalte «Overhead» angezeigt, in der Informationen über den freien Speicherplatz ausgegeben werden, der nach der Optimierung oder Reparatur der Datenbank freigegeben wurde.[hr][li] [b][i]Datenbankabfrage[/i][/b] – ermöglicht die Ausführung einer beliebigen Abfrage in der Datenbank. Über das im Tab angezeigte Formular können praktisch alle Abfragen ausgeführt werden, mit Ausnahme von Datenauswahlabfragen (SELECT).

[b][i][color=orangered]Beispiele für Datenbankabfragen[/color][/i][/b]
[li] Abfrage, die alle registrierten Benutzer löscht, die das Projekt seit dem 29.02.2010 18:15:00 nicht besucht haben.[/justify]
[code]DELETE FROM {prefix}_users WHERE user_lastvisit < "2010-02-29 18:15:00";[/code]
[justify][li] Abfrage, die alle registrierten Benutzer löscht, die das Projekt nie besucht haben.[/justify]
[code]DELETE FROM {prefix}_users WHERE user_lastvisit = "0000-00-00 00:00:00";[/code]
[justify][li] Abfrage, die alle registrierten Benutzer mit der IP-Adresse 193.201.225.104 löscht. Diese Möglichkeit ist nützlich für das massenhafte Löschen von Spam-Bots im Falle ihrer Registrierung.[/justify]
[code]DELETE FROM {prefix}_users WHERE user_last_ip = "193.201.225.104";[/code]
[justify][li] In einigen Fällen, bei der Veröffentlichung großer Texte mit mehr als 65535 Zeichen, ist es notwendig, die Größe der gespeicherten Informationen auf das Maximum zu erhöhen. Führen Sie das folgende Abfragepaket aus:[/justify]
[code]ALTER TABLE `{prefix}_stories` CHANGE `hometext` `hometext` MEDIUMTEXT NULL DEFAULT NULL;
ALTER TABLE `{prefix}_stories` CHANGE `bodytext` `bodytext` LONGTEXT NOT NULL;[/code][justify][hr][color=red][b][i]Achtung![/b]
Nach der Abfrage gibt das System einen Bericht über die Ergebnisse der Abfrageausführung in einzelnen Tabellen aus: Ok (wenn alles korrekt verlaufen ist), Fehler (wenn ein Fehler aufgetreten ist).[/i][/color][/justify]
