[justify]The «My Favorites» section is designed for viewing and managing the list of materials added by website users to favorites. The section also allows you to configure settings for «My Favorites».

[color=green][b]«Main» tab[/b][/color]
Displays the list of favorite materials added by website users. The following information is displayed in the list:
[li] [b][i] Module[/i][/b] – which module the favorite material belongs to.
[li] [b][i]Title[/i][/b] – the title of the favorite material. Displayed as a hyperlink leading to the material view.
[li] [b][i]Posted by[/i][/b] – displays the username of the user who added the material to their favorites list.

The administrator can perform the following actions with each material (access to actions in the «Functions» column):
[li] [b][i]Detailed view[/i][/b] – opens the favorite material on the website.
[li] [b][i]Delete object[/i][/b] – removes the bookmark for the material from the «My Favorites» section (also deleted for the user who added the favorite).

[color=orangered][b][i]How many times a material has been added to favorites[/i][/b][/color]
In the table with favorite materials, you can sort by column contents by clicking on the column header. By sorting data by the «Title» column, you can see how many times a specific material has been added to favorites.

[color=green][b]«Configurations» tab[/b][/color]
The following settings for «My Favorites» are configured in this tab:
[li] [b][i]Number of publications per user page[/i][/b] – the number of materials added to favorites that will be displayed on one page in the user's personal account.
[li] [b][i]Number of publications per administrator page[/i][/b] – the number of materials added to favorites that will be displayed on one page in the «My Favorites» section of the control panel.
[li] [b][i]Maximum number of page numbers for users (administrators)[/i][/b] – the page list will include the specified number of pages, after which the last page number separated by ellipsis will be displayed.
[li] [b][i]Maximum allowed quantity[/i][/b] – the maximum number of materials that one user can add to favorites.
[li] [b][i]Activate favorites?[/i][/b] – this setting allows you to disable the «My Favorites» module.[/justify]
