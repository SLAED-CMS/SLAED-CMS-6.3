# Фавориты

Модуль **«Фавориты»** (`admin.php?name=favorites`) предоставляет администратору централизованный доступ к управлению закладками, которые пользователи сайта сохраняют в свои личные коллекции («Избранное»). 
С помощью этого инструмента вы можете анализировать популярность материалов и настраивать лимиты для этой функции на сайте.

---

## 1. Главная (Список фаворитов)

На главной вкладке выводится общая сводная таблица всех материалов, добавленных кем-либо из пользователей в свои «Фавориты». Обратите внимание, что один и тот же материал может фигурировать в списке несколько раз — если его добавили разные пользователи.

### Содержимое таблицы

* **№** — уникальный внутренний идентификатор записи в базе данных фаворитов.
* **Заголовок** — кликабельное название сохраненной публикации. Переносит вас прямо на страницу этого материала на публичной части сайта (frontend).
* **Модуль** — системное имя модуля, к которому принадлежит материал (например, `Форум`, `Магазин` или `Вопросы и ответы`).
* **Разместил** — кликабельный никнейм (логин) пользователя, который добавил эту публикацию себе в избранное.
* **Функции** — кнопка **«Редактор»**, внутри которой доступно действие «Удалить объект».

> [!CAUTION]
> Действие «Удалить объект» полностью стирает эту закладку из базы данных. Для пользователя, добавившего данный материал, он тоже мгновенно пропадет из списка его избранного.

> [!TIP]
> **Аналитика популярности:** Вы можете использовать этот список для оценки интереса к контенту. Если нажать на сортировку по столбцу «Заголовок», таблица сгруппирует данные, и вы визуально увидите, какие статьи или темы форума пользователи сохраняют в закладки чаще всего.

---

## 2. Конфигурации

На этой вкладке задаются технические лимиты и ограничения для работы модуля фаворитов как в личном кабинете пользователя, так и в самой панели администратора.

### Основные настройки

* **Количество публикаций на страницу пользователя** — сколько закладок будет одновременно отображаться на одной странице (pagination) в профиле обычного посетителя на фронтенде сайта.
* **Количество публикаций на страницу администратора** — сколько записей выводить на одной странице на вкладке «Главная» в модуле «Фавориты» в админ-панели.
* **Максимальное количество номеров страниц пользователей / администратора** — определяет, сколько кликабельных кнопок с номерами страниц (`1, 2, 3, 4, 5...`) выводить в блоке пагинации. Если страниц больше, блок будет сокращен с помощью многоточия (например: `1 2 3 4 5 ... 20`).
* **Максимально допустимое количество** — жесткий лимит на общее число закладок, которые один пользователь физически может добавить в свой личный профиль. При превышении система выдаст лимит-уведомление.

> [!IMPORTANT]
> **Активировать фавориты?** — Глобальный переключатель (Да/Нет). Если выбрать «Нет», функция добавления материалов в «Избранное» будет полностью скрыта и отключена во всех модулях (новости, статьи, форум) на всем сайте.
