[justify]Cette section est destinée à la gestion des messages informatifs affichés sur la page d'accueil du site.
Les messages peuvent être nécessaires pour :
[li] accueillir les utilisateurs ;
[li] publier une annonce importante (par exemple, que le site sera en maintenance à une date donnée) ;
[li] publier une annonce «urgente».

[b][color=green]Ajout d'un message[/color][/b]
Pour ajouter un message, accédez à l'onglet «Ajouter» et remplissez le formulaire qui contient les champs suivants :
[li] [b][i]Titre[/i][/b] – indiquez-le de manière courte et claire ;
[li] [b][i]Texte[/i][/b] – notez que le texte du message sur le site est affiché directement après le titre, et non sur une page séparée ;
[li] [b][i]Langue[/i][/b] – choix de la version linguistique dans laquelle le message doit être affiché ;
[li] [b][i]Durée en jours[/i][/b] – combien de jours le message sera actif. 0 signifie que la durée est illimitée ;
[li] [b][i]Qui verra ceci ?[/i][/b] – choisissez pour quels types d'utilisateurs le message sera visible ;
[li] [b][i]Activer ?[/i][/b] – choisissez si le message doit être affiché ou non.

[color=orangered][b][i]Pages d'affichage des messages[/i][/b][/color]
Les messages sont affichés uniquement sur la page d'accueil du site.

[color=orangered][b][i]Règles d'affichage de plusieurs messages actifs[/i][/b][/color]
Le message ajouté avant les autres est affiché.[/justify]
