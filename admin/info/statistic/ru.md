# Статистика

Раздел **«Статистика»** — это встроенная система веб-аналитики, позволяющая отслеживать общую посещаемость вашего сайта, качество аудитории и источники трафика без использования тяжелых внешних скриптов.

---

## 1. Главная (Аналитика)

Верхняя часть страницы (рядом с кнопкой «OK») содержит выпадающий список **«Показать статистику за:»**. Если система собрала достаточное количество архивных логов, вы сможете переключаться между месяцами для анализа исторических данных.

### График посещений (Гистограмма)
Цветная масштабируемая столбчатая диаграмма визуализирует показатели за выбранный месяц, разделяя их по категориям (Уникальные посетители, Аудитория, Переходы). Под каждым столбцом выводится детальная цифровой сводка за этот день.

### Таблица данных
Под графиком расположена подробная таблица с разбивкой по суткам (каждая строка — один день). Значение колонок:
* **Дата** — отчетные сутки.
* **Уникальные** — количество уникальных посетителей (считается по уникальным IP/сессиям).
* **Входы (Хиты)** — общее количество загруженных (просмотренных) страниц сайта всеми пользователями.
* **Главная** — количество прямых переходов непосредственно на индексную (главную) страницу сайта.
* **Переходы** — трафик с внешних ресурсов (переходы по гиперссылкам с чужих сайтов, форумов или из поисковой выдачи).
* **Поисковые боты** — количество зафиксированных обращений от поисковых роботов (индексаторов Google, Yandex и т.д.).
* **Аудитория** — "чистые" (прямые) заходы. Это живые посетители, которые целенаправленно вбили адрес вашего сайта в браузер или зашли из закладок (из подсчета 'Уникальных' вычитаются 'Поисковые боты' и 'Переходы').
* **Пользователи** — сколько зарегистрированных (и авторизованных на момент визита) пользователей сегодня посетили проект.
* **Генерация**, **SQL-запросы**, **Память PHP** — нагрузка средней страницы за этот день: время, за которое сервер собрал страницу, число запросов к базе и пиковая память PHP. Считаются все страницы сайта и панели, которые попали в статистику; фоновые опросы панели в счёт не идут. Строка **Всего** — среднее за весь показанный период. У дней, записанных до появления этих колонок, вместо цифр стоит прочерк.

Ниже, в расширенной статистике, рядом с графиком **Hits by hour** стоит график **Average generation by hour** — среднее время генерации страницы по часам суток за тот же период. По нему видно, в какие часы сайт отвечает медленнее. Те же почасовые цифры за текущий час показывает строка цифр кокпита на главной панели.

> [!TIP]
> Значение в колонке **Входы** (Хиты), как правило, всегда в 5-10 раз больше колонки **Уникальные**, так как один живой посетитель может пролистать десяток страниц сайта за один сеанс. Если их значения одинаковы, это может свидетельствовать о высокой доле "отказов" (пользователи сразу уходят с сайта).

## 2. Конфигурации

Настройки визуализации встроенной гистограммы и работы самого модуля:

* **Расстояние между балок** — отступ между столбцами на графике в пикселях (влияет на общую ширину картинки).
* **Ширина балки** — толщина каждого столбца графика в пикселях.
* **Активировать статистику?** (`Да/Нет`) — глобальный выключатель. Если вы пользуетесь мощными сторонними метриками (Яндекс.Метрика, Google Analytics) и хотите снизить нагрузку на свой сервер и базу данных, вы можете полностью отключить сбор встроенной статистики.
