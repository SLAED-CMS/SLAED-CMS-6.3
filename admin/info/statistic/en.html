[justify]The "Statistics" section is designed for viewing site traffic statistics.

[color=green][b]"Main" Tab[/b][/color]
[b][i][color=orangered]Histogram[/color][/i][/b]
The histogram (bars) displays information about traffic statistics for the selected period.
By default, information for the current month is displayed, but the period can be set using the dropdown list "Show statistics for:".
Below each bar, a statistical summary is shown in the order corresponding to the column order in the table.

[b][i][color=orangered]Table[/color][/i][/b]
Displays traffic statistics in a table containing the following columns:
[li] [b][i]Date[/i][/b] – reporting date;
[li] [b][i]Unique[/i][/b] – number of unique site visitors;
[li] [b][i]Hits[/i][/b] – total number of pages viewed;
[li] [b][i]Main page[/i][/b] – number of visitors to the site's main page;
[li] [b][i]Referrals[/i][/b] – number of referrals from search engines and other websites;
[li] [b][i]Search bots[/i][/b] – number of search bots that visited the site;
[li] [b][i]Audience[/i][/b] – visitors who accessed the site directly, i.e. excluding referrals from other websites and search engines, as well as search bots;
[li] [b][i]Users[/i][/b] – number of registered users who visited the site.
By default, the table displays information for the current month, but the period can be set using the dropdown list "Show statistics for:".

[color=green][b]"Configurations" Tab[/b][/color]
In this tab, the following section settings can be configured:
[li] [b][i]Bar spacing[/i][/b] – the distance between histogram bars.
[li] [b][i]Bar width[/i][/b] – the width of the bars.
[li] [b][i]Activate statistics?[/i][/b] – whether statistics should be collected or not.[/justify]
