[justify]This section is designed for managing the service texts of the website that are displayed in all modules of the site in all language versions.
[b][color=green]Text management[/color][/b]
Management of language module texts is done in the «Main» tab, which contains a list of modules where service texts for language versions can be set.
Explanations for the table displayed in the «Main» tab:
[li] [b][i]Module[/i][/b] – displays the name of the system module.
[li] [b][i]Who sees[/i][/b] – displays whether the information from this module is visible to all website visitors or only to users (authorized visitors).
[li] [b][i]Status[/i][/b] – whether the module is currently activated (Activated), i.e., displayed on the website, or not (Deactivated).

The administrator can perform the following actions with each entry (access to actions in the «Functions» column):
[li] [b][i]Administrator[/i][/b] – navigate to editing service words used in the administration section, or no value indicating that the administrator part of the module does not contain service words.
[li] [b][i]Module[/i][/b] – navigate to editing service words used in the public part of the system, or no value indicating that the user part of the module does not contain service words.

Navigation to the service words editing form for language versions is done by clicking on the value in the corresponding column (Administrator or Module).

[hr][b][color=blue]Please note![/color][/b]
To edit the main language constants of the administration panel as well as the user parts, the PHP settings parameter Max input vars: 4000 (maximum allowed number of incoming variables) or higher is required. This parameter is available in the administrator block «System Information».[hr]
[color=orangered][b][i]Rules for setting language versions for content pages (news, texts, and others)[/i][/b][/color]
To create news for a specific language version of the website (for example, for English), you need to create a category in the «Categories» section and specify in which language version it should be displayed (create the category in the corresponding language). Then, when creating an English-language news item, assign it to the previously created language category. When the user switches to the English version, they will see the news assigned to the English category.
To create language content pages, simply create their content in the corresponding language and add the link to them in the desired language version.[/justify]
