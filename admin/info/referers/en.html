[justify]The "Referrals" section is designed for viewing statistics of user and search bot referrals from other websites. It allows you to evaluate, for example, the effectiveness of placing a link to your website on a particular resource.

[color=green][b]"Main" Tab[/b][/color]
Referral statistics are presented as a table containing the following information:
[li] [b][i]Nickname[/i][/b] – if the referred user is registered on the website, their nickname is displayed. If not registered, then the IP Address. If the referral was made by a search bot, the name of the search engine is displayed.
[li] [b][i]IP Address[/i][/b] – the IP Address of the referred user is displayed.
[li] [b][i]Referral Addresses[/i][/b] – from which page the referral to the website was made.
[li] [b][i]Entry Addresses[/i][/b] – to which specific page the referral was directed.
[li] [b][i]Date[/i][/b] – date and time of the referral.

[b][i][color=orangered]Sorting and Grouping in the Referrals Table[/color][/i][/b]
To group referrals by various criteria, use the criteria listed before the table.
You can also sort data in a column alphabetically by clicking on the name of the desired column.

[color=green][b]"Configuration" Tab[/b][/color]

[li] [b][i]Number of entries per administrator page[/i][/b] – the specified number of referrals will be displayed on one page within the referrals table in the "Main" tab.
[li] [b][i]Maximum number of page numbers for administrators[/i][/b] – if the number of pages with referrals exceeds the specified value, an ellipsis will be displayed after the page number corresponding to the specified number.
[li] [b][i]Retention period for referrals from other websites, in days[/i][/b] – after this time expires, referral information will be automatically deleted.
[li] [b][i]Activate referral statistics from other websites?[/i][/b] – whether referrals will be saved or not.

[color=green][b]"Delete" Tab[/b][/color]
[hr][color=red][b][i]Warning![/b]
Clicking this tab clears the referral statistics.[/i][/color][/justify]
