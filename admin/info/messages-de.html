[justify]Dieser Bereich dient zur Verwaltung von Informationsnachrichten, die auf der Hauptseite der Website angezeigt werden.
Nachrichten können benötigt werden, um:
[li] Benutzer zu begrüßen;
[li] eine wichtige Ankündigung zu platzieren (z. B. dass die Website an einem bestimmten Datum modernisiert wird);
[li] eine «heiße» Ankündigung zu platzieren.

[b][color=green]Nachricht hinzufügen[/color][/b]
Um eine Nachricht hinzuzufügen, wechseln Sie zur Registerkarte «Hinzufügen» und füllen Sie das Formular aus, das folgende Felder enthält:
[li] [b][i]Titel[/i][/b] – geben Sie ihn kurz und klar an;
[li] [b][i]Text[/i][/b] – beachten Sie, dass der Nachrichtentext auf der Website direkt nach dem Titel angezeigt wird und nicht auf einer separaten Seite;
[li] [b][i]Sprache[/i][/b] – Auswahl der Sprachversion, in der die Nachricht angezeigt werden soll;
[li] [b][i]Laufzeit in Tagen[/i][/b] – wie viele Tage die Nachricht aktiv sein wird. 0 bedeutet, dass die Zeit nicht begrenzt ist;
[li] [b][i]Wer wird es sehen?[/i][/b] – wählen Sie, für welche Benutzertypen die Nachricht sichtbar sein wird;
[li] [b][i]Aktivieren?[/i][/b] – wählen Sie, ob die Nachricht angezeigt werden soll oder nicht.

[color=orangered][b][i]Seiten zur Nachrichtenanzeige[/i][/b][/color]
Nachrichten werden nur auf der Hauptseite der Website angezeigt.

[color=orangered][b][i]Regeln für die Anzeige mehrerer aktiver Nachrichten[/i][/b][/color]
Es wird die Nachricht angezeigt, die vor den anderen hinzugefügt wurde.[/justify]
