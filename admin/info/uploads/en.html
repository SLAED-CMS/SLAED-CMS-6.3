[justify]The "Uploads and Templates" section is designed for managing files uploaded to module directories, including: managing uploaded files, uploading new files, managing templates for displaying files on website pages.

[b][color=green]"File Catalog" Tab[/color][/b]
In this tab you can:
[li] Upload files to the directory of the selected module (the directory/module is selected in the upper right corner).
[li] Manage the list of files uploaded to the main module directory.
[b][i]Main directory[/i][/b] – files uploaded by the administrator, visitors, and users depending on the selected module
[li] Manage the list of files uploaded to the additional module directory.
[b][i]Additional directory[/i][/b] – as a rule, these are preview files (thumbnails) created automatically by the system. This feature is available when publishing images using the BB editor. The size of the automatic image reduction (Width, Height) can be set in the configurations for each module individually.

[color=green][b]"Templates" Tab[/b][/color]
For each file type (file types can be added in the "Configurations" tab >> "General" subsection) uploaded to the website (typically when using the BB editor), a custom template can be set. The template is active for objects inserted in the BB editor (left "Paperclip" button in the bottom panel of the editor).

Depending on the file extension, the template set by the administrator will be automatically used during output. It is possible to set the size of the attached object, both width and height. If no size is specified, the system uses the default settings.
The administrator has the ability to set a custom template for each format, which in turn provides unlimited possibilities for various types of graphics display, video playback, music playback, etc.

[li] [b][i]align=center[/i][/b] – object position (left, right, center);
[li] [b][i]title=title[/i][/b] – alternative text, heading;
[li] [b][i]width=500[/i][/b] – width;
[li] [b][i]height=500[/i][/b] – height;
[li] [b][i]rel=rel[/i][/b] – if used, it will show a group of images with the ability to scroll through them. The value of rel after the equals sign can be anything; for a group of images, it is preferable to use a unique value, e.g. rel=my_img.

[color=green][b]"Configurations" Tab[/b][/color]
Contains two subsections:

[b][i][color=orangered]General[/color][/i][/b]
The main configurations for uploading and displaying files are set here:
[li] [b][i]Default directory[/i][/b] – the directory that will be opened by default in the "Main" tab of the "Uploads and Templates" section.
[li] [b][i]Application formats[/i][/b] – formats for which a template can be added in the templates section.
[li] [b][i]Default application width[/i][/b] – set in case nothing is specified in the module configurations.
[li] [b][i]Default application height[/i][/b] – set in case nothing is specified in the module configurations.

[b][i][color=orangered]Modules[/color][/i][/b]
Upload configurations are set individually for each module.
[hr][color=blue][b]Please note![/color][/b]
The "All" module is responsible for modules that do not have an administrator panel. For example, the user module or third-party modules that work with the BB editor.[/justify]
