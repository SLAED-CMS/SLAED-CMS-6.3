[justify]La section « Uploads et modèles » est destinée à la gestion des fichiers téléchargés dans les répertoires des modules, notamment : la gestion des fichiers téléchargés, le téléchargement de nouveaux fichiers, la gestion des modèles d'affichage des fichiers sur les pages du site.

[b][color=green]Onglet « Catalogue de fichiers »[/color][/b]
Dans cet onglet, vous pouvez :
[li] Télécharger des fichiers dans le répertoire du module sélectionné (le répertoire/module est sélectionné dans le coin supérieur droit).
[li] Gérer la liste des fichiers téléchargés dans le répertoire principal du module.
[b][i]Répertoire principal[/i][/b] – fichiers téléchargés par l'administrateur, les visiteurs et les utilisateurs en fonction du module sélectionné
[li] Gérer la liste des fichiers téléchargés dans le répertoire supplémentaire du module.
[b][i]Répertoire supplémentaire[/i][/b] – en règle générale, ce sont des fichiers d'aperçu (miniatures) créés automatiquement par le système. Cette possibilité existe lors de la publication d'images à l'aide de l'éditeur BB. La taille de la réduction automatique de l'image (Largeur, Hauteur) peut être définie dans les configurations pour chaque module individuellement.

[color=green][b]Onglet « Modèles »[/b][/color]
Pour chaque type de fichier (les types de fichiers peuvent être ajoutés dans l'onglet « Configurations » >> sous-section « Général »), téléchargé sur le site (généralement lors de l'utilisation de l'éditeur BB), un modèle personnalisé peut être défini. Le modèle est actif pour les objets insérés dans l'éditeur BB (bouton gauche « Trombone » dans le panneau inférieur de l'éditeur).

En fonction de l'extension du fichier, le modèle défini par l'administrateur sera automatiquement utilisé lors de l'affichage. Il est possible de définir la taille de l'objet joint, tant en largeur qu'en hauteur. En l'absence de taille spécifiée, le système utilise les paramètres par défaut.
L'administrateur a la possibilité de définir un modèle personnalisé pour chaque format, ce qui offre des possibilités illimitées d'utilisation de différents types d'affichage graphique, de lecture vidéo, de lecture musicale, etc.

[li] [b][i]align=center[/i][/b] – position de l'objet (left, right, center) ;
[li] [b][i]title=title[/i][/b] – texte alternatif, titre ;
[li] [b][i]width=500[/i][/b] – largeur ;
[li] [b][i]height=500[/i][/b] – hauteur ;
[li] [b][i]rel=rel[/i][/b] – si utilisé, affiche un groupe d'images avec la possibilité de les faire défiler. La valeur de rel après le signe égal peut être quelconque ; pour un groupe d'images, il est préférable qu'elle soit unique, par exemple rel=my_img.

[color=green][b]Onglet « Configurations »[/b][/color]
Contient deux sous-sections :

[b][i][color=orangered]Général[/color][/i][/b]
Les configurations principales pour le téléchargement et l'affichage des fichiers sont définies ici :
[li] [b][i]Répertoire par défaut[/i][/b] – le répertoire qui s'ouvrira par défaut dans l'onglet « Principal » de la section « Uploads et modèles ».
[li] [b][i]Formats d'applications[/i][/b] – formats pour lesquels un modèle peut être ajouté dans la section des modèles.
[li] [b][i]Largeur d'application par défaut[/i][/b] – définie au cas où rien n'est spécifié dans les configurations du module.
[li] [b][i]Hauteur d'application par défaut[/i][/b] – définie au cas où rien n'est spécifié dans les configurations du module.

[b][i][color=orangered]Modules[/color][/i][/b]
Les configurations de téléchargement sont définies individuellement pour chaque module.
[hr][color=blue][b]Veuillez noter ![/color][/b]
Le module « Tous » est responsable des modules qui ne disposent pas de panneau d'administration. Par exemple, le module utilisateur ou les modules tiers qui fonctionnent avec l'éditeur BB.[/justify]
