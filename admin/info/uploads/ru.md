# Загрузки

Раздел **«Загрузки»** — это централизованная система управления файлами и медиа-контентом сайта. Он позволяет загружать файлы в директории различных модулей, управлять ими и настраивать шаблоны их отображения при использовании редактора.

---

## 1. Каталог файлов

Вкладка является основным файловым менеджером системы. В верхнем выпадающем списке **«Директория»** выберите модуль, файлами которого хотите управлять (например, `uploads/news` или `uploads/files`).

### Функции менеджера:
* **Загрузка:** Вы можете загрузить файл со своего компьютера или указать прямую ссылку на файл в интернете (система сама скачает его на сервер).
* **Приоритет источника:** Выбранный локальный файл всегда важнее ссылки. Ссылка используется только тогда, когда файл не был выбран вообще, а отклонённый локальный файл никогда не подменяется загрузкой по ссылке.
* **Правила для ссылки:** Допускаются только схемы `http` и `https` и только публично маршрутизируемые адреса. Загрузка отклоняется для локальных, приватных и зарезервированных адресов, в том числе после переадресации. Разрешено не более трёх переадресаций, действуют таймаут соединения и общий таймаут запроса, а объём загружаемых данных ограничен настройкой размера файла.
* **Основная директория:** Список всех файлов, загруженных в папку выбранного модуля.
* **Дополнительная директория (Эскизы):** Здесь хранятся автоматически созданные уменьшенные копии изображений (thumbnails), если модуль настроен на их генерацию.

---

## 2. Шаблоны

SLAED CMS позволяет задавать уникальный HTML-вид для каждого типа вставляемого файла. Это особенно полезно при вставке файлов через редактор.

Список блоков на этой вкладке формируется из настройки **«Форматы приложений»** вкладки «Конфигурации», а сохранение перестраивает файл шаблонов целиком. Поэтому удаление расширения из списка форматов удаляет и его шаблон, а переименование расширения оставляет новый блок пустым и теряет старый.

**Доступные переменные шаблона:**
* `[src]` — прямая ссылка на файл.
* `[tsrc]` — ссылка на файл предварительного просмотра (эскиз).
* `[width]`, `[height]` — ширина и высота окна вывода.
* `[twidth]` — ширина эскиза из настроек модуля.
* `[align]` — выравнивание (left, right, center).
* `[title]` — описание или заголовок файла.
* `[rel]` — атрибут для группировки изображений (например, для создания галерей).

## 3. Конфигурации

Тонкая настройка правил загрузки для всего сайта и каждого модуля в отдельности.

### Основные настройки:
* **Директория по умолчанию:** Папка, которая будет открываться при входе в модуль.
* **Форматы приложений:** Список расширений, для которых можно создавать уникальные шаблоны во вкладке «Шаблоны». Принимаются только те расширения, для которых у системы есть политика типа файла: всё остальное отбрасывается при сохранении, а отброшенные значения перечисляются в сообщении о сохранении.
* **Размеры по умолчанию:** Стандартная ширина и высота для медиа-объектов.

### Настройки модулей:
Для каждого системного модуля (Новости, Форум, Профиль и т.д.) можно задать индивидуальные лимиты:
* **Типы файлов:** Список разрешенных расширений (через запятую).
* **Лимиты размера:** Максимальный размер одного файла и общий размер всех файлов для одного модуля. Ограничение на один файл действует и для загрузок из этой панели — вкладка «Каталог файлов» берёт свои правила из записи **«Модуль: Все»**.
* **Размеры изображений:** Ограничения по ширине и высоте загружаемых картинок (в пикселях).
* **Авто-эскизы:** Ширина автоматически создаваемой миниатюры.
* **Права доступа:** Разрешение загрузки для обычных пользователей и гостей.

## 4. Поддерживаемые форматы

Система знает 21 формат, и только они могут быть сохранены в списках расширений:

* **Изображения:** `avif`, `gif`, `jpeg`, `jpg`, `png`, `webp`
* **Аудио:** `flac`, `m4a`, `mp3`, `oga`, `ogg`, `opus`, `wav`
* **Видео:** `mp4`, `webm`
* **Документы:** `pdf`
* **Архивы:** `7z`, `gz`, `rar`, `tar`, `zip`

**Что изменилось:**
* Выведены из поддержки десять форматов, каждый по своей причине: `swf` — технология Flash прекращена и ни один браузер её не выполняет; `ogv`, `ogx` и `spx` — не воспроизводятся во всех поддерживаемых браузерах; `m4p` — контейнер с защитой DRM, `m4r` — рингтон, оба неприменимы на сайте; `m4b`, `m4v` и `wave` — лишние написания уже поддерживаемых `m4a`, `mp4` и `wav`; `bmp` — формат без сжатия, полностью заменённый `webp` и `avif`.
* Исправлены два написания: `7zip` стало `7z`, `gzip` стало `gz`.
* Добавлены пять форматов: `webp`, `avif`, `flac`, `pdf` и `tar`. В общий список они входят полностью, а модулям добавлены только `webp` и `avif` — прямые замены уже разрешённых изображений. Остальные форматы можно включить модулю вручную во вкладке «Конфигурации».
* Уже вставленный в материалы контент с выведенным форматом продолжает отображаться — он выводится обычной ссылкой на файл.

---

## 5. Файловая панель редактора

Гость больше не видит в файловой панели редактора ранее загруженные файлы: он получает только те файлы, которые вернул его собственный текущий запрос на загрузку.

---

> [!TIP]
> Настройка **«Модуль: Все»** в конфигурациях задаёт правила для загрузок с вкладки «Каталог файлов» этой панели — независимо от того, какая директория выбрана. Она не применяется автоматически к модулям, у которых нет собственной записи: такие модули просто не могут быть целью загрузки из редактора.

> [!IMPORTANT]
> Если вы разрешаете загрузку файлов гостям, обязательно убедитесь, что в списке разрешенных типов (`FTYPE`) отсутствуют опасные расширения (такие как `php`, `php5`, `phtml`, `exe`), и установлены строгие лимиты на размер файла. Тип файла теперь проверяется по содержимому, а не только по расширению, и исполняемые или активные в браузере форматы отклоняются даже тогда, когда они указаны в настройках.
