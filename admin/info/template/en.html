[justify][color=green][b]Using Themes[/b][/color]
To change the website design, you can use themes.
A theme is a set of files responsible for the appearance of website pages. A theme includes: CSS files (Cascading Style Sheets) that define color, background, font size, etc. for key page elements, template files for the main page elements, and graphic files. To change the website design, simply switch the graphic theme in the administration panel to a new one.
[hr][color=blue][b]Please note![/b][/color]
In SLAED CMS, themes are stored in the «templates» directory.[hr]If the administrator has layout and design skills, they can independently create a theme for the website. You can also view and try on your website themes that have already been created and can be downloaded from the file catalog at [url=https://slaed.net]slaed.net[/url].

[color=green][b]"Templates" Tab[/b][/color]
In this tab, the HTML layout of specific website blocks is defined (for example, the menu).
To make changes to a file, simply click on the desired file in the file list, make changes in the displayed field, and click the "Save changes" button.
[hr][color=blue][b]Please note![/b][/color]
Changes are made to the theme selected in the list above the file list. To switch themes, select the desired theme in the list and click "OK".[hr]
[b][i][color=orangered]What to pay attention to when editing a theme[/color][/i][/b]

[u]Theme variables[/u]
The theme uses one type of variables: $arg[1], $arg[2], etc.
They are responsible for displaying headings, content, and other components depending on which system component the design belongs to.

Variables of the type: $lan[1], $lan[2], etc. are used for displaying constants (words depending on the language selected by the visitor, if this option is enabled, otherwise in the default language). You can add your own language constants to the corresponding array in the theme file: core/template.php

In addition to the two main types, global system variables can be used in the theme, such as: $theme, $conf
[li] [b][i]$theme[/i][/b] – determines the name of the current default theme, or the theme selected by the user in profile settings, if this option is enabled
[li] [b][i]$conf[/i][/b] – is responsible for displaying parameters set in the main system configuration file

[u]File index.html[/u]
The main design of the system is handled by the index.html file, which is intended for forming the structure and order of displaying modules, blocks, and other system components. The layout designer and web designer can fill it with any HTML design and apply all possible and known layout techniques. It is possible to use the main template individually for the project's main page, regardless of the installed module, as well as individually for each module and category of the system.
The index.html file uses additional variables responsible for the global output of modules and blocks.
Below is a description of the standard variables of the form {%XXXX%} and what they are responsible for. These variables can be placed throughout the file in any order.

[li] [b][i]{%META%}[/i][/b] – standard header formation - meta and title, as well as content that is present in the system by default.
[li] [b][i]{%LINK%}[/i][/b] – standard header formation - link and CSS styles, as well as content that is present in the system by default.
[li] [b][i]{%SCRIPT%}[/i][/b] – standard header formation - script and JavaScript, as well as content that is present in the system by default.
[li] [b][i]{%BLOCKS banner%} or {%BLOCKS b%}[/i][/b] – top banner.
[li] [b][i]{%BLOCKS left%} or {%BLOCKS l%}[/i][/b] – left blocks.
[li] [b][i]{%BLOCKS message%} or {%BLOCKS m%}[/i][/b] – message on the main page.
[li] [b][i]{%BLOCKS center%} or {%BLOCKS c%}[/i][/b] – top center blocks.
[li] [b][i]{%MODULE%}[/i][/b] – placeholder for the module that the system should insert (the content of the system module will be displayed in this area).
[li] [b][i]{%BLOCKS down%} or {%BLOCKS d%}[/i][/b] – bottom center blocks.
[li] [b][i]{%BLOCKS right%} or {%BLOCKS r%}[/i][/b] – right blocks.
[li] [b][i]{%BLOCKS foot%} or {%BLOCKS f%}[/i][/b] – bottom banner.
[li] [b][i]{%LICENSE%}[/i][/b] – system copyrights.
[li] [b][i]{%BLOCKS time%} or {%BLOCKS t%}[/i][/b] – page generation time.
[li] [b][i]{%BLOCKS variables%}[/i][/b] – debug extensions: system information (memory, generation and DB time), variable and database query analyzer.

Directly in the main template, you can use "Free Blocks", which are displayed using the following variables:
[li] [b][i]{%BLOCKS none,XXX%} or {%BLOCKS n,XXX%}[/i][/b] – any system block or free block without styling, where XXX is either the block ID or the block file name.
[li] [b][i]{%BLOCKS standart,XXX%} or {%BLOCKS s,XXX%}[/i][/b] – any system block or free block with styling, where XXX is either the block ID or the block file name.
Information about summary blocks can be found in the "Blocks and Banners" section.
