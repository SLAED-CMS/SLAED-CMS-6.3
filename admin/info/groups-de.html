[justify]Gruppen dienen zur Einteilung der Benutzer entweder abhängig von der gesammelten Punktzahl oder durch Zuordnung zu einer speziellen Gruppe.
Jeder autorisierte Benutzer führt auf der Website bestimmte Aktionen aus (Seiten ansehen, kommentieren usw.) – für jede solche Aktion kann er die in den Einstellungen angegebene Anzahl von Punkten sammeln und so in die entsprechende Benutzergruppe (Rang) gelangen.

[b][color=green]Punkteverwaltung[/color][/b]
Die Verwaltung der Punktewerte erfolgt in der Registerkarte «Punkte». Geben Sie die Anzahl der Punkte ein, die für die Ausführung bestimmter Aktionen auf der Website vergeben werden, und klicken Sie auf «Speichern».

[b][color=green]Gruppenverwaltung[/color][/b]
Die Verwaltung der Gruppen erfolgt in den Registerkarten «Hauptseite» und «Hinzufügen».
Die Registerkarte «Hauptseite» ermöglicht die Ansicht der Liste der erstellten Gruppen sowie folgende Aktionen (Spalte «Funktionen»):
[li] [b][i]Detaillierte Ansicht[/i][/b] – öffnet den Bereich «Benutzer», in dem die zur Gruppe gehörenden Benutzer angezeigt werden.
[li] [b][i]Vollständige Bearbeitung[/i][/b] – öffnet das Bearbeitungsformular der Gruppendaten.
[li] [b][i]Objekt löschen[/i][/b] – die Gruppe wird gelöscht.

Die Registerkarte «Hinzufügen» ermöglicht das Hinzufügen einer neuen Gruppe. Das Formular zum Hinzufügen einer Gruppe enthält:
[li] [b][i]Gruppenname[/i][/b] – dieser Name wird auf der Website bei der Anzeige von Benutzerinformationen angezeigt.
[li] [b][i]Beschreibung[/i][/b] – geben Sie eine Beschreibung ein, die die Gruppe charakterisiert; die Beschreibung wird auf der Website nicht angezeigt.
[li] [b][i]Spezielle Gruppe[/i][/b] – wenn die Gruppe speziell ist, werden Punkte nicht berücksichtigt und der Benutzer muss dieser Gruppe durch Bearbeitung seines Profils zugewiesen werden.
[li] [b][i]Minimal erforderliche Punktzahl[/i][/b] – geben Sie an, wie viele Punkte ein Benutzer sammeln muss, um Mitglied der erstellten Gruppe zu werden. Wenn angegeben ist, dass die Gruppe speziell ist, verschwindet dieses Feld.
[li] [b][i]Bild[/i][/b] – wählen Sie ein Bild, das die Gruppenmitglieder charakterisiert. Standardmäßig wird eine Liste von Rängen angeboten. Die Bilder in der Liste werden aus dem Verzeichnis images/ranks/ der Website geladen, daher kann die Auswahl möglicher Bilder bei Bedarf selbst erweitert werden.
[li] [b][i]Farbe[/i][/b] – die Farbe des Gruppennamens wird ausgewählt. Das heißt, auf der Website wird der Gruppenname in der gewählten Farbe angezeigt.
Vergessen Sie nach dem Ausfüllen nicht, die Schaltfläche «Speichern» zu drücken.[/justify]
