# Changelog Cache Directory ## Формат кеша Все файлы кеша хранятся в формате JSON с расширением `.json`. Имя файла: `SHA1(cache_key).json` Пример: `b7a3f8c9d2e1a4b5c6d7e8f9a0b1c2d3e4f5a6b7.json` ## Структура файла ```json { "meta": { "created_at": 1734460000, "expires_at": 1734460900, "etag": "\"W/abc123def456\"", "last_modified": "Wed, 17 Dec 2025 18:00:00 GMT", "url": "https://api.github.com/repos/OWNER/REPO/commits?per_page=100&page=1" }, "data": [ { "fullhash": "abc123def456...", "hash": "abc123d", "date": "2025-12-17 18:00", "author": "Eduard Laas", "email": "eduard@slaed.net", "subject": "Fix: Repair cache system", "body": "Detailed description...", "files": [] } ] } ``` ## Метаданные - `created_at` - Unix timestamp создания кеша - `expires_at` - Unix timestamp истечения кеша (created_at + TTL) - `etag` - ETag из HTTP ответа (для GitHub API) - `last_modified` - Last-Modified из HTTP ответа - `url` - URL запроса (для отладки) ## Очистка кеша Файлы автоматически удаляются при истечении TTL. Ручная очистка: удалить все `.json` файлы из этой директории. ## Безопасность - `index.html` - блокирует прямой доступ к директории - Права доступа: 0755 для директории, 0644 для файлов - Атомарная запись через временные файлы (`.tmp`) - Блокировка файлов при записи (LOCK_EX)
