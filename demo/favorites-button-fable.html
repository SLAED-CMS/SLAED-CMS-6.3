«В избранное» — круглая звезда перед заголовком

Замена чипа-сердца на круглую кнопку в визуале sl-but-mini/sl-dial: тёмная звезда bi-star, на hover — brand-link. Три состояния с подсказкой sl-tip.sl-float. HTMX-контракт getFavoriteButton() (id=rep<id><mod>, hx-swap="outerHTML", href с токеном) не меняется — меняется только разметка фрагмента.

1. Три состояния финал

Наведи или сфокусируй Tab-ом каждую кнопку — у всех есть подсказка. Серая звезда лимита не реагирует на клик (aria-disabled).

2. Эффект добавления — варианты «взрыва»

Кликни по любой звезде. Все варианты: pop звезды + свой характер разлёта. После взрыва кнопка переходит в состояние «в избранном» и показывает тост (сброс через 2,5 с для повторного теста).

3. Живой контекст: шапка статьи

Реальная разметка partials/view.html: звезда стоит на месте {{{ favorites }}} перед заголовком. Переключатель имитирует ответ сервера с лимитом.

4. Контракт для переноса

Что меняется, что нет

PHP (getFavoriteButton()) продолжает отдавать флаги is_favorite / is_favorite_on / is_favorite_off, href с токеном и HTMX-атрибуты. Меняются только фрагменты span.html/link.html: вместо sl-chip sl-chip-danger sl-favor* — круглая кнопка:

<span id="rep642news" class="sl-tip sl-float sl-fav">
  <a href="index.php?go=1&op=addFavorite&id=642&mod=news&token=…"
     class="sl-but-mini" hx-get="…" hx-target="#rep642news" hx-swap="outerHTML" hx-push-url="false"
     aria-label="Добавить в избранное"><i class="bi bi-star"></i></a>
  <div class="sl-float-panel">Добавить в избранное</div>
</span>
