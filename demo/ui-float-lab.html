SLAED · Float UI — вариант на изучение

Дизайн-вариант на базе кнопки sl-float (.sl-but-mini): мягкая серая кнопка с белой иконкой, которая «зажигается» синим при наведении / когда открыта её панель. Новый размер — 26×26. Дропдауны — на настоящем механизме .sl-float + slaed.js (тёмная всплывающая панель).
