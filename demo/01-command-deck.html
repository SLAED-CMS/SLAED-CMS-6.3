Page cache / 8.0 · rebuild → body + sidecar
HITfresh body + verified sidecar → подстановка dynamic regions → response. Модуль и шаблон не строятся заново.
MISSsingle-flight rebuild → kernel → module / parser → template → body + sidecar → response.
BYPASSadmin, POST, авторизованный пользователь или неразрешённый маршрут → live render, без записи page cache.
cache=1 — главная + список новостей. cache=2 — только главная. Parser cache — отдельный нижний слой.
