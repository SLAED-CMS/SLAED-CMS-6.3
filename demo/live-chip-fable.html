Live-чип блоков — эфир, пауза, стоп

Круглый информ-чип в правом верхнем углу блока на штатной механике sl-tip.sl-float — расширение «Play»-глифа из voting-widget.html. PHP отдаёт флаги is_live / is_paused / is_closed + интервал и endpoint; шаблон рисует чип; HTMX-триггер every Ns висит на контейнере блока, «Пауза» его снимает. Здесь автообновление имитируется JS-таймером с теми же данными.

3. Вживую: блоки «Голосование» и «Пользователи»

Демо-интервал 10 с (в системе — live_every, глобальный конфиг live_u). Голоса и счётчики «приходят» по таймеру; «обновлено N с назад» тикает; «Пауза» в панели чипа останавливает поток — чип переключается в warning-состояние.

4. Контракт для переноса

PHP → шаблон 
// blocks/voting.php, blocks/user_info.php передают:
'is_live' => true, 'is_paused' => false, 'is_closed' => false,
'live_every' => 30, 'live_query' => 'name=voting&op=getVotingView&id=7',
'live_label' => _LIVEON, 'pause_label' => _LIVEPAUSE, ...

<!-- шаблон блока: чип + HTMX-триггер на контейнере -->
<div hx-get="index.php?{{ live_query }}" hx-trigger="every {{ live_every }}s"
     hx-swap="innerHTML" hx-push-url="false">…</div>
<!-- «Пауза» снимает hx-trigger (htmx.trigger + removeAttribute), чип меняет класс -->
