«Поделиться» — веер sl-dial в мета-строке

Быстрые действия в штатном веере sl-dial: Telegram, WhatsApp, ВКонтакте, QR, «Копировать» и «Ещё» (лист со всеми сетями). Клик по сети открывает её реальное окно «Поделиться» с каноническим URL (getSeoUrl() + homeurl). QR — настоящий, сканируемый: самодостаточный генератор (порт Nayuki, byte-mode UTF-8, EC L, Reed–Solomon, выбор маски по штрафу) без внешних библиотек. Это отдельная функция от getNetworks() (там — вход через соцсети).

Канонический URL сейчас:

1. Веер в мета-строке статьи финал

Реальная разметка partials/view.html: веер стоит в sl-meta-actions перед якорным номером. Раскрытие по hover и по клику (тач). Все действия читают текущий канонический URL — переключи режим сверху и проверь.

Порядок быстрых действий в веере: от тогла наружу — Telegram, WhatsApp, ВКонтакте, QR, Копировать, Ещё. «Копировать» подменяет иконку на галочку и красит кнопку в success; «Ещё» открывает лист со всеми сетями; QR — модалку с крупным сканируемым кодом.

2. Альтернативные паттерны

B. Ряд чипов (всегда раскрыт)

Проще, но занимает место в мета-строке постоянно.

C. Одна кнопка → сразу лист

Минимум UI, но +1 клик до популярных сетей. Хорош на мобильном.

D. Системный share (Web Share API)

Нативный лист ОС на телефонах; на десктопе не везде доступен — нужен фолбэк на наш лист.

4. QR-код

Генератор в ~130 строках JS: byte-mode + UTF-8, EC-level L, Reed–Solomon, 8 масок с выбором по штрафу, рендер в SVG. Кодируется канонический URL текущего режима — отсканируй камерой, статья откроется. Ниже код сгенерирован прямо на странице.

PHP → шаблон 
// PHP отдаёт только данные (без HTML/классов):

'share_title' => $title,
'share_label' => _SHARE, 'copy_label' => _COPYLINK, 'qr_label' => _QRCODE, ...

// Шаблон владеет веером (fragments/dial.html + share-флаг), листом и модалками.
