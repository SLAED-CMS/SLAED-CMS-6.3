Категории · Drag-and-Drop вместо стрелок

Тот же принцип, что в блоках: стрелки убраны, перетаскивание за ручку, сохранение без перезагрузки (зелёная вспышка = имитация ответа). Группы — по модулям. Все варианты живые — таскай.

Вариант 1 — как в блоках: группы по модулям, плоский список

Точная копия утверждённого вида блоков: группы-заголовки «Статьи», «Новости», «Форум»; иерархия показана как сейчас — полным путём «Родитель / Дочка»; перетаскивание только внутри своего модуля, чужой модуль краснеет. Минимальная правка кода — переиспользуются все классы и JS блоков.

Плюс: единый UX с блоками, минимум нового кода. Минус: подкатегории вперемешку с родителями (как и сейчас со стрелками).

Вариант 2 — дерево с отступами, перенос внутри родителя

Иерархия видна структурой: подкатегории с отступом и веткой └ вместо склейки названий. Перетаскивать можно только среди соседей по родителю (siblings) — дочки переезжают вместе с родителем автоматически. Попытка бросить в чужой уровень — красная подсветка.

Плюс: структура читается сразу, порядок «семьями». Минус: правка построения списка глубже (сортировка деревом, перенос поддерева).

Вариант 3 — дерево + смена родителя (фантазийный)

Как вариант 2, плюс два типа drop-зон: между строк = изменить порядок, прямо на строку (фиолетовая рамка) = сделать подкатегорией этой категории. Перенос в корень — бросить на заголовок модуля. Так мышкой решается и порядок, и вложенность — без формы редактирования.

Плюс: полное управление структурой одним жестом. Минус: самый сложный вариант (изменение parent + пересчёт порядков + права/циклы), легко бросить не туда.

Вариант 4 — вариант 1 + сворачиваемые группы модулей

Дополнение для длинных списков: клик по заголовку модуля сворачивает/разворачивает его группу. Работает с любым из вариантов выше.

Плюс: длинный список категорий 5+ модулей становится обозримым. Минус: ещё один клик до содержимого.
