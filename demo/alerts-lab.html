SLAED Alerts Lab

5. Анимации появления

Шесть модификаторов движения. Нажмите «Проиграть заново», чтобы повторить.

slide-in-right

Въезд справа — для toast.

slide-in-left

Въезд слева.

slide-in-down

Спуск сверху.

slide-in-up

Подъём снизу.

pop / bounce

Упругое появление.

flip-in

Переворот по оси X.

7. Анимированные иконки внутри уведомлений

Иконка получает зацикленную микро-анимацию через утилиту .sl-ico-* на теге <i class="bi">. Те же классы автоматически применяются к toast-уведомлениям ниже.

pulse — пульсация

Плавное увеличение и возврат масштаба.

spin — вращение

Непрерывный поворот — процесс, синхронизация.

shake — дрожание

Лёгкая тряска для привлечения внимания.

beat — сердцебиение

Двойной импульс масштаба, как пульс.

ring — звонок

Покачивание колокольчика вокруг верхней точки.

bounce — отскок

Короткий подпрыгивающий акцент.
