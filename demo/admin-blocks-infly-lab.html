Блоки · маркировка свободных (infly)

Пункт 8 пожеланий: в списке блоков не видно, какие блоки свободные (исключены из вывода позиций, выводятся только явным вызовом из PHP-кода по id/файлу, метка infly в поле which). В примерах: «Форум внизу» — свободный, «Реклама в статье» — свободный фиксированный (infly,flyfix). Все варианты требуют одной и той же правки PHP: добавить a.which в SELECT списка — отличается только вывод.

Вариант 1 — чип рядом с позицией

Существующий sl-chip с новым акцентным тоном sl-chip-accent в колонке «Позиция». Для flyfix — чип с замком. Позиция остаётся видимой (для свободных она справочная).

Плюс: словарь чипов уже общий для тем, ноль нового CSS кроме тона. Минус: колонка «Позиция» становится шире.

Вариант 2 — только иконка

Компактный маркер sl-infly-icon (bi-wind) после бейджа позиции, расшифровка — в title (как у бейджей позиций). flyfix — bi-pin-angle-fill.

Плюс: самый компактный, таблица не растёт. Минус: смысл виден только по наведению.

Вариант 3 — отдельная колонка «Размещение»

Колонка «Позиция» переименовывается в «Размещение»: для обычных блоков — бейдж позиции, для свободных — акцентный чип вместо позиции (она для них всё равно не действует: реальную позицию задаёт вызов в шаблоне).

Плюс: честная модель — не показываем неработающую позицию. Минус: теряется сортировка по фактической колонке bpos.

Вариант 4 — акцентная полоса строки

Строка свободного блока получает полосу слева (sl-row-infly) и лёгкую акцентную заливку (sl-row-infly-tint) + легенда под таблицей. Маркер виден периферийным зрением на длинном списке.

 Свободные блоки — выводятся явным вызовом из кода, позиция и порядок на них не действуют.

Плюс: заметно сразу. Минус: конкурирует с ховером строк и статусными цветами.

Вариант 5 — отдельная группа внизу списка

«Отдельная группа» из пожелания буквально: свободные блоки выносятся из позиций в собственную секцию sl-group-row в конце списка. Внутри секции колонки «Позиция» и «Положение» пустые — для честности.

Плюс: полное разделение, ничего не смешивается. Минус: ломает сквозную сортировку списка, самая большая правка.

Вариант 6 — фильтр-чипы над таблицей

Маркировка как в варианте 1 + переключатель sl-filter-chips: Все / Позиционные / Свободные. Живой — пощёлкай. Фильтр решает и задачу «увидеть только свободные» на больших списках.

Все Позиционные Свободные

Плюс: и маркер, и инструмент. Минус: JS + новый UI-элемент над таблицей.

Комбинация — вариант 3 + вариант 5

Свободные блоки вынесены в собственную секцию sl-group-row внизу списка, а колонка называется «Размещение»: у позиционных — бейдж позиции, у свободных — акцентный чип. «Положение» у свободных пустое — порядок на них не действует, реальную точку задаёт вызов в шаблоне.

Итог: разделение + честная колонка — не показываем неработающие позицию и порядок.
