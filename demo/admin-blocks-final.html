Блоки · итоговый вид списка

Объединение выбранных комбинаций: группы по позициям + ручка в «Положении» (DnD-лаборатория, в2+в5) и свободные блоки отдельной группой с честным размещением (infly-лаборатория, в3+в5). Перетаскивание живое — только внутри своей позиции, чужая группа краснеет, после дропа перенумерация и вспышка сохранения. Свободные блоки (infly/flyfix) не перетаскиваются: из обычного вывода позиций они исключены и выводятся только явным вызовом getBlocks(позиция, id|файл) из PHP-кода темы или модуля — в колонке «Позиция» у них чип с иконкой.

Колонка «Позиция» = порядок внутри группы (грип + номер), у свободных блоков вместо номера — чип: ветер = свободный, булавка = свободный фиксированный.
