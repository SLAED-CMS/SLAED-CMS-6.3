Блоки · Drag-and-Drop вместо стрелок

Пункт 6 пожеланий: колонка со стрелками sl-move-controls удалена во всех вариантах. Перетаскивание работает по-настоящему — попробуй. Порядок «Положение» перенумеровывается, зелёная вспышка = имитация сохранения (htmx-ответ). Перетаскивание разрешено только внутри одной позиции (Право / Вниз).

Вариант 1 — колонка-ручка

Отдельная узкая колонка с грипом bi-grip-vertical на месте бывших стрелок. Тянуть можно только за ручку, строка при этом полупрозрачна, цель показана акцентной линией сверху/снизу.

Плюс: явная зона захвата, случайно не утащишь строку. Минус: лишняя колонка.

Вариант 2 — ручка в колонке «Положение»

Без новой колонки: грип встаёт слева от номера в существующей ячейке «Положение» (там, где раньше был colspan=2 с числом и стрелками). Самый компактный вариант.

Плюс: таблица не меняет ширину, смысл колонки сохранён. Минус: маленькая зона захвата.

Вариант 3 — перетаскивание всей строки

Ручки нет вообще — вся строка cursor: grab. Колонка «Положение» показывает только номер. Максимально просто, но конфликтует с выделением текста и кликами по ссылкам в строке.

Плюс: большая зона захвата, ноль лишней разметки. Минус: легко дёрнуть строку случайно.

Вариант 4 — ручка + слот-плейсхолдер

Как вариант 1, но вместо тонкой линии строки раздвигаются и место вставки показано пунктирным слотом sl-drop-slot. Нагляднее на длинных списках.

Плюс: видно «куда встанет» ещё до дропа. Минус: список прыгает по высоте.

Вариант 5 — группы по позициям + ручка

Список разбит строками-заголовками sl-group-row по позициям (Право, Вниз) — колонка «Позиция» больше не нужна. Перетаскивание в чужую группу подсвечивается красным и запрещено. Бонус: та же группировка решает читаемость длинного списка.

Плюс: граница «внутри позиции» видна сама по себе. Минус: самая большая правка разметки списка.

Комбинация — вариант 2 + вариант 5

Группы по позициям (sl-group-row, без колонки «Позиция») + ручка внутри ячейки «Положение» вместо отдельной колонки. Ни одной лишней колонки: слева от номера — грип, граница перетаскивания совпадает с границей группы, чужая группа краснеет.

Итог: самая компактная таблица из всех вариантов — колонок меньше, чем сейчас со стрелками.
