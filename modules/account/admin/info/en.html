[justify]The «Users» section is designed for managing website users.

[b][color=green]User Management[/color][/b]
Management of existing users is done in the «Home» tab.
[li] [b][i]Full Edit[/i][/b] – changing user information.
[li] [b][i]Delete Object[/i][/b] – deleting the user account.
[li] [b][i]Block IP Address[/i][/b] – blocking the user's IP address. Management of blocked IP addresses is done in the «Security» section (where you can also set the message displayed when attempting to access from a blocked IP address).

[color=orangered][b][i]User Search[/i][/b][/color]
Search fields are displayed above the user list on the right:
[li] In the first field, select the field to search by (e.g., Nickname).
[li] In the second field, enter the search value.
To start the search, click the «OK» button.

[hr][color=blue][b]Please Note![/color][/b]
[li] When editing a user account, if the «Send notification to user's E-Mail» option is enabled, an email will be sent to the user according to the template each time the account is edited.
[li] To view the registration date and time and the last login, hover the mouse cursor over the (i) icon next to the desired user in the first column of the user list.[hr]
[b][color=green]Adding a User[/color][/b]
To add a new user, go to the «Add» tab and fill in the information about the new user.
Explanations for some form fields:
[li] [b][i]Activate custom menu?[/i][/b] – The user can create their own menu by setting links to menu items using the editor.
[li] [b][i]Points[/i][/b] – In this field, you can set the initial number of points. For details on point calculation rules, see the Information for the «Groups» section.
[li] [b][i]Moderator check of user messages?[/i][/b] – All user messages (comments, topics, and forum posts) will be published only after moderator review.
[li] [b][i]Website design theme[/i][/b] – This field is displayed only if multiple design themes are installed. The user can specify which theme they prefer.
[hr][color=blue][b]Please Note![/color][/b]
When adding a user, you must specify: nickname, e-mail, password, and password confirmation.[hr][b][color=green]New Users[/color][/b]
The «New Users» tab displays a list of registered users who have not activated their account.
The administrator can activate the user's account (Activate) or delete it (Delete Object).
[b][color=green]Reset Parameters[/color][/b]
In this tab, you can reset points, ratings, warnings, and signatures for all system users.
[hr][color=red][b][i]Warning![/b]
Use this tab carefully – all user ratings (points) will be deleted and set to zero.[/i][/color][hr]
[b][color=green]Configuration Management[/color][/b]
The «Configurations» tab configures the rules for how the website works with users (registration and account settings).
Explanations for some configuration parameters:
[li] [b][i]Greeting type for anonymous visitors[/i][/b] – Whether a login form or a link to registration and login will be displayed below the website logo.
[li] [b][i]Registration without E-Mail confirmation?[/i][/b] – Whether users need to confirm their email by clicking a link sent to their email.
[li] [b][i]Allow users to change the number of publications?[/i][/b] – Whether users can change the specified number of publications on the home page when configuring their profile.
[li] [b][i]Activate registration of new users?[/i][/b] – Whether new users can register on the project. This function is typically used to temporarily disable registration.
[li] [b][i]Activate uLogin service for authorization via social networks?[/i][/b] – Allows users to log in through social networks such as: Odnoklassniki, Google, Yandex, VKontakte, Facebook, and many others. The uLogin service is used, which provides unified access to your website without additional registration.
[li] [b][i]Rule confirmation during user registration?[/i][/b] – Whether the user must agree to the website rules during registration.
[li] [b][i]User registration rules[/i][/b] – Text containing the registration rules for the website. For example, «By agreeing to these rules, I confirm that I am over 13 years old.»
[li] [b][i]uLogin service code template for authorization via social networks[/i][/b] – JavaScript code provided by the uLogin service, which specifies parameters, settings, and styles for the login button block. The code template uses the [url] variable, which is automatically replaced by the system with your redirect address after successful authorization.
[hr][color=blue][b]Please Note![/b][/color]
[li] The [url] attribute is a required parameter. If removed, website authorization will not work.
[li] If the user's password is changed, authorization through social networks under the previous account will not be possible.
[li] For such users, password change and recovery through standard system procedures are also not possible.[hr]
[li] [b][i]Forbidden names and E-Mails[/i][/b] – If a user specifies a name or email from the given list, the system will display an appropriate warning. Forbidden names and emails are specified separated by commas, without spaces after commas.[/justify]
