[justify]La section «Utilisateurs» est destinée à la gestion des utilisateurs du site.

[b][color=green]Gestion des utilisateurs[/color][/b]
La gestion des utilisateurs existants s'effectue dans l'onglet «Accueil».
[li] [b][i]Édition complète[/i][/b] – modification des informations de l'utilisateur.
[li] [b][i]Supprimer l'objet[/i][/b] – suppression du compte utilisateur.
[li] [b][i]Bloquer l'adresse IP[/i][/b] – blocage de l'adresse IP de l'utilisateur. La gestion des adresses IP bloquées s'effectue dans la section «Sécurité» (où vous pouvez également définir le message affiché lors d'une tentative d'accès depuis une adresse IP bloquée).

[color=orangered][b][i]Recherche d'utilisateurs[/i][/b][/color]
Les champs de recherche sont affichés à droite au-dessus de la liste des utilisateurs :
[li] Dans le premier champ, sélectionnez le champ de recherche (par exemple, Pseudo).
[li] Dans le deuxième champ, entrez la valeur recherchée.
Pour lancer la recherche, cliquez sur le bouton «OK».

[hr][color=blue][b]Attention ![/color][/b]
[li] Lors de la modification d'un compte utilisateur, si l'option «Envoyer une notification à l'E-Mail de l'utilisateur» est activée, un e-mail sera envoyé à l'utilisateur selon le modèle à chaque modification.
[li] Pour afficher la date et l'heure d'inscription et de dernière connexion, passez le curseur de la souris sur l'icône (i) à côté de l'utilisateur souhaité dans la première colonne de la liste des utilisateurs.[hr]
[b][color=green]Ajout d'un utilisateur[/color][/b]
Pour ajouter un nouvel utilisateur, allez dans l'onglet «Ajouter» et remplissez les informations sur le nouvel utilisateur.
Explications pour certains champs du formulaire :
[li] [b][i]Activer le menu personnalisé ?[/i][/b] – L'utilisateur peut créer son propre menu en définissant des liens vers les éléments du menu via l'éditeur.
[li] [b][i]Points[/i][/b] – Dans ce champ, vous pouvez définir le nombre initial de points. Pour plus de détails sur les règles de calcul des points, consultez les Informations de la section «Groupes».
[li] [b][i]Vérification par le modérateur des messages de l'utilisateur ?[/i][/b] – Tous les messages de l'utilisateur (commentaires, sujets et messages du forum) seront publiés uniquement après vérification par le modérateur.
[li] [b][i]Thème de design du site[/i][/b] – Ce champ n'est affiché que si plusieurs thèmes de design sont installés. L'utilisateur peut indiquer quel thème il préfère.
[hr][color=blue][b]Attention ![/color][/b]
Lors de l'ajout d'un utilisateur, vous devez obligatoirement spécifier : pseudo, e-mail, mot de passe et confirmation du mot de passe.[hr][b][color=green]Nouveaux utilisateurs[/color][/b]
L'onglet «Nouveaux utilisateurs» affiche une liste des utilisateurs inscrits qui n'ont pas activé leur compte.
L'administrateur peut activer le compte de l'utilisateur (Activer) ou le supprimer (Supprimer l'objet).
[b][color=green]Réinitialiser les paramètres[/color][/b]
Dans cet onglet, il est possible de réinitialiser les points, les notes, les avertissements et les signatures de tous les utilisateurs du système.
[hr][color=red][b][i]Attention ![/b]
Utilisez cet onglet avec précaution – toutes les notes des utilisateurs (points) seront supprimées et remises à zéro.[/i][/color][hr]
[b][color=green]Gestion des configurations[/color][/b]
L'onglet «Configurations» permet de configurer les règles de fonctionnement du site avec les utilisateurs (paramètres d'inscription et de compte).
Explications pour certains paramètres de configuration :
[li] [b][i]Type d'accueil pour les visiteurs anonymes[/i][/b] – Si un formulaire de connexion ou un lien vers l'inscription et la connexion sera affiché sous le logo du site.
[li] [b][i]Inscription sans confirmation E-Mail ?[/i][/b] – Si les utilisateurs doivent confirmer leur e-mail en cliquant sur un lien envoyé à leur adresse e-mail.
[li] [b][i]Autoriser les utilisateurs à modifier le nombre de publications ?[/i][/b] – Si les utilisateurs peuvent modifier le nombre de publications spécifié sur la page d'accueil lors de la configuration de leur profil.
[li] [b][i]Activer l'inscription de nouveaux utilisateurs ?[/i][/b] – Si les nouveaux utilisateurs peuvent s'inscrire sur le projet. Cette fonction est généralement utilisée pour désactiver temporairement l'inscription.
[li] [b][i]Activer le service uLogin pour l'authentification via les réseaux sociaux ?[/i][/b] – Permet aux utilisateurs de se connecter via des réseaux sociaux tels que : Odnoklassniki, Google, Yandex, VKontakte, Facebook et bien d'autres. Le service uLogin est utilisé, offrant un accès unifié à votre site sans inscription supplémentaire.
[li] [b][i]Confirmation des règles lors de l'inscription ?[/i][/b] – Si l'utilisateur doit accepter les règles du site lors de l'inscription.
[li] [b][i]Règles d'inscription des utilisateurs[/i][/b] – Texte contenant les règles d'inscription sur le site. Par exemple, «En acceptant ces règles, je confirme que j'ai plus de 13 ans.»
[li] [b][i]Modèle de code du service uLogin pour l'authentification via les réseaux sociaux[/i][/b] – Code JavaScript fourni par le service uLogin, qui spécifie les paramètres, les réglages et les styles du bloc de boutons de connexion. Le modèle de code utilise la variable [url] qui est automatiquement remplacée par le système par votre adresse de redirection après une authentification réussie.
[hr][color=blue][b]Attention ![/b][/color]
[li] L'attribut [url] est un paramètre obligatoire. S'il est supprimé, l'authentification sur le site ne fonctionnera pas.
[li] En cas de changement de mot de passe, l'authentification via les réseaux sociaux avec le compte précédent sera impossible.
[li] Pour ces utilisateurs, le changement et la récupération du mot de passe via les procédures standard ne sont pas non plus possibles.[hr]
[li] [b][i]Noms et E-Mails interdits[/i][/b] – Si un utilisateur spécifie un nom ou un e-mail de la liste donnée, le système affichera un avertissement approprié. Les noms et e-mails interdits sont spécifiés séparés par des virgules, sans espaces après les virgules.[/justify]
