# RSS-каналы

Раздел **«RSS-каналы»** (`admin.php?name=rss`) позволяет управлять конфигурацией RSS-потоков сайта и добавлять в систему каналы сторонних ресурсов для просмотра пользователями.

---

## 1. Что такое RSS и для чего он нужен

RSS — стандартный веб-формат для трансляции данных между сайтами и агрегаторами новостей. Использование RSS позволяет:
* Другим сайтам и программам получать актуальные новости вашего ресурса.
* Вашим пользователям подписаться на обновления через удобные им программы-агрегаторы.

### Прямой доступ к RSS:
Экспортный файл вашего сайта всегда доступен по адресу:
```
https://ваш_сайт/index.php?go=rss
```

---

## 2. Управление каналами (вкладка «RSS-каналы»)

Каналы бывают двух видов и перечислены в одной форме:

| Тип | Описание |
|---|---|
| **Стандартный** | Канал вашего сайта. Добавляется в `<head>` страниц для обнаружения поисковиками и агрегаторами |
| **Сторонний** | Канал другого сайта. Отображается в публичном разделе «RSS-каналы» для просмотра посетителями |

Управление строками в форме:
* Для добавления нового канала нажмите **«+»** рядом с последним.
* Для удаления незаполненной строки нажмите «+» рядом с **предыдущей** строкой.
* Для удаления существующего сохранённого канала установите значение `0` в поля этой строки и сохраните.

> [!IMPORTANT]
> Все изменения применяются только после нажатия кнопки **«Сохранить изменения»**.

---

## 3. Конфигурации

* **Минимальное/максимальное количество по умолчанию:** Лимит записей, передаваемых в одном RSS-потоке.
* **Шаблон оформления:** HTML-шаблон для вывода записей в RSS. Поддерживаемые переменные:
  * `[title]` — заголовок публикации
  * `[date]` — дата публикации
  * `[guid]` — прямая ссылка на публикацию
  * `[description]` — содержание записи
* **Активировать вывод каналов на страницах сайта?** — управляет отображением иконки/ссылки на RSS в интерфейсе браузера (в URL-строке и шапке страницы).
* **Активировать просмотр RSS-каналов?** — разрешает ли пользователям просматривать список добавленных каналов в публичном разделе «RSS-каналы» и на своей домашней странице профиля.
