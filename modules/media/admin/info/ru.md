# Медиа каталог

Раздел **«Медиа каталог»** (`admin.php?name=media`) предназначен для публикации описаний и ссылок на медиа-файлы: фильмы, музыкальные альбомы, записи подкастов и другой мультимедийный контент.

> [!TIP]
> Категории медиа-каталога (по жанрам, исполнителям и т.д.) создаются в разделе **«Категории»** блока «Администратор».

---

## 1. Главная (Список записей)

В основной вкладке отображается перечень опубликованных медиа-материалов:
* **Подробный просмотр:** Страница медиа-файла в публичном виде.
* **Полное редактирование:** Форма редактирования описания и ссылок.
* **Удаление:** Удаляет запись.

---

## 2. Добавление и модерация

### Добавление (вкладка «Добавить»):
При добавлении нового материала можно указать несколько ссылок для скачивания одного файла (например, с разных файлообменников). Управление ссылками:
* **Добавить ссылку:** Нажмите значок «+» рядом с последней добавленной ссылкой.
* **Удалить пустую ссылку:** Нажмите «+» рядом с полем, стоящим _перед_ незаполненной строкой.

> [!NOTE]
> Для проверки внешнего вида записи перед публикацией используйте «Предварительный просмотр» → «Отправить» → «ОК».

### Новые (вкладка «Новые»):
Медиа-материалы, добавленные пользователями или гостями, ожидают одобрения здесь. Для публикации откройте форму редактирования и сохраните запись.

---

## 3. Недоступные медиа-файлы

Аналогично каталогу файлов: посетители могут сообщать о нерабочих ссылках. Такие записи выводятся в отдельной вкладке для проверки или игнорирования администратором.

---

## 4. Конфигурации

* **Языки для выбора:** Список возможных языков (через запятую), из которых можно выбрать при добавлении медиа-файла.
* **Форматы для выбора:** Список форматов (например: `MP4,AVI,MKV,MP3`).
* **Качество для выбора:** Уровни качества (например: `HD,FullHD,4K,CAMRip`).
* **Максимальное количество ссылок:** Лимит ссылок для скачивания на одну запись в каталоге.
* **Разрешить добавлять медиа-файлы?** / **Разрешить гостям добавлять?**
* **Возможность сообщать о недоступных файлах?**
* **Разрешить гостям видеть ссылки на загрузку?** — если «Нет», ссылки для скачивания видны только авторизованным пользователям.
