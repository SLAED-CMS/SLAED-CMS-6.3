# Магазин

Раздел **«Магазин»** (`admin.php?name=shop`) — полноценный модуль электронной коммерции для организации каталога товаров, приёма и обработки заказов, а также управления партнёрской программой с реферальными вознаграждениями.

---

## 1. Каталог продуктов (вкладка «Продукты»)

### Подраздел «Активные» / «Неактивные»:
Товары разделены на две очереди. Администратор может переключать их статус:
* **Деактивировать** — убирает товар с сайта без удаления записи из системы.
* **Активировать** — возвращает товар в публичный каталог.

Поддерживается **групповое управление**: отметьте нужные товары флажком и выберите действие в поле «Действие с отмеченными» → «ОК».

### Добавление товара вручную (подраздел «Добавить»):
* **Связанные темы:** Товары из указанных категорий будут отображаться в блоке «Похожие товары» при просмотре данного.
* **Дата публикации:** Товар появится в каталоге не ранее указанной даты.
* **Опросы:** Привязка опроса (из модуля «Опросы»), который показывается на странице товара.
* **Зафиксировать:** Закрепляет товар вверху каталога, игнорируя дату добавления.

---

## 2. Импорт и Экспорт каталога

Вкладка **«Экспорт/Импорт»** позволяет работать с данными в формате CSV (совместим с 1С и Excel).

### Порядок первого импорта:
1. **Экспортируйте** один тестовый товар — это создаст CSV-шаблон с корректными заголовками колонок.
2. Заполните шаблон данными вручную или экспортируйте из 1С/учётной системы.
3. Загрузите файл в папку `uploads/shop/temp/`.
4. В подразделе **«Импорт»** выберите загруженный файл и запустите импорт.

---

## 3. Управление заказами (вкладка «Клиенты»)

Заказы проходят через следующие статусы:

| Статус | Описание |
|---|---|
| **Новые** | Только что поступившие заказы, ещё не просмотренные |
| **Неактивные** | Просмотренные/обработанные заказы (после открытия редактора) |
| **Активные** | Заказы, принятые в работу администратором |

> [!IMPORTANT]
> После первого открытия карточки заказа он **автоматически** перемещается из «Новые» → «Неактивные». Для принятия в работу нажмите «Активировать» — клиент увидит обновлённый статус в своём личном кабинете в разделе «Клиент».

### Поиск по заказам:
Форма поиска над вкладками позволяет искать по: №, Нику, ФИО, E-mail, Домену сайта.

## 4. Партнёрская программа (вкладка «Партнёры»)

Позволяет пользователям-партнёрам привлекать клиентов через реферальные ссылки и получать процент вознаграждения.

* **Уровневые проценты:** В конфигурациях можно задать до 3 уровней вознаграждения (например: 0 клиентов → 3%, 3 клиента → 5%, 10 клиентов → 7%).
* **Управление партнёрами:** Список «Новые» → одобрение/активация → «Активные». В карточке активного партнёра указывается выплаченная сумма.
* **Cookie-срок:** Сколько дней система «помнит», что пользователь пришёл по партнёрской ссылке. Если в этот период он совершит заказ, клиент будет засчитан партнёру.

---

## 5. Конфигурации

* **Основная валюта:** Символ или название валюты (например: `₽`, `EUR`, `грн`).
* **E-Mail для заказов:** Куда приходят уведомления о новых заказах.
* **Дублировать подтверждение на E-Mail клиента?** — отправлять ли клиенту письмо после оформления заказа.
* **Время хранения Cookies корзины** (в днях): Как долго сохраняются добавленные товары при закрытии браузера.
* **Информационные тексты:** Текст «Информация об оплате» (показывается после отправки заказа), «Информация для клиентов», «Информация для партнёров» и «Информация об авторе» (выводится в счёте).

> [!TIP]
> Категории продуктов создаются в разделе **«Категории»** блока «Администратор».
