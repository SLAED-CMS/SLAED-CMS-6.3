# Пожертвования / Платежи (Money)

Раздел **«Пожертвования»** предназначен для управления денежными сборами на сайте. Модуль принимает и хранит платежные данные, позволяет администраторам обрабатывать поступления и формировать счета в формате HTML.

---

## 1. Список поступлений (Главная)

В основной вкладке отображается таблица всех полученных платёжных заявок.

| Колонка | Описание |
|---|---|
| **ID** | Номер заявки |
| **Сумма** | Указанная плательщиком сумма в EUR |
| **E-Mail** | Адрес плательщика. При наведении на ссылку — подсказка с дополнительными данными формы, комментарием и браузером |
| **IP** | IP-адрес с геолокацией |
| **Дата** | Время создания заявки |
| **Статус** | Активирован / не активирован |

Для каждой заявки доступны действия: **Активировать/Деактивировать**, **Выставить счёт** (открывает печатную HTML-версию счёта), **Полное редактирование**, **Удаление**.

> [!IMPORTANT]
> При **активации** заявки система автоматически отправляет на e-mail плательщика уведомление с текстом, заданным в поле «Информация после оплаты» (конфигурации).

---

## 2. Добавление / Редактирование заявки

Форма во вкладке **«Добавить»** позволяет вручную создать или отредактировать платёжную запись:
* **Сумма** (обязательное поле, числовое)
* **E-Mail плательщика** (обязательное поле)
* **Дополнительные поля формы** — динамически формируются из списка полей, заданного в настройках («Поля формы»).
* **Комментарий** — произвольная заметка к заявке.
* **Дата** — время создания заявки (можно скорректировать вручную).

---

## 3. Конфигурации

* **Процент комиссии (%):** Сумма, вычитаемая из поступившего платежа при формировании счёта (например, комиссия платёжной системы).
* **Курс EUR → USD / EUR → RUB:** Используется для автоматического расчёта суммы счёта в альтернативных валютах.
* **Ссылка на реквизиты:** URL-адрес страницы с платёжными реквизитами, которая показывается пользователю после оформления платёжной заявки.
* **E-Mail для уведомлений:** Адрес, на который приходят уведомления о новых поступлениях (если оставить пустым — используется e-mail главного администратора).
* **Поля формы:** Список дополнительных полей, отображаемых в форме платёжной заявки (вводится через запятую без пробелов; например: `ФИО,Телефон,Назначение платежа`).
* **Количество записей на странице** и **в навигации** (пагинация).
* **Показывать форму анонимам?** / **Показывать форму пользователям?** / **Показывать форму администраторам?**
* **Текст на странице модуля** — вводный текст, отображаемый на публичной странице перед формой.
* **Информация после оплаты** — текст письма, которое получит плательщик после активации его заявки администратором.
* **Текст для счёта** — дополнительная информация, добавляемая на страницу выставляемого счёта.
* **Информация об авторе/получателе** — данные организации или физического лица, отображаемые в шапке счёта.
