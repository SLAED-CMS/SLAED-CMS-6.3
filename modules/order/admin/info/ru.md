# Форма заказа

Раздел **«Форма заказа»** предназначен для создания на сайте страницы с формой приёма заказов и последующей обработки поступивших заявок.

---

## 1. Главная (Список заказов)

В основной вкладке отображается таблица всех поступивших заказов.
* **Активация:** Если в конфигурациях включена проверка администратором, новые заказы будут иметь статус «Деактивирован». В колонке «Функции» для таких заказов появится кнопка **«Активировать»**.
* **Информация о заказе:** При наведении курсора на иконку `(i)` слева от E-Mail клиента всплывает окно с подробными данными заказа.

---

## 2. Добавление заказа (вкладка «Добавить»)

Используется для ручного внесения заказов в систему администратором (например, если заказ был принят по телефону, но его необходимо зафиксировать в базе для дальнейшей обработки другими сотрудниками).

---

## 3. Конфигурации

* **E-Mail для заказов:** Адрес, на который будут приходить уведомления о новых заявках.
* **Активировать форму заказа?** — включает или отключает отображение публичной формы на сайте.
* **Проверка и подтверждение администратором:**
  * **Да** — все заказы поступают в статусе «Деактивирован». После того как администратор нажмёт «Активировать», клиенту автоматически уйдёт письмо с подтверждением.
  * **Нет** — заказы сразу считаются принятыми и активными.
* **Дублировать заказы на E-Mail?** — отправлять ли полную копию данных заказа на почту администратора.
* **Текст в модуле:** Приветственное сообщение или инструкция, выводимая над формой заказа.
* **Информация после заказа:** Текст, который клиент видит на экране сразу после успешной отправки формы.
* **Информация для E-Mail:** Текст письма, которое отправляется клиенту в момент активации его заказа.

---

## 4. Дополнительные поля

По умолчанию форма содержит только поля «E-Mail» и «Комментарий». Вы можете добавить любое количество дополнительных полей (например: «Телефон», «Адрес доставки», «Выбор модели») в разделе **«Дополнительные поля»** блока «Администратор». Эти поля будут автоматически интегрированы в форму модуля «Заказ».
