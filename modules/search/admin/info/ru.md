# Поиск

Модуль обеспечивает полнотекстовый поиск по сайту. Настройки определяют, в каких модулях выполняется поиск, сколько результатов отображается и как обрабатываются запросы.

## Настройки

| Параметр | Описание |
|---|---|
| **Поиск в модулях** | Список модулей, по которым выполняется поиск. Для выбора нескольких — удерживайте `Ctrl` |
| **Минимум символов** | Минимально допустимое количество символов в поисковом запросе. Действует также в функции автодополнения при поиске пользователей |
| **Результатов на странице** | Количество результатов поиска, отображаемых на одной странице |
| **Страниц в навигации** | Максимальное количество номеров страниц в блоке постраничной навигации |
| **Максимум символов** | Ограничивает длину текста, передаваемого в поисковый запрос к базе данных. Снижает нагрузку при поиске в больших текстах |
| **Анализатор запросов** | Включает морфологическую обработку запроса: поиск ведётся одновременно по исходной форме слова, его основе и начальному фрагменту |

> [!NOTE]
> Анализатор запросов расширяет охват поиска, но увеличивает количество SQL-условий. При большой базе данных рекомендуется проверить производительность.

> [!IMPORTANT]
> Значение **Минимум символов** влияет не только на поиск, но и на автодополнение при вводе имени пользователя в личных сообщениях и панели администратора.
