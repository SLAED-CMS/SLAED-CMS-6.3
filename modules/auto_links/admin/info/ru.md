# Обмен ссылками

Раздел **«Обмен ссылками»** предназначен для автоматизации системы взаимного продвижения ресурсов. Модуль позволяет системно обмениваться ссылками и баннерами с партнерскими сайтами, что является эффективным инструментом поисковой оптимизации (SEO) и привлечения дополнительного трафика.

---

## 1. Назначение и методы обмена

Обмен ссылками в SLAED CMS 6.3 Phoenix применяется для следующих целей:
* **Рост Индекса Цитирования (ИЦ):** Повышение авторитета вашего сайта в поисковых системах.
* **Привлечение аудитории:** Прямые переходы посетителей с «дружественных» сайтов по вашему баннеру или ссылке.

### Как добавить партнерский сайт:
1. **Самостоятельная регистрация:** Заинтересованное лицо (администратор партнерского ресурса) добавляет свою ссылку через публичную часть модуля «Обмен ссылками».
2. **Администратором:** Вы можете добавить сайт вручную во вкладке «Добавить», заполнив название, описание (с BB-кодами) и URL.

---

## 2. Управление списком (Главная)

В основной таблице выводится перечень всех активных партнеров.
* **Статистика:** Для каждого сайта фиксируется количество «Входов» (трафик к вам) и «Выходов» (ваш трафик к партнеру).
* **Модерация:** В столбце «Функции» доступно полное редактирование данных сайта и его временное отключение.
* **Подробный просмотр:** При нажатии на эту опцию система покажет детальную информацию о переходах (IP-адрес и точное время), используя данные из раздела «Переходы».

---

## 3. Массовые операции и очистка

Инструментарий для поддержания базы ссылок в чистоте:
* **Обнулить значения:** Сброс всех счетчиков хитов (входов/выходов) для всех партнеров одновременно. Полезно для мониторинга активности в новом месяце или квартале.
* **Удалить сайты без входов:** Автоматический инструмент очистки. Система удаляет все сайты, с которых за все время не было зафиксировано ни одного перехода на ваш ресурс.

> [!TIP]
> Периодическое использование функции «Удалить сайты без входов» позволяет исключать недобросовестных партнеров или сайты с нулевой эффективностью.

---

## 4. Конфигурации модуля

Тонкая настройка отображения и взаимодействия:
* **Установка баннера:** Выбор системного изображения (баннера), которое будет предложено партнеру для размещения у себя. Баннеры хранятся в директории `/images/banners/` активной темы оформления.
* **Блоки (Sidebar):** Настройка параметров для системного блока `block_auto_links`:
  * **Количество ссылок:** Лимит сайтов в блоке.
  * **Количество символов:** Ограничение длины названия ссылки (при превышении будет выведено многоточие).
* **Уведомления:** Если опция «Уведомлять администраторов» включена, вы будете получать E-Mail о каждой новой заявке на обмен ссылками.
* **Навигация:** Установка максимального количества номеров страниц в навигационном блоке (пагинации) для удобства просмотра.

---

> [!IMPORTANT]
> При добавлении или редактировании ссылки администратор может задать начальные значения «Входов» и «Выходов», если обмен с партнером уже велся ранее на других условиях.

> [!WARNING]
> Будьте внимательны при использовании функции «Обнулить значения» — после этого действия вы не сможете восстановить статистику старых переходов без использования бэкапа базы данных.
