[justify]La section «Plan du site» permet de gérer les paramètres de génération du fichier sitemap.xml. Ce fichier permet d'informer les moteurs de recherche sur l'organisation du contenu de votre site. Les robots de recherche analysent ce fichier pour indexer plus précisément les sections et les pages.

Les fichiers Sitemap peuvent également être utilisés pour fournir aux moteurs de recherche des métadonnées sur vos pages. Cela inclut des informations telles que la date de dernière modification, la fréquence de mise à jour du contenu et la priorité de la page par rapport aux autres sur le site.

Pour que les robots de recherche découvrent le nouveau fichier Sitemap le plus rapidement possible, le webmaster doit modifier le fichier robots.txt en y ajoutant une directive spéciale indiquant le chemin exact vers le plan du site :

Exemple pour le protocole HTTP

[i]Sitemap: http://www.votre_site/sitemap.xml[/i]

Exemple pour le protocole sécurisé HTTPS

[i]Sitemap: https://www.votre_site/sitemap.xml[/i]

Ces modifications peuvent être effectuées directement depuis le panneau d'administration dans la section «Éditeur d'intégrations», onglet «Règles pour les robots».

Pour une indexation plus rapide, il est recommandé de vérifier le fichier de plan du site créé pour les erreurs et de l'ajouter aux moteurs de recherche Yandex, Google, Bing via «Yandex Webmaster», «Google Search Console», «Bing Webmaster».

[color=green][b]Onglet «Accueil»[/b][/color]
Cette section affiche des informations sur le fichier de plan du site créé : sa taille, sa date de création, le nombre de lignes et le code du fichier principal sitemap.xml. En cliquant sur le bouton «Actualiser», une nouvelle carte sera générée et le fichier existant sera mis à jour ou, en son absence, un nouveau fichier sera créé.

[color=green][b]Onglet «Modèle»[/b][/color]
Le modèle est conçu pour formater le plan du site, le rendant plus compréhensible et agréable pour la visualisation par les visiteurs ordinaires. Ce n'est pas un attribut obligatoire pour les moteurs de recherche et peut donc être modifié ou complètement désactivé.

À l'aide de mécanismes de styles d'autres types, plusieurs feuilles de style peuvent être créées pour un seul document XML, offrant différents scénarios d'affichage, comme dans notre cas pour un simple fichier de plan du site et un fichier d'index de plan du site.

[u]Variables du modèle[/u]
Le modèle utilise un type de variable : $lan[1], $lan[2], etc.
Celles-ci sont responsables de l'affichage des titres, des constantes (mots selon la langue choisie par le visiteur si cette option est activée, sinon dans la langue par défaut) et d'autres composants.

[color=green][b]Onglet «Configuration»[/b][/color]
Cet onglet contient les paramètres principaux de génération. Explications pour certains paramètres :

[li] [b][i]Modules[/i][/b] – modules du système pour lesquels le plan du site sera généré. Pour sélectionner deux options ou plus, maintenez la touche «Ctrl» enfoncée. Pour désactiver, sélectionnez «Non».
[li] [b][i]Fréquence de mise à jour[/i][/b] – paramètre indiquant la fréquence de mise à jour de la page. Pas un attribut obligatoire, peut être désactivé en sélectionnant «Non».
[li] [b][i]Priorité[/i][/b] – indique l'importance d'une page par rapport aux autres. La priorité peut être définie de 0.1 (faible) à 1.0 (élevée). Recommandé : maximum 1.0 pour la page principale, élevé 0.9 pour les modules, moyen 0.8 pour les catégories, plus bas 0.7 pour les publications. Pas un attribut obligatoire, peut être désactivé en sélectionnant «0».
[li] [b][i]Intervalle de temps entre les mises à jour du fichier de carte en heures[/i][/b] – le système peut créer des plans de site automatiquement. L'intervalle entre les créations de fichiers est spécifié en heures.
[li] [b][i]Génération et mise à jour automatiques du fichier de carte ?[/i][/b] – générer ou non le fichier de plan du site.
[li] [b][i]Indiquer la date de dernière modification[/i][/b] – ajouter ou non le paramètre de date pour les liens des sections correspondantes du site. Pas un attribut obligatoire, peut être omis.
[li] [b][i]Générer des liens[/i][/b] – sélectionner les sections pour lesquelles des liens seront générés dans le fichier de carte.
[li] [b][i]Utiliser le modèle de conception XSL pour le fichier de carte ?[/i][/b] – utiliser ou non le modèle de conception du plan du site s'il existe.
[li] [b][i]Créer une structure de carte normale pour la visualisation sur le site ?[/i][/b] – si cette option est définie, en plus de la version standard du plan du site, le système créera un fichier au format HTML pour la publication et la visualisation normale en tant que module système standard. Si vous prévoyez de l'utiliser, activez le module «sitemap» dans le panneau d'administration, section «Modules».

[hr][color=blue][b]Attention ![/b][/color]
La génération de liens est effectuée uniquement pour les modules activés pour la visualisation sur le site par «tous les visiteurs». La modification des paramètres de fonctionnement et de visibilité des modules est disponible depuis le panneau d'administration principal dans la section «Modules».[hr]
Plusieurs exigences s'appliquent à la création d'un plan du site que le webmaster doit connaître.

[li] Le nombre de liens dans un fichier Sitemap ne doit pas dépasser 50 000 unités. S'il y en a plus, le système créera plusieurs plans de site séparés qui seront répertoriés dans le fichier d'index Sitemap.
[li] La taille maximale d'un fichier de carte ne doit pas dépasser 10 Mo. Si cela se produit, le système le compressera automatiquement à l'aide de gzip.[/justify]
