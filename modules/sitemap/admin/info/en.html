[justify]The «Sitemap» section allows you to manage the settings for generating the sitemap.xml file. This file informs search engines about how content is organized on your website. Search robots scan this file to index sections and pages more accurately.

Sitemap files can also be used to provide search engines with metadata about your pages. This includes information such as the date of last modification, content update frequency, and page priority compared to others on the site.

For search robots to learn about a new Sitemap as quickly as possible, the webmaster needs to modify the robots.txt file by adding a special directive specifying the exact path to the sitemap:

Example for HTTP protocol

[i]Sitemap: http://www.your_site/sitemap.xml[/i]

Example for secure HTTPS protocol

[i]Sitemap: https://www.your_site/sitemap.xml[/i]

These changes can be made directly from the administration panel in the «Embedding Editor» section, «Rules for Robots» tab.

For faster indexing, it is recommended to check the created sitemap file for errors and add it to search engines like Yandex, Google, Bing using «Yandex Webmaster», «Google Search Console», «Bing Webmaster».

[color=green][b]«Home» Tab[/b][/color]
This section displays information about the created sitemap file: its size, creation date, number of lines, and the code of the main sitemap.xml file. Clicking the «Refresh» button will generate a new sitemap and update the existing one or create a new file if none exists.

[color=green][b]«Template» Tab[/b][/color]
The template is designed to format the sitemap, making it more understandable and pleasant for visual viewing by regular visitors. It is not a mandatory attribute for search engines and can therefore be modified or completely disabled.

Using style mechanisms of other types, multiple stylesheets can be created for a single XML document, providing different display scenarios, as in our case for a simple sitemap file and a sitemap index file.

[u]Template Variables[/u]
The template uses one type of variable: $lan[1], $lan[2], etc.
These are responsible for outputting headers, constants (words depending on the language selected by the visitor if this option is enabled, otherwise in the default language), and other components.

[color=green][b]«Configuration» Tab[/b][/color]
This tab contains the main generation settings. Explanations for some settings:

[li] [b][i]Modules[/i][/b] – system modules for which the sitemap will be generated. To select two or more options, hold the «Ctrl» key. To disable, select «No».
[li] [b][i]Update Frequency[/i][/b] – parameter indicating the page update frequency. Not a mandatory attribute, can be disabled by selecting «No».
[li] [b][i]Priority[/i][/b] – indicates the importance of a page compared to others. Priority can be set from 0.1 (low) to 1.0 (high). Recommended: maximum 1.0 for the main page, high 0.9 for modules, medium 0.8 for categories, lower 0.7 for publications. Not a mandatory attribute, can be disabled by selecting «0».
[li] [b][i]Time interval between sitemap updates in hours[/i][/b] – the system can create sitemaps automatically. The interval between file creations is specified in hours.
[li] [b][i]Automatic generation and update of the sitemap file?[/i][/b] – whether to generate the sitemap file or not.
[li] [b][i]Indicate last modification date[/i][/b] – add date parameter for links of corresponding site sections or not. Not a mandatory attribute, can be omitted.
[li] [b][i]Generate links[/i][/b] – select sections for which links will be generated in the sitemap file.
[li] [b][i]Use XSL design template for sitemap file?[/i][/b] – whether to use the sitemap design template if one exists.
[li] [b][i]Create a regular sitemap structure for viewing on the site?[/i][/b] – if this option is set, in addition to the standard sitemap, the system will create an HTML file for publication and regular viewing as a standard system module. If you plan to use it, activate the «sitemap» module in the administrator panel, «Modules» section.

[hr][color=blue][b]Please Note![/b][/color]
Link generation is performed only for modules activated for viewing on the site by «all visitors». Changing module operation and visibility settings is available from the main administrator panel in the «Modules» section.[hr]
Several requirements apply to sitemap creation that the webmaster should know.

[li] The number of links in a Sitemap file should not exceed 50,000 units. If there are more, the system will create several separate sitemaps that will be listed in the Sitemap index file.
[li] The maximum size of a single sitemap file should not exceed 10 MB. If this happens, the system will automatically compress it using gzip.[/justify]
