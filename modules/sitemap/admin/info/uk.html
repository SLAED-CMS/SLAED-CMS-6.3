[justify]Розділ «Карта сайту» дозволяє керувати налаштуваннями генерування файлу sitemap.xml. Цей файл дозволяє повідомляти пошуковим системам про те, як організовано вміст на вашому сайті. Пошукові роботи переглядають цей файл, щоб точніше індексувати розділи та сторінки.

Файли Sitemap також можна використовувати для надання пошуковим системам метаданих про ваші сторінки. Це такі відомості, як дата останніх змін, періодичність оновлення контенту та пріоритет сторінки порівняно з іншими на сайті.

Щоб пошукові роботи якомога швидше дізналися про новий файл Sitemap, веб-майстру необхідно внести зміни до файлу robots.txt, прописавши в ньому спеціальну директиву, що вказує точний шлях до карти сайту:

Приклад для протоколу HTTP

[i]Sitemap: http://www.ваш_сайт/sitemap.xml[/i]

Приклад для безпечного протоколу HTTPS

[i]Sitemap: https://www.ваш_сайт/sitemap.xml[/i]

Ці зміни можна внести безпосередньо з панелі керування системою, у розділі «Редактор впроваджень», вкладка «Правила для роботів».

Для швидшої індексації рекомендується перевірити створений файл карти сайту на наявність помилок та додати до пошукових систем Yandex, Google, Bing за допомогою «Яндекс Вебмайстер», «Google Search Console», «Bing веб-майстер».

[color=green][b]Вкладка «Головна»[/b][/color]
У цьому розділі відображається інформація про створений файл карти сайту, його розмір, дата створення, кількість рядків та безпосередньо код основного файлу sitemap.xml. При натисканні на кнопку «Оновити» відбудеться генерація нової карти та відповідно оновлення існуючого або у разі відсутності, створення нового файлу.

[color=green][b]Вкладка «Шаблон»[/b][/color]
Шаблон призначений для оформлення карти сайту, робить його зрозумілішим та приємнішим для візуального перегляду звичайними відвідувачами і не є обов'язковим атрибутом для пошукових систем, тому може бути модифікований або повністю вимкнений.

За допомогою механізмів стилів інших типів для одного XML-документа може бути створено кілька таблиць стилів, що забезпечують кілька кінцевих сценаріїв відображення інформації, як у нашому випадку, для простого файлу карти сайту та файлу індексу списку карт сайту.

[u]Змінні шаблону[/u]
У шаблоні використовується один тип змінних: $lan[1], $lan[2] тощо.
Вони відповідають за виведення заголовка, констант (слів залежно від мови, обраної відвідувачем, якщо така можливість активована, в іншому випадку мовою, встановленою за замовчуванням) та інших складових.

[color=green][b]Вкладка «Конфігурація»[/b][/color]
У цій вкладці встановлюються основні налаштування генерації. Пояснення до деяких налаштувань:

[li] [b][i]Модулі[/i][/b] – модулі системи, для яких буде генеруватися карта сайту. Для вибору двох і більше варіантів утримуйте клавішу «Ctrl». Для вимкнення оберіть параметр «Ні».
[li] [b][i]Частота оновлення[/i][/b] – параметр, що вказує частоту оновлення сторінки. Не є обов'язковим атрибутом, можна вимкнути, обравши значення «Ні».
[li] [b][i]Пріоритет[/i][/b] – вказує ступінь важливості сторінки порівняно з іншими. Пріоритет можна виставляти від 0.1 (низький) до 1.0 (високий). Рекомендується розставляти таким чином: максимальний для головної сторінки 1.0, для модулів високий 0.9, для категорій середній 0.8, для публікацій нижчий 0.7. Не є обов'язковим атрибутом, можна вимкнути, обравши значення «0».
[li] [b][i]Проміжок часу між оновленнями файлу карти, в годинах[/i][/b] – система може створювати карти сайту в автоматичному режимі. Проміжок між створеннями файлів карти вказується в годинах.
[li] [b][i]Автоматична генерація та оновлення файлу карти?[/i][/b] – генерувати файл карти чи ні.
[li] [b][i]Вказувати дату останньої зміни[/i][/b] – додавати параметр дати для посилань відповідних розділів сайту чи ні. Не є обов'язковим атрибутом, можна не використовувати.
[li] [b][i]Генерувати посилання[/i][/b] – обрати розділи, для яких будуть генеруватися посилання у файлі карти.
[li] [b][i]Використовувати шаблон оформлення XSL для файлу карти?[/i][/b] – використовувати чи ні шаблон оформлення карти сайту, у разі якщо шаблон присутній.
[li] [b][i]Створювати звичайну структуру карти для перегляду на сайті?[/i][/b] – у разі встановлення цієї опції, додатково до стандартної версії карти сайту системою буде створено файл у форматі HTML для публікації та звичайного перегляду у вигляді стандартного модуля системи. Якщо планується його використання, активуйте модуль «sitemap» у панелі адміністратора, розділ «Модулі».

[hr][color=blue][b]Зверніть увагу![/b][/color]
Генерація посилань виконується тільки для модулів, активованих для перегляду на сайті «всім відвідувачам». Зміна налаштувань роботи та видимості модулів доступна з головної панелі адміністратора системи, розділ «Модулі».[hr]
До створення карти сайту застосовуються кілька вимог, про які повинен знати веб-майстер.

[li] Кількість посилань у файлі Sitemap не повинна перевищувати 50 тисяч одиниць. Якщо їх більше, то система створить кілька окремих карт сайту, які пропишуться у файлі індексу Sitemap.
[li] Максимальний розмір одного файлу карти не повинен перевищувати 10 Мб. Якщо це станеться, система автоматично зменшить його за допомогою архіватора gzip.[/justify]
