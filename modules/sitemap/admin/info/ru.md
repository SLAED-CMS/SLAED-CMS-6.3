# Карта сайта (Sitemap)

Раздел **«Карта сайта»** управляет настройками автоматической генерации файла `sitemap.xml`, который помогает поисковым системам (Google, Яandex, Bing) эффективнее индексировать содержимое вашего сайта.

---

## 1. Просмотр и обновление (вкладка «Главная»)

Сверху плитки показывают число файлов карты, их общий размер и число адресов, а строки под ними — адрес карты для поисковых систем и дату, размер и число адресов каждого файла. Ниже стоит предпросмотр кода. Нажмите кнопку **«Обновить»** для немедленной принудительной перегенерации файла. Генерацию ведёт задача планировщика `sitemap`: когда планировщик выключен, идёт установка обновления, задача уже работает или в карте не выбран ни один модуль, файл не пересобирается, и сообщение над страницей называет причину.

---

## 2. Шаблон оформления (вкладка «Шаблон»)

XSL-шаблон обеспечивает красивое визуальное отображение `sitemap.xml` для людей, открывающих файл напрямую в браузере. Для поисковых роботов этот шаблон не имеет значения. Вы можете его изменить или полностью отключить в конфигурациях.

Вкладку видит и сохраняет только суперадминистратор: браузер исполняет шаблон в адресе сайта, поэтому его правка равна праву на весь сайт. Администратору с одним правом на карту сайта вкладка не показывается, а прямой адрес ведёт на главную вкладку с сообщением «Доступ запрещен».

Файл `storage/sitemap/sitemap.xsl` пишется с версией: если его изменили, пока был открыт редактор, сохранение отклоняется, а ваш текст остаётся в форме. Пустой шаблон не сохраняется: панель отвечает «Оставлено пустым поле с текстом!», и файл остаётся прежним.

---

## 3. Конфигурации

| Параметр | Описание |
|---|---|
| **Модули** | Выберите модули, страницы которых нужно включать в карту (для выбора нескольких удерживайте **Ctrl**) |
| **Частота обновления** | Подсказка для поисковиков о том, как часто обновляется страница (необязательный атрибут) |
| **Приоритет** | Важность страниц в системе индексирования. Рекомендуемая шкала: Главная → `1.0`, Разделы → `0.9`, Категории → `0.8`, Публикации → `0.7` |
| **Интервал обновления (в часах)** | Как часто система будет автоматически перегенерировать файл |
| **Автоматическая генерация?** | Включает/выключает автогенерацию |
| **Указывать дату изменения?** | Добавлять ли атрибут `lastmod` к URL (необязательный) |
| **Использовать XSL-шаблон?** | Подключать ли визуальный шаблон из вкладки «Шаблон» |
| **Создавать HTML-карту для сайта?** | Дополнительно генерировать HTML-версию карты для публичного показа (требует активации модуля `sitemap` в разделе «Модули») |

---

## Настройка robots.txt

Чтобы поисковые роботы находили файл карты автоматически, добавьте в файл `robots.txt` следующую директиву:

```
Sitemap: https://ваш_сайт/sitemap.xml
```

Отредактировать `robots.txt` можно в разделе **«Файловый менеджер»** → вкладка **«Системные файлы»**, ссылка `public/robots.txt`.

---

> [!IMPORTANT]
> Ссылки в карте сайта генерируются **только для модулей, активных для просмотра всеми посетителями**. Проверьте настройки видимости модулей в разделе «Модули».

> [!NOTE]
> **Технические ограничения формата:** один файл Sitemap не должен содержать более 50 000 URL и весить более 10 МБ. При превышении лимитов система автоматически разбивает карту на несколько файлов с индексным файлом-оглавлением (Sitemap Index) или сжимает с помощью gzip.
