[justify]Der Bereich «Sitemap» ermöglicht die Verwaltung der Einstellungen zur Generierung der Datei sitemap.xml. Diese Datei informiert Suchmaschinen über die Organisation der Inhalte auf Ihrer Website. Suchroboter durchsuchen diese Datei, um Bereiche und Seiten präziser zu indexieren.

Sitemap-Dateien können auch verwendet werden, um Suchmaschinen Metadaten über Ihre Seiten bereitzustellen. Dazu gehören Informationen wie das Datum der letzten Änderung, die Aktualisierungshäufigkeit und die Priorität der Seite im Vergleich zu anderen auf der Website.

Damit Suchroboter so schnell wie möglich von einer neuen Sitemap erfahren, muss der Webmaster die Datei robots.txt ändern und eine spezielle Direktive hinzufügen, die den genauen Pfad zur Sitemap angibt:

Beispiel für HTTP-Protokoll

[i]Sitemap: http://www.ihre_website/sitemap.xml[/i]

Beispiel für sicheres HTTPS-Protokoll

[i]Sitemap: https://www.ihre_website/sitemap.xml[/i]

Diese Änderungen können direkt über das Administrationspanel im Bereich «Einbettungseditor», Registerkarte «Regeln für Roboter» vorgenommen werden.

Für eine schnellere Indexierung wird empfohlen, die erstellte Sitemap-Datei auf Fehler zu überprüfen und sie bei Suchmaschinen wie Yandex, Google, Bing über «Yandex Webmaster», «Google Search Console», «Bing Webmaster» hinzuzufügen.

[color=green][b]Registerkarte «Hauptseite»[/b][/color]
In diesem Bereich werden Informationen über die erstellte Sitemap-Datei angezeigt: Größe, Erstellungsdatum, Zeilenanzahl und der Code der Hauptdatei sitemap.xml. Durch Klicken auf die Schaltfläche «Aktualisieren» wird eine neue Sitemap generiert und die bestehende aktualisiert oder bei Abwesenheit eine neue Datei erstellt.

[color=green][b]Registerkarte «Vorlage»[/b][/color]
Die Vorlage dient zur Gestaltung der Sitemap und macht sie verständlicher und angenehmer für die visuelle Betrachtung durch normale Besucher. Sie ist kein obligatorisches Attribut für Suchmaschinen und kann daher modifiziert oder vollständig deaktiviert werden.

Mit Hilfe von Stilmechanismen anderer Typen können für ein XML-Dokument mehrere Stylesheets erstellt werden, die verschiedene Anzeigevarianten ermöglichen, wie in unserem Fall für eine einfache Sitemap-Datei und eine Sitemap-Index-Datei.

[u]Vorlagenvariablen[/u]
In der Vorlage wird ein Variablentyp verwendet: $lan[1], $lan[2] usw.
Diese sind für die Ausgabe von Überschriften, Konstanten (Wörter je nach der vom Besucher gewählten Sprache, falls diese Option aktiviert ist, andernfalls in der Standardsprache) und anderen Komponenten verantwortlich.

[color=green][b]Registerkarte «Konfiguration»[/b][/color]
In dieser Registerkarte werden die Haupteinstellungen für die Generierung festgelegt. Erläuterungen zu einigen Einstellungen:

[li] [b][i]Module[/i][/b] – Systemmodule, für die die Sitemap generiert wird. Um zwei oder mehr Optionen auszuwählen, halten Sie die Taste «Strg» gedrückt. Zum Deaktivieren wählen Sie «Nein».
[li] [b][i]Aktualisierungshäufigkeit[/i][/b] – Parameter, der die Aktualisierungshäufigkeit der Seite angibt. Kein obligatorisches Attribut, kann durch Auswahl von «Nein» deaktiviert werden.
[li] [b][i]Priorität[/i][/b] – gibt die Wichtigkeit einer Seite im Vergleich zu anderen an. Die Priorität kann von 0.1 (niedrig) bis 1.0 (hoch) eingestellt werden. Empfohlen: Maximum 1.0 für die Hauptseite, hoch 0.9 für Module, mittel 0.8 für Kategorien, niedriger 0.7 für Publikationen. Kein obligatorisches Attribut, kann durch Auswahl von «0» deaktiviert werden.
[li] [b][i]Zeitintervall zwischen Sitemap-Aktualisierungen in Stunden[/i][/b] – das System kann Sitemaps automatisch erstellen. Das Intervall zwischen den Dateierstellungen wird in Stunden angegeben.
[li] [b][i]Automatische Generierung und Aktualisierung der Sitemap-Datei?[/i][/b] – ob die Sitemap-Datei generiert werden soll oder nicht.
[li] [b][i]Datum der letzten Änderung angeben[/i][/b] – Datumsparameter für Links der entsprechenden Website-Bereiche hinzufügen oder nicht. Kein obligatorisches Attribut, kann weggelassen werden.
[li] [b][i]Links generieren[/i][/b] – Bereiche auswählen, für die Links in der Sitemap-Datei generiert werden sollen.
[li] [b][i]XSL-Designvorlage für Sitemap-Datei verwenden?[/i][/b] – ob die Sitemap-Designvorlage verwendet werden soll, falls vorhanden.
[li] [b][i]Normale Sitemap-Struktur zur Ansicht auf der Website erstellen?[/i][/b] – bei Aktivierung dieser Option erstellt das System zusätzlich zur Standard-Sitemap eine HTML-Datei zur Veröffentlichung und normalen Ansicht als Standardsystemmodul. Bei geplanter Nutzung aktivieren Sie das Modul «sitemap» im Administratorpanel, Bereich «Module».

[hr][color=blue][b]Beachten Sie![/b][/color]
Die Linkgenerierung erfolgt nur für Module, die für die Ansicht auf der Website für «alle Besucher» aktiviert sind. Die Änderung der Arbeits- und Sichtbarkeitseinstellungen der Module ist über das Hauptadministratorpanel im Bereich «Module» möglich.[hr]
Bei der Erstellung einer Sitemap gelten mehrere Anforderungen, die der Webmaster kennen sollte.

[li] Die Anzahl der Links in einer Sitemap-Datei darf 50.000 Einheiten nicht überschreiten. Wenn es mehr sind, erstellt das System mehrere separate Sitemaps, die in der Sitemap-Index-Datei aufgeführt werden.
[li] Die maximale Größe einer Sitemap-Datei darf 10 MB nicht überschreiten. Falls dies passiert, wird das System sie automatisch mit gzip komprimieren.[/justify]
