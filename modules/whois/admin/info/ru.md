# Whois (Проверка доменов)

Раздел **«Whois»** (`admin.php?name=whois`) предназначен для сбора и проверки информации о доменных именах, связанных с пользователями или посетителями сайта. Позволяет пользователям вносить данные о своём домене, хостинге и дата-центре, а администратор может верифицировать и публиковать эти сведения.

---

## 1. Главная (Одобренные записи)

В основной вкладке отображаются все активные (одобренные) записи о доменах.

| Колонка | Описание |
|---|---|
| **Отправитель** | Ник пользователя или имя. Подсказка при наведении содержит IP, дату и комментарий |
| **Сайт / Хост / ДЦ** | URL домена, хостинга и дата-центра с их статусом |
| **Функции** | Управление активностью каждого из трёх полей (Сайт, Хост, ДЦ) независимо друг от друга |

Статус каждого из трёх полей (Сайт, Хост, ДЦ) можно переключать **независимо** нажатием на соответствующий индикатор в колонке функций.

---

## 2. Новые записи (вкладка «Новые»)

Записи, добавленные пользователями или гостями, попадают на первичную модерацию в эту вкладку. Они «невидимы» для других пользователей, пока администратор не одобрит публикацию через форму редактирования.

---

## 3. Добавление записи

При ручном создании или редактировании записи администратором заполняются:
* **Автор:** Поиск пользователя по нику из базы, или ввод произвольного имени.
* **Сайт** (обязательное поле) — основной URL домена.
* **Хост** — URL хостинг-провайдера.
* **ДЦ** — URL дата-центра.
* **Комментарий** — произвольная заметка от автора записи.

---

## 4. Конфигурации

* **Количество записей на странице** и **в навигации** (пагинация).
* **Уведомлять администратора о новых поступлениях?** — E-Mail при каждой новой заявке на модерацию.
* **Разрешить пользователям добавлять записи?** — доступность публичной формы для авторизованных пользователей.
* **Разрешить гостям добавлять записи?** — доступность формы для анонимных посетителей.
