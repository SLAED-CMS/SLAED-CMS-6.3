# Клиенты (Версии продуктов)

Раздел **«Клиенты»** (`admin.php?name=clients`) предназначен для ведения каталога программных продуктов, дистрибутивов или различных версий системы. Модуль позволяет организовать базу доступных для загрузки файлов с описанием и автоматическим подсчетом количества скачиваний.

---

## 1. Главная (Список продуктов)

В основной вкладке отображается таблица всех зарегистрированных в системе версий или продуктов.
* **Название и Версия:** Имя продукта и его точный номер версии.
* **Дата релиза:** Информационное поле о дате выпуска продукта.
* **Счетчик «Скачено»:** Автоматически фиксирует количество уникальных загрузок данного архива.
* **Статус:** Цветной индикатор активности (зеленый — продукт доступен, красный — скрыт).

В списке можно быстро найти нужную версию и перейти к её редактированию кнопкой **«Редактор»**.

---

## 2. Добавление и редактирование

При создании новой записи о продукте (вкладка **«Добавить»**) заполняются следующие параметры:
* **Название:** Полное наименование (например, «SLAED CMS 6.3 Phoenix»).
* **Текст:** Подробное описание продукта. Поддерживается использование BB-кодов и визуального редактора для оформления текста.
* **Директория архива:** Точный путь к файлу на сервере или ссылка на скачивание.
* **Версия:** Строковое значение версии.
* **Код / Артикул:** Внутренний идентификатор или код продукта для учета.
* **Сортировка (№):** Порядковый номер, определяющий место продукта в общем списке.
* **Активировать архив?:** Позволяет мгновенно включить или выключить доступность файла для скачивания без удаления записи.

## 3. Информация

Специальная вкладка для административных заметок. Здесь можно сохранить общие правила ведения каталога или техническую информацию для других администраторов сайта.

---

> [!TIP]
> Модуль часто используется разработчиками для публикации истории обновлений и предоставления пользователям доступа к старым версиям ПО.

> [!IMPORTANT]
> Перед публикацией новой версии убедитесь, что файл архива действительно находится по указанному пути в поле «Директория архива», иначе пользователи не смогут начать загрузку.
