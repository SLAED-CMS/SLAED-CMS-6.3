# Каталог файлов

Раздел **«Каталог файлов»** предназначен для публикации файлов в соответствующем разделе сайта с разбивкой по категориям.

> [!TIP]
> Категории для каталога файлов создаются в разделе **«Категории»** блока «Администратор».

---

## 1. Главная (Список файлов)

В основной вкладке отображается перечень всех опубликованных файлов:
* **Подробный просмотр:** Страница файла так, как это видит посетитель.
* **Полное редактирование:** Форма редактирования данных о файле и его метаинформации.
* **Удаление:** Удаляет запись из каталога.

---

## 2. Добавление файла

При добавлении нового материала во вкладке **«Добавить»** предусмотрены три варианта размещения файла:
1. **Загрузить с компьютера:** Непосредственный upload файла со своего ПК или из локальной сети.
2. **Загрузить по ссылке:** Укажите URL — система самостоятельно скачает и сохранит файл на сервере.
3. **Ссылка на файл:** Файл хранится на внешнем ресурсе и не скачивается на ваш сервер. При этом варианте необходимо вручную указать размер файла в байтах, так как система не может определить его автоматически.

> [!NOTE]
> Перед окончательной публикацией воспользуйтесь опцией «Предварительный просмотр», чтобы проверить, как запись выглядит на сайте. Для публикации выберите «Отправить» → «ОК».

---

## 3. Модерация (вкладка «Новые»)

Если пользователям или гостям разрешено добавлять файлы самостоятельно, все новые поступления отображаются в этой вкладке. Файл **не появится в публичном каталоге** до тех пор, пока администратор не откроет форму его редактирования и не сохранит изменения (тем самым одобряя публикацию).

---

## 4. Недоступные файлы

Посетители могут сообщить о том, что ссылка на скачивание файла не работает. Такие файлы попадают в эту вкладку. Администратор может:
* Нажать «Подробный просмотр» и самостоятельно проверить ссылку на работоспособность.
* Нажать «Игнорировать» — предупреждение будет снято, и файл исчезнет из этого списка (до получения следующей жалобы).

---

## 5. Конфигурации

* **Максимальный размер файла (в байтах):** Лимит на вес загружаемого файла. Поле принимает только числовые значения.
* **Допустимые форматы файлов:** Разрешенные расширения через запятую без пробелов (например: `zip,rar,7z,pdf`).
* **Количество колонок таблицы категорий:** Визуальный параметр, определяющий, сколько столбцов будет в таблице категорий на странице модуля.
* **Разрешить добавлять файлы?** / **Разрешить гостям добавлять?**
* **Возможность сообщать о недоступных файлах?** — включает/выключает кнопку «Сообщить о недоступности» при просмотре файлов.
